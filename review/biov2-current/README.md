# 当前BIO_V2/ADS1292R只读审查副本

这里是现行B板源文件快照，**不是可直接构建/烧录的完整工程**。SCREEN、所有标准库和历史二进制没有整体复制，不能用本目录重建当前已运行镜像。

27个板级C/H/启动文件逐字节与本地现行源相同，包含最新通道独立修复BIO_V2；来源/准确SHA见`artifacts/ecg-source/biov2-source-manifest.json`。

原`build_arm.py`仅归档作流程审查，其相对工具依赖/原工程布局未迁移。地址生成器`make_profile.py`仅去掉真实板UID字段，公开记录原SHA与审查副本SHA；不得将这个审查版生成器用于真机身份门禁。没有修改原生产文件。

当前正常源配置RLD_SENS=EC、RESP1=EA，最近初始化真实回读亦为EC/EA；它们不等于拟议S_DAC_ECG_ONLY的CC/2A。G0/G1不应用B板寄存器补丁、不重编B板、不烧录。后续改变B板配置需要负责人裁定并冻结另一个候选。

当前候选BIO_V2 BIN身份已知，但板上今天实际镜像未读取。27+29历史普通测试和候选ARM通过，只能按各自当轮边界理解。

板UID、完整Flash、真实输入/患者数据、电脑连接信息和运行态地址表不公开。源码中设备地址/寄存器地址是芯片标准定义，不是服务器连接信息。
