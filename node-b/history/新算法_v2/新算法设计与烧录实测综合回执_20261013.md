## 3. 独立处理链

```text
同一帧两路signed原始码 + 源序号/采样ms/flags
       ↓ 断段/削顶清除资格，首点初始化直流估计
50/100 Hz有界双二阶陷波
       ├ ECG：5 Hz高通 + 25 Hz低通 → RMS门限/完整峰宽 → 新鲜周期窗
       └ 呼吸：慢直流跟踪 + 0.8 Hz低通 → 完整谷峰起伏 → 新鲜周期窗
       ↓ 至少3个新合法间隔 + 最近周期一致性 + 干扰资格
候选速率 / valid / 原因码 / 滤波波形，供界面和诊断读取
```

IIR系数按250 Hz及[RBJ二阶滤波公式](https://www.w3.org/TR/audio-eq-cookbook/)独立生成，不使用旧FIR系数或旧算法源码。全程静态、有界状态，逐帧常数开销；不引入RTOS、动态内存或新中断任务。

关键规则：

- 恒定大直流从首点建立基线，避免零初态产生虚假呼吸峰。
- 原始序号断段、flags、明显削顶或输入中断撤销资格。
- 候选峰时间与最后合法周期时间分开；非法候选不延长合法测量有效期。
- 超时清除周期资格与旧间隔，不因一个新峰复活旧速率。
- 速率失效保留流式滤波状态，不反复清零滤波造成新的阶跃。
- 至少3个新合法间隔，最近窗口间隔在中位周期20%内，才建立工程valid。
- 强陷波差分占比与低频能量资格在建立周期历史之前检查；不是先制造数值再隐藏告警。

工程支持范围：HR约30～220/min，呼吸6～40/min；ECG预热5 s，呼吸预热10 s。它们是原型的软件判据，**不是“正常人体范围”或临床认可阈值**。没有参考值时，范围内数值也不能作为正确心率/呼吸率。

公开原因位：1预热、2新周期不足、4周期不一致、8过期、16输入断段、32削顶、64强周期干扰、128宽带噪声资格不足。原因会保持失效语义直到新周期重建，不能只用最后一个能量比反推全部历史事件。
