# 工频单变量排查方案与接线调整条件

2026-10-13。当前条件：外部电极与模拟器断开，开发板USB_232连接电脑，J-Link四线3V3/SWDIO/GND/SWCLK接板上同名引脚，模块与开发板保持共地。用户没有独立电源或测量仪器。

## 本轮可执行的对照

维持当前全部线缆、供电及位置；PG15=START，PA0=PWDN、PA2=CS、PA3=DRDY、PA5=SCLK、PA7=DIN、PA6=DOUT。两ADC通道始终内部短接、增益4、250SPS，SPI仍为656.25kHz；所有寄存器只在启动阶段配置，采集中不修改。

| 条件 | RLD_SENS | RESP1 | 用途 |
|---|---:|---:|---|
| BASE | CC | 2A | RLD缓冲、调制、解调关闭；CH2感测选择和112.5°相位固定 |
| RLD_ON | EC | 2A | 与BASE仅差RLD缓冲使能bit5 |
| MOD_ON | CC | 6A | 与BASE仅差呼吸调制使能bit6 |
| RESP_ON | CC | EA | 与MOD_ON仅差呼吸解调使能bit7 |

RLD感测选择不能在同一对照中随缓冲使能一起变化；相位也不能随调制使能一起变化。RESP_ON直接对BASE同时改变调制、解调两位，**不作为单变量对照**。

顺序：B0 BASE → R1 RLD_ON → B1 BASE → M1 MOD_ON → D1 RESP_ON → B2 BASE。每轮35秒，保留初始化与所有原件，分析排除首5秒。B0/B1/B2用于评估时间漂移；CH2的49–51Hz带RMS为主要观察量，CH1为辅助观察。解调会改变CH1处理路径，CH1噪声降低不能直接解释为电源或外部共模干扰改善。

芯片内部短接、外部电极拔下时，本轮只评价电路开启后对内部数据的耦合，不能验收RLD对外部电极的反馈效果、ECG精度或呼吸阻抗测量。[TI ADS1292R手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)

观测有效性由身份、实际寄存器回读、原件SHA、完整序号、时序与驱动错误决定；噪声升高保留为实验结果，不为获得PASS改门限。原Flash每窗口双读备份，结束恢复并VerifyBin／独立1MiB回读。失败数据不覆盖。

## 供电方向：尚未核实

标准20针J-Link的VTref（1脚）是目标电压参考输入，5V-Supply（19脚）才是可选目标供电输出。但当前探头／转接板仅提供“3V3”丝印信息，不能据此推断供电方向，也不能从VTref=3.3V读数推出有几路供电。[SEGGER连接器定义](https://kb.segger.com/20-pin_J-Link_Connector)

当前只做保持原样的寄存器对照，不拔3V3线、不操作探头供电开关。若后续实物确认是VTref，应保留板3.3V→VTref参考线；若确认是独立供电输出，应按板卡电源原理图处理单路供电，不能同时向同一3.3V电源轨注入两个独立电源。任何改线先确定探头型号／引脚方向及开发板电源路径，再给出具体步骤。

## 后续供电／公共地对照需要什么

1. 独立电池／移动电源或可核验的隔离台架电源，能稳定维持开发板及模块供电；确认接入点、电压与板上稳压／防倒灌路径。
2. 核实J-Link 3V3线方向，最好补齐实物照片及对应原理图；若存在实际探头供电，先解决供电路径的可辨识性。
3. 对照时仅改变目标因素：要比较电源本身，应保持其它电脑连接和回流路径不变；更换USB电源同时断开电脑USB，会同时改变供电与公共地路径，只能标为组合路径变化。
4. 比较电脑公共地路径时，**模块GND—开发板GND必须保持连接**。实验目标是电脑相关路径，不是取消数字信号参考地。
5. 现有采集依赖J-Link实时读约0.512秒保留窗口；拔掉J-Link后无法取得完整静默窗口。需要先准备经验证的自主RAM留存或合适的独立记录方法，采样结束后才重连读取；不能把重连后的数据当作断开期间的数据。

在这些条件满足前，供电／公共地贡献标为待测。不得用“移除所有地线”或直接把悬空输入噪声变化宣告为根因。

## 保留的限制

没有独立电源、示波器或漏电／电流记录，不能识别实际电源电流流向、供电纹波、各回流路径电流。本轮RLD／RESP对照仍共享电脑供电与J-Link连接，结论仅适用于这一接线状态。最终结果和恢复情况另存综合回执，不覆盖本方案或历史失败。
