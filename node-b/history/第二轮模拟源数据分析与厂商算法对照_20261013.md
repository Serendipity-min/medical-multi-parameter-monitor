# 第二轮模拟源数据分析与厂商算法对照

日期：2026-10-13。执行方式：纯脱机，只读原始 CSV、文档及固件源码；没有连接开发板、烧录、修改算法或采集工具。

## 1. 结论

1. **第二轮的采样连续性表现良好，但信号质量仍明显不满足稳定心率／呼吸率验证要求。** CSV 中双通道配对、序号和时间连续；ECG 主要为约 50 Hz 及 100 Hz 成分，呼吸通道有干扰、基线变化和不规则起伏。
2. **不同模拟源的原始输入已经明显不同。** 在相同统计口径下，第二轮 ECG 波动标准差约为第一轮的 8.45 倍。差异存在于算法前的原始码，不能用“换个峰值算法”直接解释或消除。
3. 冻结 BIO_V2 的 Host 回放在第二轮只于约 16.821–20.247 秒短暂给出有效心率 60，呼吸率始终无有效输出。**没有模拟源真值，因此 60 不代表已经测准；无效输出也不能直接解释为算法程序故障。**
4. 用户给出的 F407 示例目录目前是**带本地诊断修改的移植版**，不是可以确认身份的未修改厂家原版。它的 FIR 可用于对照滤波效果，但当前采集调度和心率逻辑存在具体问题，不建议直接替换我们的采集链路。
5. 本轮不支持“重新写整套算法就能解决”的判断。建议先确定模拟源的输出方式与参考值，区分输入端／共模干扰、模块链路和算法局限，再做有针对性的调整。

## 3. 源码与算法有什么区别

| 项目 | 当前 F407 示例移植版 | BIO_V2 与当前实验采集链路 |
|---|---|---|
| START | PA1；另有 START 命令诊断 | PG15，适应目前接线，PA1 不再驱动 START |
| 其它主要 SPI／控制脚 | PA0 PWDN、PA2 CS、PA3 DRDY、PA5 SCLK、PA6 DOUT、PA7 DIN | 相同 |
| 采样率 | CONFIG1=0x01，名义 250 SPS | 同样名义 250 SPS |
| 增益 | CH1SET/CH2SET=0x60，12 倍 | 0x40，4 倍 |
| RLD | RLD_SENS=0xCB，缓冲器关闭 | 0xEC，缓冲器开启，选择 CH2 共模 |
| 导联检测 | LOFF_SENS=0x00，并周期读状态 | LOFF_SENS=0x00；保留帧 STATUS 证据 |
| 时钟诊断 | PA8 输出 HSE/4，源码意图为 2 MHz 外部 CLK | 本次没有改变现有时钟方案 |
| 数据交接 | ISR 覆盖一组全局 CH1/CH2，单个 flog 标志 | 每帧保存双通道与 IRQ 序号／时间／flags，经有界 128 帧队列交接 |
| 原始数值 | 24 位码异或 0x800000 后转 float | 符号扩展为有符号 ADC 码 |
| ECG 滤波 | 129 抽头（128 阶）FIR，变量名 BPF_5Hz_40Hz | 直流估计、50/100 Hz 陷波、5 Hz 高通与 25 Hz 低通 IIR |
| 呼吸滤波 | 129 系数低通，变量名 LPF_2Hz；保留直流 | 慢直流估计、50/100 Hz 陷波、0.8 Hz 低通 |
| 心率计算 | 三点局部极大值＋最大值／峰峰值阈值；用 IRQ 计数乘 4 ms 算周期 | RMS 阈值、峰宽、周期范围、至少三个新鲜合法间隔、最近间隔稳定性和超时失效 |
| 呼吸率计算 | **没有完整呼吸率算法**；B 只是呼吸波 | 完整波谷到波峰、显著起伏、合法周期和新鲜资格 |
| 质量控制 | 没有系统性的干扰比例、周期资格和过期有效性 | 原始／去干扰功率判断、呼吸低频占比判断、缺口／削顶失效、原因码 |
| 输出 | B 呼吸波、A ECG 波、C 心率的文本串口 | 原始双通道证据、诊断状态、波形、rate 与 valid 独立输出 |

寄存器字段核对依据 TI 数据手册的 CHnSET、RLD_SENS 表；0x60 与 0x40 不是同增益，0xCB 与 0xEC 的 RLD 缓冲状态也不同。数据手册另有 LOFF_SENS、LOFF_STAT 的配置要求，故本次全零导联状态不能单独证明电极接触合格。[TI ADS1292R 数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)

**不能原样烧录此示例作公平算法对照：** 当前 START 接 PG15，而示例仍输出 PA1；增益、RLD 和诊断读寄存器行为也不同。PA8 外部 CLK 是否实际接线，本轮没有证据。不同 ADC 配置下的 ADC 码幅值不能直接当成同一物理输入幅值比较。

### 3.1 FIR 名称与真实频响不完全一致

直接提取当前源码的全部系数，在 250 SPS 下计算频响；没有运行厂家固件或修改系数。

| 当前数组 | 实际计算结果 |
|---|---|
| BPF_5Hz_40Hz | 相对峰值 −3 dB 通带约 **3.787–29.211 Hz**，并非完整 5–40 Hz；50 Hz 增益约 −75.75 dB；直流增益 0.014884 |
| LPF_2Hz | 相对直流／峰值 −3 dB 截止约 **1.920 Hz**；直流增益 1.158841，非单位增益 |
| 两组 FIR | 129 系数、对称；均匀 250 SPS 时线性相位群延迟 64 点，即 256 ms |

`raw24 ^ 0x800000` 对有效 24 位补码等价于“有符号码加 8388608”，本身不应判为符号转换错误。但示例 FIR 的非零直流增益会保留固定输出偏置；这与我们去直流后的零附近波形外观明显不同。波形更平滑、偏置不同，均不能证明心率更准确。

### 3.2 当前示例中可确认的代码问题

1. **没有样本 FIFO。** ISR 更新两路全局值，主循环读两路值和清 flog 之间没有帧级交接保护；存在覆盖未处理样本、读到不同帧的双通道值、抹掉新 flog 的竞态。仅给变量加 volatile 也无法补上帧一致性。
2. **周期性主动丢弃输入。** main.c 每约两秒读 LOFF 后设 `loff_skip=20`。假定主循环逐帧跟上，相当于每次跳过约 80 ms、名义约 4% 的输入；加上读寄存器时关闭 EXTI 的时间，处理序列不再保证均匀。FIR 和 `point_cnt*4` 没有完整补偿这些变化。
3. **心率状态未初始化。** 局部 `Peak`、`BPM_LH[3]`、`BPM` 在早期参与比较／输出前未完整赋值。Peak 首次更新要等 2000 多个处理点，不能把前段输出当可靠测量。
4. **统计类型和计时不稳健。** 滤波输出 float 写入无符号 min/max/峰值历史，不适合一般有符号输入；IRQ 增加 point_cnt 与主循环清零存在竞态；point_cnt 是 IRQ 数而非已处理峰之间的可靠时间戳。
5. **SPI 错误没有完整传播。** 单字节 HAL 调用使用长超时且忽略返回值，ISR 故障路径可能阻塞；芯片 ID 不符时初始化循环没有有界退出。
6. **没有呼吸率验收链路。** B 波形有起伏，并不等于完成了呼吸率计算或精度验证。

关键定位：main.c 第 343–345、383–431、441–448 行；exti.c 第 82–100 行；ads1292.c 第 111–121 行。以上为静态风险，未声称本轮在该示例上复现了丢样或崩溃。

补充观察：

- 第二轮 −407 万码的极值在约 **0.020 秒**，低于 −100 万码的 73 个样本集中在前约 0.36 秒。它是启动段大幅瞬态，**不能描述成全程持续 −407 万码偏置**。30 秒后的均值仅约 −49,492 码，但仍有非常强的周期波动。

**判断：** CSV 连续性好于早期问题状态，但本轮不是已通过的标准 ECG／呼吸输入。约 50 Hz 及其谐波与工频干扰相符，也可能来自模拟源或共同耦合；仅凭 CSV 不能在连线、模块和模拟源之间作唯一归因。

第二轮心率有 31,424 帧为 reason=66，占约 84.54%。66=64 `MAINS` +2 `NO_CYCLES`。结束时算法自身的干扰估计为 ECG 0.987809、呼吸 0.969051。这个在线指数功率估计与第 5 节的 Welch 带功率口径不同，不能拿两个百分比直接判一致或矛盾。MAINS 原因也可能保留到新的周期资格建立，而非每一帧即时频谱判断。

本次只运行逐帧 API，没有第二轮实机 getter／主循环调用时序或 RAM 状态。因此它回答的是“这些原始输入喂给冻结算法会怎样”，不宣称精确重建了第二轮 ARM 的全部时序行为。

同时进行了当前示例 FIR 的数学滤波对照：完整均匀输入、offset-binary 数值、相同系数，使用双精度 `lfilter`。**未执行它有未初始化状态的 BPM 逻辑，未模拟 ISR 丢帧和周期 LOFF 跳帧，也不冒充 CMSIS 单精度实机输出。** 图中可看到 FIR 压低了高频波动，但仍有通带内周期成分和呼吸基线变化。

## 7. 根因范围与下一步

| 事项 | 当前证据允许的判断 |
|---|---|
| 采集调度／缓存再次丢样 | 本 CSV 未见序号或时序缺口，不是本轮首要证据；底层仍需原始快照核验 |
| START／DRDY 周期异常 | 本 CSV IRQ 间隔稳定，未复现严重周期异常 |
| 数值转换错误 | 两路值处于合法有符号 24 位范围；CSV 本身不显示整体顶轨；缺原始字节，不能最终核验转换 |
| 模拟源／接触／共模问题 | 原始波形显著变化、强共同 50/100 Hz，是优先核查方向；尚无唯一根因 |
| 当前算法对强干扰的局限 | 已确认多数时段不能建立可靠新鲜周期；约 25 Hz 与偏离中心的干扰仍可能留在滤波输出 |
| 当前示例是否更准 | 没有同输入、同配置、已知真值的完整算法对照，不能判定 |
| 传感器是否损坏 | 现有证据不能认定 |

建议后续先保留当前采集链路和原始证据，使用有明确设定值的主动 ECG／呼吸阻抗模拟源建立参考。若设备不能提供已知输出，只能继续作工程质量观察，不能验收率值精度。

可区分原因的对照项目：模块内部短接／内部测试信号、已知 ECG 差分输入、明确的呼吸阻抗变化；固定固件、寄存器、接线和采集时长，每轮只改变一个因素。应记录模拟器型号、设定值、是否支持阻抗输出、实际接线、完整 session/raw/设备状态及固件 SHA。

拿到受控输入后，优先检查 50/100 Hz 及约 25 Hz 的来源和幅度，再评估陷波带宽／中心频率、抗基线阶跃和峰值资格的调整。不能为得到“范围内数字”关闭质量判据，也不建议退回示例的单 flag 采集结构。本轮只提出方案，没有启动任何硬件操作。
