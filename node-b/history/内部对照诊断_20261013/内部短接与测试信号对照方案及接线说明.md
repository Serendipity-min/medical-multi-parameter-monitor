# ADS1292R 内部短接与内部测试信号对照方案

日期：2026-10-13。状态：**脱机准备完成，真机测试尚未执行。**

## 1. 目的与范围

先检查芯片转换、SPI读取和连续采集是否正常，再判断外部电极／模拟源／RLD链路是否引入干扰。A/B两模式使用完全相同的最小采集程序，仅 CONFIG2、CH1SET、CH2SET 不同。

本次新建独立诊断目录，未修改 BIO_V2 或原生产工程。保留原始9字节帧、24字节队列记录、IRQ序号／DWT／毫秒时间戳与驱动错误计数；不滤波、不计算心率或呼吸率、不启用屏幕、USART、CAN和以太网任务。因此本轮结果不能代替完整任务下的调度验证。

本轮不连接硬件、不烧录；待开发板连接并开始测试后执行以下步骤。两模式均要求外部电极、探头与模拟器从模块模拟输入接口拔下，不连接真人。**内部短接由芯片MUX完成，不需要用导线短接模块电极、电源或GPIO。**

## 2. 接线：START 接 PG15

| 模块丝印／功能 | STM32F407ZGT6 引脚 | 信号方向 |
|---|---|---|
| PW／PWDN | PA0 | MCU → 模块，复位／掉电控制 |
| START | **PG15** | MCU → 模块，启动转换 |
| CS | PA2 | MCU → 模块，片选 |
| DR／DRDY | PA3 | 模块 → MCU，数据就绪 |
| SCLK／SLCK | PA5 | MCU → 模块，SPI时钟 |
| IN／DIN | **PA7** | MCU → 模块，SPI数据输入 |
| OUT／DOUT | **PA6** | 模块 → MCU，SPI数据输出 |
| +5V | 开发板提供的稳定5V | 模块供电输入 |
| GND | 开发板GND | 公共参考 |

模块原理图的 J2 接口：5脚PWDN、6脚START、8脚CS、9脚DIN、10脚SCLK、11脚DOUT、12脚DRDY；1/2脚为5V，3/4脚为GND。**实物按丝印确认方向，不凭排针朝向猜编号。**

- 将旧 START→PA1 的线完全移除，不能同时接 PA1、PG15。
- PA2/PA3 与板载串口／RS485之间的跳帽保持断开；不要让其它外设同时驱动这两个脚。
- BOOT0=0；维持目前 BOOT1=0 的正常Flash启动连接。
- J-Link使用板上SWD接口：SWDIO=PA13、SWCLK=PA14、GND共地、VTref接目标3.3V参考；有NRST时接板上复位端。VTref不是模块5V输入。
- 本诊断不使用USART采样。USB串口号可以记录，但不需要改接PA9/PA10；原始数据通过J-Link/SWD读取。
- 电源端子与排针按原理图选择一路供电，不并接两个独立5V电源。

### 内部时钟与 J3

用户提供的模块原理图为V2.0，标明默认内部时钟：R16将CLKSEL上拉至DVDD_3V3，J3连接CLKSEL与GND。**该原理图对应的J3开路选择内部时钟，短接选择外部时钟。**

本方案使用名义512kHz内部时钟：J3保持开路，CLK不连接PA8或其它外部时钟，GPIO1/GPIO2不接额外信号。若实物没有可辨认的J3，保持现状并记录照片，不短接未知焊盘；版本不一致时先核实。

TI手册说明 CLKSEL=1 选择内部时钟、=0选择外部时钟。原理图接线与芯片引脚定义分别核验，不能把旧讨论中的“J3短接”当成本轮内部时钟要求。[TI ADS1292R数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)

## 3. A/B寄存器配置

| 地址／寄存器 | A：SHORT内部短接 | B：TEST内部方波 |
|---|---:|---:|
| 01 CONFIG1 | 01 | 01 |
| 02 CONFIG2 | E0 | E3 |
| 03 LOFF | F0 | F0 |
| 04 CH1SET | 41 | 45 |
| 05 CH2SET | 41 | 45 |
| 06 RLD_SENS | C0 | C0 |
| 07 LOFF_SENS | 00 | 00 |
| 09 RESP1 | 02 | 02 |
| 0A RESP2 | 03 | 03 |
| 0B GPIO | 0C，高两位回读核验 | 同左 |

两路均为增益4、250SPS；关闭呼吸调制／解调、外部RLD驱动和导联激励。A选择MUX=0001内部短接；B选择MUX=0101内部测试源，INT_TEST=1、TEST_FREQ=1。测试源是约1Hz方波，不是心电波形，也不应据此输出“心率60”。

TI给出的内部测试幅值为±VREF/2400。按增益4换算，理想ADC高低电平相对中心约±13,981码、峰峰值约27,962码；直流偏置、增益误差、噪声及边沿转换过程应另行记录。[TI ADS1292R数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)

### 本次发现并隔离处理的SPI时序风险

原采集副本名义SCLK为84MHz/64=1.3125MHz。TI手册§8.3.7说明寄存器读写SCLK至多为2fCLK；512kHz内部时钟时约为1.024MHz。**诊断副本统一改用/128=656.25kHz**，同时保留有界收发、10μs命令间隔／CS保持。原工程没有改动。

该发现提示原初始化存在潜在时序风险，不等于已经证明第二轮异常由此导致；成功回读也不能消除超规格使用的疑问。A/B采用同一安全时钟，避免寄存器配置失效影响对照。[TI ADS1292R数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)

## 5. 开发板连接后的执行顺序

1. 拍照记录上述接线、模块版本、J3状态、供电和SWD连接；确认外部模拟输入接口已拔下。
2. 核验F407家族与UID。当前准备资料绑定历史板卡 `<DEVICE_UID_REDACTED>`；不一致则停止，重新核实目标身份。
3. 当轮原Flash全1MiB双读，核对长度／SHA及两份内容完全一致，保存本轮恢复原件。不能用历史Flash代替当前板上其它测试程序。
4. 安装精确SHORT BIN；VerifyBin后独立回读并核验BIN、全片SHA及扇区变更范围。记录安装操作日志和 `INSTALL_VERIFIED` 回执，引用真实恢复原件。
5. SHORT采集35秒：启动延迟原件保留，分析排除首5秒，要求至少25秒有效分析跨度。每约0.1秒读3072字节原始队列，周期读取公开状态；结尾一次HALT、确认后读取128KiB RAM、恢复运行并确认。
6. 检查ID、实际寄存器回读、flags、驱动错误、序号和导出覆盖。身份／寄存器／协议错误先停止排查；噪声异常如实记录，可用下一模式帮助定位，不能改写为PASS。
7. 同样安装并核验精确TEST BIN，采用相同采集时长、工具和供电接线。
8. 完整恢复第3步的原Flash，VerifyBin并独立全片回读，要求恢复SHA与本轮原件完全相同；记录最终运行状态。若无法确保恢复或Flash双读不一致，立即停止，不继续扩大测试。

没有冷断电、真实assert注入、Broker故障、安全扫描、H16或长期soak。A/B准备的每轮采集35秒，共70秒采集；安装、核验和恢复另计。

采集脚本不会烧录，默认只显示计划。实际执行需要 `--execute --confirm-no-human --mode SHORT/TEST --installed-receipt <本轮安装回执>`；回执必须含精确BIN、UID、全片SHA及可复核恢复原件。连接开发板本身不触发任何脚本。

## 7. 如何解释结果

- SHORT和TEST均正常：支持最小任务下芯片内部转换／读取正常；下一步检查外部输入、模拟源、接触和RLD路径。不能因此证明外部通道映射、完整任务调度或人体测量正确。
- SHORT也有强50/25Hz或尖峰：优先检查模块供电／参考、数字耦合、时钟与读取链路；短接旁路外部输入，不直接归因于模拟器。
- SHORT正常，TEST周期／幅值异常：优先核验CONFIG2、MUX、时钟和补码／帧读取；不改心率算法掩盖异常。
- 两者有序号缺口／SPI错误：先修复通信和采集，暂不评价波形或率值。
