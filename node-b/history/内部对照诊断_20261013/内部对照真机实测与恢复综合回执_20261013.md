## 1. 本轮结论

- **内部短接复采与内部测试方波均通过预先冻结的工程筛查。** 最小任务、低速SPI配置下，连续转换、双通道读取、补码解析和队列交付工作正常；实际寄存器回读与A/B配置一致。
- **修复了一项真实的主机采集工具问题。** 首次SHORT采集出现2.125秒主机轮询停顿，造成481帧原始观察缺失；板端驱动未报告丢样。失败数据与报告完整保留，修复后复采验证。
- **内部短接仍有可测50Hz底噪。** 通过本轮宽松工程筛查不等于达到器件本底噪声规格，也不证明整个模拟链路完全正常。
- 本轮没有测心率／呼吸率精度。外部输入、RLD、呼吸调制和完整业务任务未在本轮验收；原有强50/100Hz与约25Hz成分尚不能唯一归因。

修复仅将分析依赖加载移到J-Link连接／复位启动之前；采集模式、帧结构、固件与判据未改。普通Host回归48/48通过。复采最大主机等待降为0.204秒，TEST为0.203秒，最终完整重建所有已捕获帧。

由于外部输入已拔下、芯片MUX内部短接，至少这部分工频底噪不能只解释成模拟器输出或电极接触。供电／参考、公共地、USB/J-Link连接路径、板上耦合等仍需区分。当前数据不能指出其中某一条路径，也不能凭RMS量级认定模块损坏。

## 7. 本轮收窄了哪些原因

| 原因方向 | 本轮允许的结论 |
|---|---|
| 主机采集工具停顿 | 已复现、定位并修复一次首次加载依赖的停顿；不证明此前外部数据的所有问题同源 |
| 最小任务采集调度／缓存 | 两轮通过数据无错误和缺口，支持该配置下正常；不替代完整任务验证 |
| START／DRDY严重异常 | 本轮未复现，周期稳定 |
| ADC内部转换／补码／双通道读取 | 已知内部方波正确，支持链路基本工作；外部通道映射仍需外部输入验证 |
| 共同工频干扰 | 内部短接也有残余，说明需要继续查公共路径，不能全部归因于外部输入 |
| 原外部输入约25Hz强成分 | SHORT该频段很小；由于外部源、RLD和RESP被同时旁路／关闭，来源仍未唯一定位 |
| 原完整算法、RLD、呼吸阻抗与模拟源适配 | 未验收 |

下一步建议保持同一最小采集框架和安全SPI时序，接入已知心率／幅值的**非人体主动ECG模拟器**，先单独验证ECG输入；随后逐项检查RLD连接／状态与呼吸调制，避免一次改变多个因素。若缺少已知输入，继续只能做质量表征。本轮没有开始这些追加硬件测试，也没有修改生产算法来制造有效数值。
