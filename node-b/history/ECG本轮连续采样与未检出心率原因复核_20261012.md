日期：2026-10-12（Asia/Shanghai）。范围：一次短采集、固件回读及既有数据离线分析。

## 1. 来源更正与执行边界

**本轮实际来源为人体。** 启动时用户称为模拟人体/模拟真实人体信号，执行据此按模拟源台架准备；采集和普通固件切回完成后，用户澄清贴片实际贴在本人身上。启动阶段的 session/hardware 回执和目录名称保留不覆盖，并以 `input_provenance_correction.json` 补充真实来源。不能把本轮报告标为“假人通过”。

## 2. 综合结论

1. **本轮连续性及数字传输检查通过。** 保存了连续 2500 点，约 10 秒，没有序号缺口、异常 STATUS、SPI 错误或队列溢出；此前的缓存导出缺口没有在新记录方式下复现。
2. **心电功能验收未通过。** 算法与 UI 的有效心率标志为 0，呼吸率也无有效值。数值 0 表示“算法没有有效输出”，不能解读为受测者生理心率为 0。
3. **确认了此次未判拍的直接软件机制：** 学习期信号极大值设定的门限下界高于之后出现的全部判拍积分峰值；首次判拍前缺少信号水平下调路径，回搜也尚不能启动。这解释了为什么持续运行仍然没有有效 BPM。
4. **原始心电另有明显约 50 Hz 成分。** 当前不能把全部异常归结为芯片损坏、接线错误或某个单一滤波参数，也不能保证降低门限就能得到正确心率。干扰来源、可信 QRS 与阈值恢复必须分别核查。

## 5. 干扰与未判拍机制

### 5.1 约 50 Hz 成分：实测，不定性来源

对完整 CH2 数据进行 Welch 功率谱分析，1024 点窗、去线性趋势、以 DWT 推算采样频率：最强谱峰约 50 Hz（网格 49.998 Hz，分辨率约 0.244 Hz）。49～51 Hz 占 0.5～100 Hz 分析功率约 **73.96%**。

以常数、线性趋势、50 Hz 正余弦对时戳拟合，50 Hz 正弦幅值约 16954 码。该频谱比例不是临床信噪比，不能据此证明某条导线或供电就是唯一来源。

固件滤波后范围 −3062～2244。波形包含重复的负向候选脉冲；这说明不宜简单把所有数据称为全无效，但本轮没有独立参考 ECG，不能将候选脉冲直接认证为 R 波。呼吸通道没有足够可靠周期及有效 rate 输出，呼吸功能未通过。

### 5.2 无有效 BPM 的直接机制：有源码及 RAM 证据

当前 `pan_tompkins.c`：

- 293～301 行：学习结束后，以 `s_learn_max` 或噪声下限设置 `s_signal_level`。
- 312～316 行：`threshold=max(0.25*signal+0.75*noise, 8*noise, floor)`。
- 344 行：候选积分峰值必须大于该阈值才允许受理。
- 367～368 行：search-back 需要已经有首拍且 RR 数量≥2。
- 403 行：学习结束后的 `s_signal_level` 仅在已受理心拍时更新，尚未获得首拍时没有下调路径。

因为没有首拍，window peak 没有因受理心拍而清空，signal level 也仍等于学习极大值；之后的最高积分峰值还低于固定阈值下界，**局部峰接受条件无法成立，search-back 的前提也无法满足**。这就是本轮始终检不出 BPM 的直接机制。当前 despike 没有处于抑制状态，不支持继续把现象称为此前的伪迹抑制锁死。

由记录的真实固件滤波输出重建微分平方/38 点积分，最大约 1.7035347×10⁻⁷，与 RAM 中真实最大值接近；重建有整数输出量化及起始历史缺失，判定仍以原始 RAM/源码为依据。

**边界：** 本轮未保存前 6 秒原始波形，无法证明学习期较大的值究竟来自启动过渡、干扰还是某个真实输入。没有独立参考 QRS，不能证明每一个被拒绝的峰都应该接受。已确认的是当前首拍获取策略在这组输入下没有恢复路径，尚不是完整的“唯一根因已闭合”。

## 6. 后续修复与剩余项

优先做纯离线的首拍获取恢复设计及负向测试：覆盖学习阶段幅值较高、后续较低、持续噪声、无输入、真 QRS、混合干扰和恢复。候选策略应有超时、有限再学习/受控信号水平衰减、独立噪声闸门，不能只靠降低全局门限来得到一个看似合理的数字。本轮没有应用这些算法改动。

约 50 Hz 干扰的排查仍需经过保护条件核验后的合适测试环境，或脱离人体的已知电压信号/合格心电模拟器，分离电极/导联/RLD、供电和外接地路径。没有在人体连接状态下指导或执行改线、切换参考端或进一步调寄存器。
