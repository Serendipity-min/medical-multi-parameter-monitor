## 2. 最小修复

旧逻辑在学习期结束时用学习期极大值设置 SPKI，之后只有接受心拍才更新 SPKI。若初期幅值较高、后来降低，首拍可能永远达不到门限，回搜也因没有首拍/RR而无法启动。

新逻辑仅在 `s_have_beat==0` 时，按采集时戳维护一个 **2000 ms 观察窗**。完整窗口结束后，将过期 SPKI 向近期积分峰值与原有噪声下限的较大者下调；不会在每点持续急降，也不会因主循环排队消费改变窗口时间。uint32 无符号时间差支持回绕，输入失效/重新初始化时清除恢复窗口状态。

保留原有 `8×noise` 闸门、绝对底限、局部极大值判定、不应期、T 波判断、至少三个有效 RR 和超时撤销逻辑。窗口峰值不会被直接当成心拍，也不重置 FIR 来制造峰值。获得首拍后，原有判拍更新路径继续运行。

本轮未调整中值/伪迹门限、FIR 系数、显示倍率、采样率、SPI、PG15 START、CAN、屏幕协议或呼吸算法。新增状态仅 `uint32_t` 时戳与 `float` 峰值，普通固件增加 RAM **8 B**。

## 3. 普通 Host 证据

测试采用生产 FIR 系数、float32 单点 FIR 数学实现及实际生产 Pan-Tompkins C 代码，不等同于 ARM 上的 CMSIS 优化实现或临床验证。固定夹具、随机种子、编译命令和旧/新源码身份均归档。

| 场景 | 旧版 | 修复版 |
|---|---|---|
| 正常 60 / 90、负向 60 脉冲 | 有效；输出 60 / 89 / 60 | 与旧版完整结果相同 |
| 高幅值启动→稳定 60 | 20 秒虚拟输入均无有效值 | 首次有效 7508 ms，最终 60 |
| 高幅值启动→稳定 90 | 均无有效值 | 首次有效 8508 ms，最终 89 |
| 高幅值启动→更小幅值 60 | 均无有效值 | 首次有效 7508 ms，最终 60 |
| 高幅值启动并跨毫秒回绕 | 均无有效值 | 与直接 60 场景一致 |
| 已知 QRS 脉冲叠加 50 Hz | 均无有效值 | 首次有效 7508 ms，最终 60 |
| 零、直流、纯 50 Hz、纯 10 Hz、慢漂移、固定种子噪声、启动大幅值后噪声 | 全程无有效 BPM | 全程无有效 BPM |
| 断流尾段、恢复、显式 200 ms 输入缺口 | 原首拍故障阻止恢复 | 尾段无有效值；恢复检出；缺口后撤销旧值 |
| 25 点批量消费 | 均无有效值 | 首次有效时刻及最终值与直接消费一致 |

这些数值来自虚拟时间夹具；不是受测者心率。90 输入产生 89 是当前 4 ms 时戳/RR取整数条件下的已有结果，测试采用 ±1 容差，没有修改心率输出校准。

原有 8 项时戳回归重新编译旧/新当前输入，均输出：

```text
checks=8 failures=0 direct_hr=60 direct_rr=15 hash=d44467a881e07813
```

旧 R2 回执的滤波 Hash不同，因为当前工程此前已由 Gemini 将输出倍率提高 10 倍；本轮比较的是同一 R4 输入身份的旧/新算法，而非把 R2 输出冒充当前基线。

## 4. 既有人体数据的限定回放

以 R4 记录的固件滤波值作为输入，从其末端 RAM 的 SPKI/NPKI 播种，分别运行旧/新实际 C 阈值路径。原始前 6 秒/学习期和完整初始状态未保存，所以该回放只作为相同播种条件下的差分，不能声称完整重演了原试验时间线；也不是原始 ADC→中值→伪迹→FIR 全链路重放。

| 项目 | 旧版 | 修复版 |
|---|---:|---:|
| 输入点数 | 2500 | 2500 |
| 结束 SPKI | 7.1477706×10⁻⁷ | 8.6910440×10⁻⁸ |
| 结束 NPKI | 2.1483217×10⁻⁸ | 2.1483217×10⁻⁸ |
| 有效 BPM 点数 | 0 | 0 |

陈旧 SPKI 的高门限已经能够恢复，但该噪声数据仍被原有噪声闸门拒绝，状态为 **PARTIAL / 未取得有效 BPM**。没有降低 `PT_SNR_GATE=8` 来追求显示数字，也没有将这个结果标记为人体功能 PASS。

这说明后续仍需处理信号质量和独立 QRS 对照。约 50 Hz 成分的来源、导联/参考端/供电完整条件，以及呼吸功能仍为剩余项。
