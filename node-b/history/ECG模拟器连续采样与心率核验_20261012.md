# ECG 模拟器连续采样与心率核验回执（R6）

日期：2026-10-12（Asia/Shanghai）。输入来源：**专用模拟器，经用户明确确认为非真人**。

本轮范围为一次受控连续采样、固件 RAM 状态核验与离线分析。相对于 R1–R5 的直接目的：
把 R4 那轮"来源被澄清为人体"造成的证据缺口补上，用非人体源重新检验"设备能否把
一路正常量级的心电信号变成可用心率"。

---

## 1. 结论与当前状态

**采集链路与器件身份全部通过；设备仍未输出可用心率；输入侧信号质量不合格。**

1. **连续性为历轮最好**：连续 2500 点、序号缺口 0、非法 STATUS 0、flag 非零 0、
   队列溢出 0、长间隔 0；IRQ 间隔 4003.52 / 4003.77 / 4004.06 μs。
2. **器件身份与起点干净**：UID `<DEVICE_UID_REDACTED>`、DBGMCU IDCODE
   `0x10076413`、Flash 1024 KiB；采集前板上镜像 SHA-256 与 R5 结束状态**完全一致**；
   本轮"普通固件"由当前源码重建后与 R5 记录的 BIN **逐字节相同**。
3. **R5 首拍恢复修复确实生效，但不够**：`s_have_beat = 1`（R4 那轮为 0），死锁已被
   打破；然而 `s_rr_count = 0`、算法与 UI 的 BPM/RPM 有效位均为 0，
   `s_quality = 51`。设备端仍无可用心率。
4. **未判拍的直接机制已定位到 RAM 级**：阈值被 `8 × 噪声` 闸门主导
   （3.131×10⁻⁷），而学习以来出现的最大积分峰值只有 3.422×10⁻⁷，
   **仅高出 9.3%**。绝大多数拍仍被拒，凑不满有效 RR。
5. **输入侧信号质量不合格**：工频（50 Hz 及谐波）占总方差 **81.76%**，
   比 R4 人体那轮的 73.96% **更差**；扣除工频后的残差里仍有 **59.69% 的能量在 15 Hz 以上**。
6. **但底层确实存在一路正常量级的心律成分**：两个互相独立的频域方法
   （零填充高分辨率谱 73.745 BPM、自相关 73.822 BPM）**相差仅 0.077 BPM**，
   基准周期 0.8128 s；时域 13 个间隔中 8 个落在该周期的 ±10% 内。
   73.8 BPM 落在成人静息心率正常范围。

**因此对本轮问题的直接回答是：数据里"有心律成分、且量级正常"，但设备"测不出可用心率"，
且信号质量不合格——不能判为符合正常人体指标，也不能判为验收通过。**

## 6. 固件输出与未判拍的 RAM 级机制

固件自身在停机时刻的状态（RAM 直接读取，非推算）：

| 字段 | 值 |
| --- | ---: |
| `s_bpm` / `s_bpm_valid` | 0 / **0** |
| `s_rpm` / `s_rpm_valid` | 0 / **0** |
| `s_quality` | 51 |
| `s_have_beat` | **1** |
| `s_rr_count` | 0 |
| `s_last_beat_ms` | 0 |
| `s_learn_max` | 2.0567698×10⁻⁷ |
| `s_signal_level` | 1.6319754×10⁻⁷ |
| `s_noise_level` | 3.9134029×10⁻⁸ |
| 学习以来最大积分峰值 `s_window_peak_val` | 3.4219377×10⁻⁷ |
| `s_sp_n`（伪迹抑制状态） | 0（未处于抑制） |

按源码阈值公式复算：

```text
threshold = max( noise + 0.25×(signal − noise),  8×noise,  1e-12 )
          = max( 7.015×10⁻⁸,  3.1307×10⁻⁷,  1e-12 )
          = 3.1307×10⁻⁷        ← 8×噪声闸门主导
学习以来最大积分峰值 = 3.4219×10⁻⁷
超出阈值仅 9.3%
```

**结论与边界（不越界表述）**

- 可确认：R5 的首拍恢复路径已经生效（`s_have_beat` 由 0 变 1，死锁打破）；
  当前门限由 `8 × 噪声` 闸门主导，而实际最大积分峰值只比它高 9.3%，
  因此只有极少数拍被受理，`s_rr_count` 停在 0，BPM 无法转为有效。
- 可确认：`s_sp_n = 0`，**不支持**再把现象称为"伪迹抑制锁死"。
- **不能确认**：噪声水平之所以偏高，是干扰耦合进带通后的结果，还是信号本身幅度偏低。
  仅凭一份 RAM 快照无法把这两者分开，本轮不作断言。

## 7. 离线独立判定（含判据自我更正链）

### 7.1 频域主估计

| 方法 | 结果 |
| --- | ---: |
| 零填充高分辨率谱（0.7–5 Hz，Hann 主瓣 0.200 Hz 分组） | **1.22908 Hz = 73.745 BPM** |
| 自相关（0.5–15 Hz 带通） | **0.8128 s = 73.822 BPM**（corr 0.401） |
| 两法差异 | **0.077 BPM** |
| 次强可分离谱峰功率比 | 0.337 |

**两个互相独立的方法一致到 0.08 BPM，是支持"存在稳定心律"的最强证据。**

### 7.2 时域一致性

以自相关基周期锁定判峰最小间距后：检出 14 个峰、13 个间隔，
其中 **8 个（61.5%）**落在基准周期 ±10% 内；其余为判峰器自身的双波瓣误判与漏拍。
判据 D 因此**不通过**——时域形态不足以支撑"干净单 QRS"的说法。

### 7.3 判据缺陷的自我更正（必须留档）

第一版自动判据给出 `reliable_single_rhythm_detected = false`。逐条复核后确认该结论由
**我自己的分析脚本四处机械缺陷**造成，而非数据：

| 缺陷 | 现象 | 更正 |
| --- | --- | --- |
| 1 | 0.5002 Hz 峰（功率 0.808）被当作竞争节律 | 该频率正落在分析带下边界 0.5 Hz，是基线漂移/趋势泄漏 |
| 2 | 1.149 / 1.229 / 1.309 Hz 被拆成三个竞争峰 | 去重阈值 0.08 Hz 小于 Hann 主瓣宽度 0.200 Hz，实为同一主瓣结构 |
| 3 | 自相关 1.6415 s 被当作竞争周期 | 它恰为基周期 0.8168 s 的 2 倍，是心搏的二次回波；另有把基周期自身误列为竞争项的代码 bug |
| 4 | 0.5–15 Hz 带内判峰把一拍拍成两拍（中位间隔被压到 480 ms） | 该带内波形每周期有两个波瓣；改为锁定最小间距后再做一致性检验 |

三版判定结果全部保留在同一证据目录（`rhythm_detection_verdict.json`、
`_corrected.json`、`_final.json`），未覆盖任一版本。
**修正的是脚本缺陷，不是放宽判据**——判据 D 修正后仍不通过，就照实写不通过。

### 7.4 呼吸通道

本轮**无呼吸模拟能力**（用户明确说明）。CH1 原始表征：工频拟合幅值仅 226 / 325 / 25 / 33 码，
0.1–1 Hz 主峰 0.4878 Hz（折合 29.3 次/分）。**该数字不作为呼吸率**——
无已知输入、无阻抗模拟、无人体验证，**RESP 功能维持"未验收"**。

## 8. 幅度与形态

按基准周期 812.77 ms 折叠，取与周期一致的 8 拍做集合平均：

| 项目 | 实测 |
| --- | ---: |
| 集合平均峰峰值 | 0.917 mV |
| 主峰半宽 | 20.0 ms |
| 原始直流偏置 | **+11.80 mV** |
| 成人 QRS 典型时限（参考） | 80–120 ms |

- 幅度 0.92 mV 落在模拟器/成人 ECG 的常见量级（典型 1 mV），**量级合理**。
- 主峰半宽 20.0 ms **明显窄于**成人 QRS 的 80–120 ms；结合第 5 节"59.69% 能量在
  15 Hz 以上"，说明折叠后的波形**不是干净的单 QRS 形态**，含大量高频成分。
  半宽是形态描述，**不是临床 QRS 时限测量**。
- 直流偏置 +11.80 mV 相对增益 4 的 ±605 mV 满量程仅 2%，未削顶；
  该偏置来自模拟器输出还是输入网络，本轮未测，不作断言。

## 9. 与 R4 人体轮的对照（本轮新增的有价值推论）

| 项目 | R4（人体，来源事后澄清） | R6（专用模拟器） |
| --- | ---: | ---: |
| 49–51 Hz 占 0.5–100 Hz 功率 | 73.96% | **88.02%**（占总方差 81.76%） |
| 50 Hz 拟合正弦幅值 | 16954 码 | **26319 码** |
| 连续性 | 2500 点通过 | 2500 点通过（抖动更小） |
| `s_have_beat` | 0（首拍死锁） | **1**（R5 修复生效） |
| BPM 有效 | 否 | 仍否 |

**推论：把信号源从人体换成专用模拟器之后，工频干扰不但没有消失，反而更强。**
因此工频干扰**不来自信号源（人体）**，而是由采集侧引入——导联线/接插件、
共地路径、供电或板上耦合。这把 R4/R5 遗留的 `50HZ_SOURCE = OPEN` 从"来源完全未知"
收窄为"来源在采集侧，而非被测对象侧"。

**该推论的边界**：两次采样之间线缆布置与走线是否完全一致未记录，因此"更强"这一
数值比较不能当作严格单变量结论；但"换掉信号源后干扰依旧存在且同量级"这一点，
足以排除"人体本身是干扰源"。

## 11. 剩余项与下一步

1. **必须先处理工频与高频干扰**。工频占总方差 81.76%，>15 Hz 占残差 59.69%，
   在这一状态下任何算法侧调参都是在噪声里找信号。建议按 R3/§6 的既定路径做
   受控对照：同一模拟器输入下，分别改变（每次只改一项）导联屏蔽与走线、
   共地/参考端接法、供电来源、RLD 连接，用同一套记录固件比较 50 Hz 拟合幅值。
2. **噪声闸门口径需要复核**。`PT_SNR_GATE = 8` 在本轮把门限顶到 3.131×10⁻⁷，
   而实际最大积分峰值 3.422×10⁻⁷。这是"采集已修好但算法仍不出数"的直接所在。
   建议在干扰受控后，用已知幅值输入标定 `s_noise_level` 的合理性，
   **不要直接调小闸门去凑一个数字**。
3. **补模拟器的型号与设定值**。给出设定心率/幅值后，本轮这套流水线可直接做
   定量等价验收，届时 `RHYTHM_COMPONENT_PRESENT` 才能升级为 PASS。
4. **呼吸功能仍从未验收**，需要具备呼吸阻抗输出的模拟器。
5. 需外部时基仪器校准 168 MHz 推算的采样率；本轮 249.764 SPS 未用外部仪器标定。
