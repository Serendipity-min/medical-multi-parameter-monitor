# 心率与呼吸同步采集核验回执（R7）

日期：2026-10-12（Asia/Shanghai）。受测对象：**真实人体**（用户确认，自然呼吸，无节拍参考）。
采集时长：**106.451 s 无损连续**。本轮**未改动任何固件、未重新烧录**。

---

## 1. 结论与当前状态

**采集链路做到了历轮最好；但心率和呼吸的固件输出仍然都是无效值，而且本轮第一次把两者的
阻塞机制都定位到了可复算的数值层面。**

1. **采集方法升级（本轮主要工程收获）**：改用"生产固件 + SWD 高速轮询队列槽"，实测
   **106.451 s 序号缺口 0**（26588 帧，seq 1→26588，249.757 SPS），且**从复位那一刻开始记录**，
   因此固件算法初态已知为零，可以做精确重放。**不改固件、不烧录**，测的就是用户实际在跑的镜像。
2. **工频显著改善，验证了 RL 假设**：接上 RA/LA/**RL** 三导联后，CH2 工频功率占比
   由 R6 的 **81.76% 降到 26.76%**（50 Hz 拟合幅值 26314 → 18750 码）。
3. **心率：仍无效**。`bpm_valid=0`、`s_have_beat=0`、`ecg_rr_count=0`。阈值被 `8×噪声`
   闸门主导（6.202×10⁻⁷），而实际达到的最大积分峰值只有 6.237×10⁻⁷——**仅高 0.6%**，
   比 R6 的 9.3% 更紧。
4. **呼吸：仍无效，且机制已定位**。`rpm_valid=0`；106 秒内**只有 1 个间隔落入 1.5–10 s 有效窗**
   （`resp_rr_count=1`，而 `RespRate_Get` 要求 ≥2）。根因见第 7 节：**一阶去直流压不住本通道
   占约 84% 能量的 <0.05 Hz 基线漂移，漂移抬高了判据门限，使其高于呼吸幅度**。
5. **呼吸本轮仍不能判定"准不准"**：用户明确是自然呼吸且无参考值。离线用正确的
   0.1–0.5 Hz 带通能取到一个 **9.2 次/分**的候选，但同一段的自相关主峰却落在 1.0 Hz
   （心电串扰）——**两个口径互相矛盾，故不出具呼吸率结论**。

## 3. 采集方法（本轮方法学）

历轮教训：R3 的 `capture_offline_data.py` 每次另起 J-Link 进程读槽，实测有效周期约 0.75 s，
超过 128 槽队列深度（0.512 s），导致序号覆盖率只有 68.27%，被明确判为"不能声称无损"。

本轮改为**单次 J-Link 会话内连续轮询**，并把轮询周期压到队列深度以下：

| 项目 | 实测 |
| --- | --- |
| 队列语义 | `EcgQueue_Pop` **不清槽**、`Push` 只在满载时拒帧 → 128 槽始终保存最近 128 帧 = 0.512 s |
| 预试轮询周期 | 204 ms（余量 2.51×）；正式采集用 `sleep 100` |
| 正式采集 | 800 次槽快照 + 80 次状态快照 + 收尾全 RAM（128 KiB） |
| 有效帧数 | 26588（丢弃 1576 个开机前未写入的空槽） |
| 序号覆盖 | **1 → 26588，缺口 0** |
| 耗时 | 109.7 s（含 J-Link 启动与收尾） |

**该方法的边界**：若某次轮询周期意外超过 512 ms 就会丢帧——本轮实测缺口为 0，
所以这一风险在本批数据上未发生；但它是**方法固有风险**，换机器/换负载需重新核验。

## 5. 工频：接上 RL 后的改善（对照 R6）

| 项目 | R6（未接 RL） | R7（接了 RA/LA/RL） |
| --- | ---: | ---: |
| CH2 50 Hz 拟合幅值 | 26313.71 码 | **18749.90 码** |
| **CH2 工频占总方差** | **81.76%** | **26.76%** |
| CH1 50 Hz 拟合幅值 | — | 330.04 码 |
| CH1 工频占总方差 | — | 9.41% |

50 Hz 谐波：100 Hz 未单列；CH2 的工频拟合同时扣除了 50/100/150/200 Hz 与线性趋势。

**判定**：接上 RL 使工频功率占比降到约 1/3，**支持"RL/共模回路是工频主因"这一判断**。
但 26.76% 仍然偏高，**不是可以忽略的量级**；且 R6 与本轮的线缆布置是否完全一致未记录，
所以"降了 3 倍"不作严格单变量结论，只作方向性证据。

**新发现（未查明，不作断言）**：**CH2 与 CH1 都在 ~7.6–8 Hz 有明显成分**
（CH2 该频段谱主峰 7.59 Hz，相对功率 1.0）。该成分同时出现在两个通道，说明它更可能来自
前端/电极界面而非某一通道；候选方向包括肌电/抖动、RESP 调制解调相关伪迹、混叠来源，
**本轮没有证据区分，不做定性**。

## 6. 心率

### 6.1 固件输出（RAM 直接读取）

| 字段 | 值 |
| --- | ---: |
| `s_bpm` / `s_bpm_valid` | 0 / **0** |
| Pan-Tompkins 侧 `s_bpm` / valid | 0 / **0** |
| `s_quality` | 98 |
| `s_have_beat` | **0** |
| `s_rr_count` | 0 |
| `s_signal_level` | 2.6127×10⁻⁷ |
| `s_noise_level` | 7.7531×10⁻⁸ |
| **`8×noise` 闸门** | **6.2025×10⁻⁷** |
| 学习以来最大积分峰值 | 6.2367×10⁻⁷ |
| 超出闸门 | **仅 0.6%** |

与 R6 相比余量更紧（R6 为 9.3%）。机制与 R6 相同：**阈值由 `8×噪声` 闸门主导，而实际
峰值刚好贴着它**，导致几乎无拍被受理，`rr_count` 无法累积。

可确认：`s_have_beat=0` 说明本轮 R5 的首拍恢复路径**处于激活状态但未成功**——
它在等一个能过闸门的峰。**不能确认**噪声水平偏高的成因（是干扰耦合进带通，还是信号
本身幅度偏低）——单份 RAM 快照无法分离。

### 6.2 离线独立口径

| 方法 | 结果 |
| --- | --- |
| 谱峰（0.7–8 Hz，扣工频后） | 主峰 **7.5915 Hz（455.5 次/分）** 相对功率 1.0；次峰 7.957 Hz；**心电候选 1.189 Hz（71.3 次/分）相对功率 0.455** |
| 自相关（0.5–15 Hz 带通） | 0.7928 s → **75.68 次/分**，相关系数 **0.270** |
| 时域一致性（周期锁定后） | 检出 159 峰，落在参考周期 ±10% 内仅 **15.8%** |

**判定**：心电候选在 ~71–76 次/分（属正常成人范围）是存在的，但**被 ~7.6 Hz 成分压过，
且时域一致性只有 15.8%**。因此**本轮不能给出可信心率**，也不能据此判算法对错。

## 7. 呼吸（本轮重点）

### 7.1 固件输出

| 字段 | 值 |
| --- | ---: |
| `s_rpm` / `s_rpm_valid` | 0 / **0** |
| `resp_have_peak` | 1 |
| **`resp_rr_count`** | **1**（`RespRate_Get` 要求 ≥2） |
| `resp_rate[0]` | 25（来自一个 2400 ms 的有效间隔） |
| `resp_last_peak_ms` | 106021 |
| `resp_peak_level` / `resp_noise_level` | 4.271×10⁻⁴ / 1.891×10⁻⁴ |

### 7.2 精确重放与它的边界

本轮从 seq=1（复位）开始采集，固件算法初态已知为零，因此可用源码同一套 EMA 与判峰判据重放。

| 项目 | 结果 |
| --- | --- |
| 离散状态（`have_peak` / `rr_count` / `rate[0]`） | **与固件完全一致**（1 / 1 / 25） |
| 浮点末值 | `dc` 差 9.78×10⁻⁵、`lowpass` 差 8.53×10⁻⁵、`peak_level` 差 6.31×10⁻⁵、`noise_level` 差 5.97×10⁻⁷ |
| 换用 `np.float32` 逐点模拟 | 差异**未消除** |

**如实记录**：即使改用单精度逐点模拟，浮点末值仍有 ~10⁻⁴ 量级差异，本轮**未能闭合其来源**
（编译器求值顺序、FPU 模式、或我未发现的其它调用路径均未排除）。因此：
**重放的离散结果可作为算法理解的验证；重放的浮点轨迹与峰序列只作定性证据，不作精确峰清单。**

### 7.3 频带分解：呼吸到底在不在 CH1 里

CH1（扣工频后，0.03–40 Hz 归一）：

| 频带 | 等效呼吸率 | 功率占比 |
| --- | --- | ---: |
| **< 0.05 Hz** | < 3 次/分 | **≈ 84%（基线漂移）** |
| 0.05–0.1 Hz | 3–6 | 8.04% |
| 0.1–0.15 Hz | 6–9 | 4.70% |
| 0.15–0.2 Hz | 9–12 | 0.70% |
| 0.2–0.3 Hz | 12–18 | 1.24% |
| 0.3–0.5 Hz | 18–30 | 0.49% |
| 0.5–1.0 Hz | 30–60 | 0.37% |
| 1–5 Hz | 60–300 | 0.32% |
| 5–40 Hz | — | 0.16% |

**正常呼吸所在的 0.15–0.5 Hz（9–30 次/分）只占 2.43%。** 同一分解用在固件
`s_lowpass` 上：<0.05 Hz 仍占 **≈ 77%**。

### 7.4 根因（可复算）

**两个叠加的缺陷：**

**① 一阶去直流压不住漂移。** `RESP_DC_ALPHA = 0.002` 在 250 SPS 下 τ≈2 s、−3dB 约 0.08 Hz。
对本通道里占约 84% 能量的 <0.05 Hz 漂移，一阶高通只衰减十几 dB，**漂移几乎原样进入
`s_lowpass`**，把 `s_peak_level` 抬高。

**② 判据因此升到呼吸幅度之上。** 判据等价于 `s_prev1 > 0.35·peak + 0.65·noise`：

| 量 | 实测（后半段中位数） |
| --- | ---: |
| \|`s_lowpass`\| | 1.341×10⁻⁴ |
| 判据门限 | **2.670×10⁻⁴** |
| peak/noise 比 | **1.93** |

**典型样本连门限的一半都不到。** 算法的 0.35/0.65 加权隐含假设"包络峰值远高于噪声基线"，
而实测 peak/noise 只有 1.93，门限正好落在信号分布中部。

**③ 开机瞬态进一步毒化包络。** `s_peak_level` 在约 5 s 时冲到 **5.05×10⁻²**（`s_lowpass`
最大 4.30×10⁻²），而下降 α=0.001（τ≈4 s）使包络**用了约 90 秒**才衰减到 10⁻⁴ 量级——
在这 90 秒里门限比呼吸幅度高两个数量级。时间轨迹显示：5.4 s 时 peak=3.657×10⁻²，
43 s 时仍为 7.19×10⁻⁵ 附近，直到 90 s 后才与呼吸幅度同量级。

**后果**：106 秒内固件只认可了约 10 个峰（下界，快照 1.35 s 一个），峰间隔大量贴在
**240 ms 的 refractory 下限**（说明数的是高频成分），**只有一个间隔（2400 ms）落入
1.5–10 s 有效窗**；`rr_count` 停在 1 < `RESP_RR_MIN_VALID`(2) → `RespRate_Get` 返回 0。

**已排除的假设**：固件**没有**被反复清零。时间轨迹逐快照检查，`resp_*` 状态无突然归零
（0 次）；采集数据 `flags` 全为 0、`delta_ms` 只有 4/5 ms、`PT_INPUT_GAP_MS=100 ms`
从未触发——即第 383 行的 `RespRate_Init()` 通路**没有**被激活。

### 7.5 离线口径也不能给出可信呼吸率

对 CH1 扣工频后做正确的 0.1–0.5 Hz 带通：13 个峰，中位周期 6.49 s → **9.24 次/分**
（峰峰 18973 码，std 2414 码）。**但同一段的自相关主峰落在 1.0 Hz（60.18 次/分，
corr 0.480）**——这是心电串扰（CH1 与 CH2 共用同一组电极）。

**两个口径互相矛盾，因此本轮不出具呼吸率结论。** 只能说：CH1 里存在幅度可观的
0.1–0.5 Hz 分量，但它与心电串扰混在一起，且固件当前的滤波与判据无法把它变成可用的呼吸率。

## 10. 剩余项与下一步

1. **呼吸：先修"去直流"，不要先调判据比例。** 84% 的能量在 <0.05 Hz，`RESP_DC_ALPHA=0.002`
   （fc≈0.08 Hz）不够。可考虑二阶/更高阶高通、或把 α 降到 0.0005（fc≈0.02 Hz）以下，
   使 0.15–0.5 Hz 的呼吸幅度相对漂移有足够余量。**改完必须用本轮的
   `hr_resp_r7.csv` 离线回放验证**，不要直接上人。
2. **呼吸：开机瞬态需要处理。** 包络上升 α=0.05、下降 α=0.001 使一次 5×10⁻² 的瞬态要
   约 90 秒才能消退。可加"学习期内不判峰"或对包络设上限，避免把瞬态当成呼吸幅度基准。
3. **呼吸：CH1 的心电串扰要量化。** 自相关主峰在 1.0 Hz，说明 CH1 里有心电成分。
   需要判断它来自 ADS1292R 通道间串扰、电极布局还是共模残留。
4. **心率：`PT_SNR_GATE=8` 的口径需要复核。** 两轮实测余量分别只有 9.3% 与 0.6%，
   说明该闸门与真实信号幅度不匹配。**先查 `s_noise_level` 为何偏高**（干扰耦合 vs 幅度偏低），
   再决定是改闸门还是改前端——不要在噪声里调参数。
5. **~7.6 Hz 成分需单独定性**：先做一次"电极离体 / 短接 / 已知源"的对照，把它与生理源分开。
6. **呼吸准确度验收**仍需合格呼吸阻抗模拟器或节拍参考；本轮的自然呼吸数据做不到。
