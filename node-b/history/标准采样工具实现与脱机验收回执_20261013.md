## 5. 当前能力边界

- 当前硬件入口限定非人体台架，并需显式 --execute / --confirm-no-human；不以按钮或声明证明患者保护。
- 仍使用运行中 SWD 重复重建，证据强度有限。真实 Commander V5.12 的交互、实际吞吐、暂停尾段与恢复确认尚待首次短时台架验证。
- BIN/profile 不匹配时停止，不自动烧录。实际采集计划包含一次 reset/go、末端一次 halt/RAM读取及恢复确认，属于会改变执行状态的调试采集。
- 时基为段内名义 ms 时间，原始 DWT/flags/计数保留；不宣称独立测得 ADC 物理边沿。
- 输出基础原始表征、状态和证据；独立参考同步、心率/呼吸准确度自动验收尚未实现。已提供模拟器设定也不伪称完成准确度评估。
- ECAP 连续串口仅为候选协议，当前板端未实现，COM18 不当作已验证原始数据口。

结论：**主机工具与脱机证据已准备好，可以进入负责人选择的首次短时非人体台架试采。尚不能写为新工具真机采集已通过。** 本轮硬件访问、安全扫描和 Git add/commit/push 均未执行。
