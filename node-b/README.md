## 后续成功标准

先以已知幅值和节律的**非人体工程源**证明 CH2 外部输入，再逐项引入 RLD 和呼吸调制，最后用已知变化阻抗检验 CH1。每轮固定源码、固件、输入设定、接线和取数工具，原件只增不改；“数值处于范围内”不构成准确度证明。
