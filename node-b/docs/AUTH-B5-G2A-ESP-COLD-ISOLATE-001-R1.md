## 拟批准的一次电气操作

1. 先结束全部调试/串口会话。若已记录ROM/HALT/身份漂移，必须先保存现场并由负责人明确决定是否允许放弃该现场断电；本附件不隐含批准清除异常。
2. 经单独明确批准后，关闭并断开B/C所有J5/开发板USB电源及J-Link电脑端USB；保持CAN H/L、独立GND、电极、模拟器、BOOT/P4/P6及屏幕连线不变。不按RESET，不移动JTAG板端，不将此操作记为冷启动或CPU根因实验。
3. 确认B/C、模块和屏幕全部熄灭，等待10秒。仅当已辨认P1且ESP-01是可拔插模块时，按原方向平直拔下整只ESP模块，记录方向并妥善保存。若焊接、固定或不能辨认，立即停，不拆焊、不加线、不搬动跳帽。
4. 记录ESP整只8针均已离开P1，且没有其他VCC、EN、USB或串口供电连接；以负责人明确完成事实或可辨认的现场影像作为隔离证据。不得靠UNKNOWN或自动推定填写 `ESP_isolated=true`。
5. 只恢复C原J5与J-Link电脑端USB，JTAG仍在C；B保持断电、C开发板USB保持断开。源/CAN/参考地不改，不发送AT或B5START。此次重新上电后的只读核验须有对应一次性授权；不沿用已消费的当前读回许可，不擅自追加探测。

到此停止。隔离事实合格不等于G2-A获准安装；安装仍须负责人单独批准唯一R2应用卡，并重新绑定实际运行、UID、Flash/options与保护状态。恢复ESP装板/供电也须以后G3电气附件另批。
