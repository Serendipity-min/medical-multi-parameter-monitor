## 新工程判据和分母

每次锚定新BOOT下首个完整性合格原码帧，不等待HR/RR有效才起计；锚点前的初始化证据仍保存。预热[0,45000)ms，评价[45000,165000)ms，165000ms硬停止采集；不延长等待算法恢复。所有硬件/原码完整性错误涵盖预热，不因处于预热而豁免。

为避免1Hz/2Hz分母混用，本提案采用固定120个1s半开时间槽：每槽取最早原生观察，选择只按设备时标、不按valid/率值；空槽计无效，重复/额外观察全部保留并披露冲突。正确且有效槽≥118/120。所有原生有效输出另查HR误差≤2bpm或RR误差≤1/min；任何有效率值超界均ENGINEERING_NOT_PASS，不能用另118个正确槽抵消。2Hz诊断预计240条，须另外完整报告每条valid/value及缺口/时标，不挑快照，也不把分箱称逐样本实时有效性证明。

原ADC 250SPS、RESP 50SPS连续性独立判断：评价段名义30000个ECG采样/6000个RESP点只是规划，实际序号/IRQ ms与cycles/flags/时钟量化/启动代次必须保留，不补点、不倒序、不复制。任何非预期新增丢样、冲突重复、乱序、跨BOOT混接、ADC/队列溢出或原生错误均单独失败；实际计数边缘及晶振容差需在M1工具卡预审时明确，不能把名义采样率等同校准时钟。

RESP组的HR记录实际valid、数值、事件簇、区间上下界/快照分辨率、CH2原码和工频/RESP成分。簇持续时间必须声明由快照还是逐样本回放估计，不能虚构同步逐拍真值。源端无QRS未证实前一律HR_TRUTH_UNKNOWN；RR_RATE_SUBFUNCTION可独立报告，RR整窗不得PASS，不伪造Lead-Off或强置INVALID。

M1只有B独立工程范围，CAN→C→Broker→Backend→WSS传播本轮不执行，不能因B通过把全链签通过。SKX电池/充电USB隔离、B电源/反供电、UTC资格、温度、电量、主机读取耗时/预算等字段实际未证实则UNKNOWN，不能填0。
