## 1. PI 核心裁定

1. **当前可以限定验收**：ECG60、TEMP_OBJECT 的两个独立工程联评 exit 0，以及 RR15 的名义呼吸率和源→CAN→云证据。它们不代表临床测量准确度、绝对电压/阻抗/温度标定或多板并发验收。
2. **不能将 RR15 判为完整 PASS**：既有冻结工况要求 HR `INVALID/null`，但 300 秒评价期 600 次约 2 Hz 的 B 诊断快照中有 20 次 `HR_valid=1`，分布六簇，云端有 10 次非预期 HR。正式 `NOT_PASS/exit_code=3` 不变。
3. **不能立刻认定为算法误报**：BioV2 C 的峰/周期通路已重现全部六簇 HR/valid；50/100Hz、RESP 耦合支持干扰假设。两版 SKX 手册的呼吸章节同时写有心率 60 bpm，RESP 模式是否输出实际 QRS 未获源端独立真值。`SOURCE_UNKNOWN/ROOT_CAUSE_UNRESOLVED` 保持。
4. **先联系厂家核对源定义**。向 SKX-2000D+ 生产/技术方索取针对本机型号、序列号、固件版本的书面答复：RESP15/1.5R/周期30/apnea0 时 RA–LL 与 RA–LA 是否含 ECG/QRS；60 bpm 的定义；能否在 RESP 不变时关闭 ECG；周期30的物理含义；生效菜单与正确负载/导联方式。销售商的其他型号页面不能替代本机确认。
5. **多速率矩阵允许进入离线设计，不授权现场操作**。先复用旧 6 个 ECG60/90/120 工程矩阵和旧 RR12/18/24 六格证据，再为当代 B41012B 设计新的独立矩阵；新采集须单独签发带作用域/时限/次数/工具哈希的执行卡。
6. **三板联动可立刻进行离线规划**，但 A/B/C 物理并发和云端运行须在多工况评审、CAN2 引脚/供电/终端/身份及 C/云资源审查后独立批准。安全扫描门、P5/P6 核心 MQTT 分支整合均不因本合同被自动授权。

## 3. M1：新多速率 B 板独立工程验证矩阵（待现场独立授权）

### 3.1 主矩阵

每格**建议三次相互独立的采集**，覆盖至少两次独立冷启动/重建会话，固定种子或顺序预注册；**不是同一条连续波形切三段冒充三次独立采集**。每次采用 45 秒稳定/预热 + 120 秒有效评价，建议单窗口评价至少 120 个 1Hz 标量或 240 个 2Hz 诊断；如果特定工具无法支持该时长，先调整新工程卡设计，不能改写旧 G3 420 秒硬停或旧 Criteria。

| 组别 | SKX 目标 | 预期功能 | 建议独立重复 | 额外限定 |
|---|---|---|---:|---|
| E60 | ECG 60 bpm | HR60 | 3 | 1mV；原可核定波形类型与导联 |
| E90 | ECG 90 bpm | HR90 | 3 | 与E60一致的波形类型优先；有变化要单列 |
| E120 | ECG 120 bpm | HR120 | 3 | 确认设备是否需“尖角/校准”菜单；不得把不同源波形冒充相同 |
| R12 | RESP 12/min | RR12 | 3 | 1.5R、周期30、apnea0；HR真值暂UNKNOWN |
| R15 | RESP 15/min | RR15 | 3 | 与历史失败分别记录；禁止将本次“无QRS”设成默认真值 |
| R18 | RESP 18/min | RR18 | 3 | 独立源菜单确认 |
| R24 | RESP 24/min | RR24 | 3 | 独立源菜单确认 |
| R30 | RESP 30/min | RR30 | 3 | **主RR=30不等于“波形周期=30”**，两菜单需分别留证 |

设计总计 **8 个目标 × 3 次 = 24 次独立工程采集**，不包含已有历史次数；若进行，每次 45+120 秒，总理论记录/预热时间 66 分钟，不含上电、准备、冷态换线与安全关闭。此为工作量估计，不是现场会话/云租期的获准预算。是否在正式执行时缩减或分批，需执行前一次性冻结；禁止见到结果后只挑通过的次数报告。

**顺序设计**：同一物理接线组内采用不同目标顺序（例如第一轮升序、第二轮降序、第三轮非相邻次序），以识别长时间漂移、首次启动与菜单切换边界。ECG↔RESP 导联切换只在批准的冷态流程下由负责人进行；不得为随机顺序频繁带电插拔、改 J3、增接线或触碰主动 RLD。每一格保留独立 run_id、BOOT epoch、工具/SHA和唯一输出目录，零隐式重试。

### 3.2 工程验收目标（新矩阵预注册指标，不修改旧冻结评测器）

| 维度 | 预登记的建议阈值/处理 | 未满足时 |
|---|---|---|
| ECG HR 量值 | 标量有效时 `|HR - target| ≤ 2 bpm`；有效覆盖建议 ≥118/120 (98.33%) | `ENGINEERING_NOT_PASS`，不删有效差值或调整分母 |
| RESP RR 量值 | 标量有效时 `|RR - target| ≤ 1 /min`；有效覆盖建议 ≥118/120 | `ENGINEERING_NOT_PASS` |
| RR 工况中的 HR | 仍记录真实 `HR_valid`、率值、簇数、持续时间、CH2 原码/工频；在源端无QRS真值前，分类 `HR_TRUTH_UNKNOWN` | **不判 RR15 全工况 PASS**，也不强制把 HR 设INVALID |
| ECG/RESP 连续采集 | ADC 250 SPS、RESP 50 SPS，保留 seq/tick/flags、样本缺口/重复/倒序和 MCU 诊断 | 任意非预期新增缺样/乱序应归因并单独失败 |
| 设备/工具稳定性 | ROM/HALT/Fault/异常 native return、Flash/身份漂移或超时均不得出现 | STOP + 证据留存，不自动恢复/补跑 |
| 有效性传播 | 原 ADC→BioV2→CAN→C→Broker→Backend→WSS 的 value/validity/source/epoch 一致；有标准覆盖的阶段精确核对 | 任何错频道、真值变更、虚假有效或无理由丢失必须失败 |
| 电量、温度、时钟、后台状态 | 记录 SKX 电池/充电USB隔离、板卡电源状态、UTC源/时钟资格、CAN及主机读耗时 | 事实缺失标记UNKNOWN，不伪造0或PASS |

以上比例是**新工程目标**，不是新的国家计量认证阈值。300秒内600条诊断存在时间相关性，不能将600条当作600次独立重复；若零异常，也须以运行会话和事件簇为单位披露统计不确定度。绝对 ECG 电压/RESP 阻抗与温度准确度均需独立校准，不由菜单名或名义换算证明。

### 3.3 扩展负例（主矩阵合格后提请另批）

- **温度补充覆盖（不计入24场主矩阵）**：既有TEMP窗口仅覆盖约25.7–26.0°C桌面物表。建议在具备可溯源温度参考和可控非人体物表后，补“较冷、室温、较暖”三种安全目标、每档至少2次，评价帧格式/CRC、非原子时标、漂移与响应；没有校准参考时只验数据连续性和相对变化，不报绝对精度PASS，不利用热源/人体/高温液体扩大电气风险。
