## 1. 物理工况与接线设计原则

1. **绝对忠实于 R5 现场实测基线**：以 R5 实测现场真实连线为基准，绝不凭空增加 V1 导联、绝不擅自引入“LA 平线接线”、绝不私自串联或并联 100kΩ 接地电阻或修改右腿驱动网络。
2. **严格区分 Lead-Off 与无 QRS 信号**：
   - **Lead-Off（脱落）**：指电极物理断开或接触阻抗超限，ADS1292 芯片内部比较器报硬件脱落；
   - **无 QRS 波形**：指电极物理接触良好、输入回路阻抗闭合，但信号源未输出有效心脏电激动（例如在 RR15 改线后，RA 与 LL 间为纯胸腔呼吸阻抗变化，无心脏去极化电压）。此时 Node-B 算法必须将 HR 正确判定为 `INVALID / null`，严禁通过修改硬件假接地来掩盖算法判定。
3. **隔离供电与非人体环境**：SKX-2000D+ 模拟器全过程采用内置纯电池供电，USB 充电线必须物理拔除；所有采集严禁接触人体，确保医疗电气安全。

## 3. ADS1292R 模块模拟通路与原理图细节

根据凌智电子《ADS1292模块电路原理图》（版本 V2.0）核验：
1. **差分输入通道分配**：
   - **CH1 (引脚 7 IN1P, 引脚 8 IN1N)**：专用于呼吸阻抗测量（RESP）。内部集成 32kHz 调制信号发生器与解调乘法器。
   - **CH2 (引脚 5 IN2P, 引脚 6 IN2N)**：专用于心电信号放大（ECG）。输入级并联 10MΩ 偏置电阻及低通滤波。
2. **右腿驱动网络 (RLD)**：
   - 引脚 3 `RLDIN` 采集共模信号，经片内放大反相后由引脚 4 `RLDOUT` 输出。
   - 外部串联 100kΩ 阻抗及补偿电容送到模块 `RL` 接口。
   - **重要禁令**：RLD 属于闭环反相驱动源，绝不可将模块 RL 直接接地（GND），否则会导致内部运放饱和，破坏整个差分放大器的共模抑制比。
3. **时钟选择 (J3)**：
   - 模块原理图标注 J3 跳线默认悬空（使用芯片内部振荡器）；严禁短接 J3，短接会将 CLKSEL 拉低导致芯片等待外部时钟而死机。

## 4. 现场执行防错核查清单（Checklist）

在未来获得 PI 签署 Gate P 现场授权后，执行任何接线前必须核对：
- [ ] SKX 模拟器 USB 充电线已物理移除，屏幕仅显示电池供电图标；
- [ ] B 板 PC10 已配置为输入，无高电平或推挽输出驱动；
- [ ] ECG60 切换为 RR15 时，必须在**完全断电**状态下操作，严禁带电热插拔模拟器导联插头；
- [ ] 导线移动仅限“黄 L 线从 LA 移动至 LL/F”，其他导线不得触碰；
- [ ] 接线完成后由操作人员拍照留存，与本图纸核对无误后方可申请下一步预检。
