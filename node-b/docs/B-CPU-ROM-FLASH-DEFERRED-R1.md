## 问题应如何描述

此前“CPU关闭”“算法消失”不是当前证据支持的准确表述。上次VTOR在系统ROM、五次PCSR也采到ROM地址，说明观测时CPU在执行ROM代码；应用Flash中候选固件仍完整。BIO_V2诊断位于RAM，应用未按预期运行时，RAM结构可能不符合tag/ABI，不能据此判断Flash程序被擦除。

Flash保存程序，RAM保存运行状态；正常断电、调试暂停或复位本身不会擦除Flash。RAM是易失状态，断电不保留，启动过程也会重新初始化相应变量。故本轮可确认“程序存在、曾未在候选应用中运行”；不能把RAM诊断失败和Flash算法丢失混为一件事。

它与更早的ROM/Flash状态切换属于同类运行异常，**是否同一根因仍未知**；不据此断言由J-Link Close、手动复位、BOOT脚、电源、SDK或固件某一因素导致。
