## 2. 尚未排除的方向

| 优先级 | 方向 | 仍缺的证据 | 判断方法 |
|---|---|---|---|
| P0 | B板实际固件身份 | 今天没有读取板上镜像；最新独立通道候选未有对应实测 | 下轮先核对准确BIN/ELF/源码，绑定接线和profile |
| P0 | 可用的外部已知ECG输入 | 先前“假人/模拟”与实际输入描述有变化，无幅值/节律真值 | 独立证实源端频率、幅值、偏置，再接收端；不能仅靠贴片或电池供电宣称真值 |
| P0 | 电极插头映射与模拟路径 | RA/LA/RL实物触点、线缆通断、两输入共模及参考条件未完整闭环 | 断电核线与受控台架测量；不用颜色猜脚，不将RL当GND |
| P1 | 外部RLD及共模 | 内部短接无法代表实际负载反馈 | 同源同负载下逐项控制RLD配置，并保留输出与输入参考测量 |
| P1 | 呼吸调制对ECG串扰 | 只在内部短接完成对照 | 已知ECG输入不变，仅改变调制/解调因素，核对真实寄存器 |
| P1 | CH1呼吸阻抗前端 | 无已知基线阻抗/变化量/呼吸频率输入；开放输入顶轨无有效率值意义 | 准备审定的非人体阻抗网络/模拟器，记录设定值与标定条件 |
| P1 | 算法对有效形态的漏检/误检 | 现有合成夹具有限；没有对应参考标注库 | 身份固定的原码回放，逐峰标注、误检/漏检及恢复耗时 |
| P1 | 约25Hz成分来源 | 可能落在ECG通带，尚无单变量外部对照 | 已知输入、原码/滤后频谱、源开关及RLD/RESP逐项对照 |
| P2 | 电源、电脑公共地与USB/J-Link耦合 | 曾暂缓；没有B板同固件、同输入、独立留存的连接路径对照 | 先有独立数据留存再做单变量对照；USB烧录本身不构成排除 |
| P2 | 模块外部保护/PGA/参考/焊接 | 内部MUX测试绕开这些路径 | 测受控外部传递关系，必要时同条件另一模块对照 |
| P2 | 时基、SPI电气和长期负载 | 有IRQ/回读，没有全部外部波形或长期极端负载 | 仅当具体风险需要时做引脚测量和受控负载，不用微小速率偏差解释全部大幅干扰 |

“未排除”不等于已证明有问题。当前优先级是证据补齐顺序，不是新的硬件操作授权。

## 3. 推荐的下一轮顺序

1. **S独立输出**：先在同一串口观测时段完成BIAS DC对照，再验证1Hz、60/90工程峰；模式ACK、计数、DMM和DSO各自记录。当前还未通过。
2. **衰减与共模网络**：源端合格后，另行确认元件实测值、负载和允许输入，验证mV差分与共模。现有候选电阻不是已批准实物接法。
3. **B板仅ECG**：另行确认窗口、镜像及输入映射；先CH2与最新通道独立候选，CH1可无效但不得拖垮ECG。保留参考输入、原码、原因位和算法状态。
4. **RLD/呼吸单变量**：一次只改变一个因素；返回基线也独立保留，不因返回值相似就删除中间失败。
5. **呼吸阻抗**：ECG可用后引入已知阻抗变化与频率；同时观察ECG是否回归。ECG电压源不能替代该项。
6. **算法最小修复**：仅在输入清楚而算法仍失败时基于同一冻结记录修改；先复现，再普通Host/ARM验证，最后按窗口复测。

## 4. 多样本记录要求

固定 `sample_id/condition_id/repeat_index/run_id`，区分输入类别及是否有真值；未知填null，不默认正常。保留原始文件SHA、BIN/ELF、工具/地址表SHA、接线、寄存器实际回读、主机请求/确认时刻、暂停尾段和退出状态。

完整性、物理信号质量和算法准确度分别评价。不能清零flags、补点制造连续、把SWD HALT确认当真实停止瞬间、把离线回放当新真机运行，也不能为了多样本对比公开实际人体原码。

历史报告位于 `history/`。其当轮FAIL、REVIEW_REQUIRED及未授权项均保留；脱敏副本不能替代本地原件。
