## 为什么触发尾端超时

原码锚54914ms，评价窗口为[54914,219914)ms；主机采集起点1147906.375，旧主机deadline1148071.375。倒数第二块1054最高原码219912ms，比半开窗口右端仅低2ms；最后保存块1055最高220076ms，双方共有稳定尾帧已覆盖到219912ms。原完成条件却要求连续两块最高原码都达到219914ms，因而继续读1056。该次读取在1148071.468返回，比主机deadline晚0.093s，gate抛出M1_PHASE_TIMEOUT；它没有被记作成功保存块。

这是把165s原码窗口和165s主机I/O期限绑死所致。不能据此指责负责人上电时间，不能解释成HR算法/板端采样失败。受限真实块和原读时序在离线采集器中复现相同超时。
