## 2. 当前 B 候选接线

| B板信号 | 模块丝印/方向 | 说明 |
|---|---|---|
| PA0 | PW / PWDN-RESET | 控制输出 |
| **PG15** | START | 当前有效方案；不是 PA1 |
| PA2 | CS | 软件片选 |
| PA3 | DR / DRDY | 输入，EXTI3 |
| PA5 | SCLK | SPI1 时钟 |
| PA7 | IN / DIN | MCU MOSI → 芯片输入 |
| PA6 | OUT / DOUT | 芯片输出 → MCU MISO |
| 已核对的5V、GND | 模块5V、GND | 维持公共参考；供电噪声尚未被完整排除 |

用户曾确认 B 板相关串口跳帽取下，COM1_R/T 对 PA9/PA10。历史第二块板照片不能证明 B 板今天的跳帽状态。下次硬件窗口仍需核对当前实物，不仅凭源码确认。

## 3. 原理图揭示的模拟路径

- 外部 `ADS1292_ERA` 网络经 56kΩ 路径到 IN2N，`ADS1292_ELA` 到 IN2P，并存在 10MΩ 偏置及电容滤波网络；呼吸调制另经串联耦合/39kΩ 支路接入。应按实际 RA/LA/RL 导联与该网络核对，**不能仅凭线色或插头外观猜触点**。
- RLDOUT 经反馈网络和 100kΩ 外送到 RLD 端；RL 是受驱动路径，不可直接当普通 GND 或源板 PA5。
- J1/J2 为模块供电入口，图中注明只使用其中一路。图示 AVDD_5V 与 DVDD_3V3 的供电关系不等于已测得实物电压。
- **模块 J3 是时钟选择，不是开发板 P11。图纸标注默认不短接、使用内部时钟；短接把 CLKSEL 拉低，不能未经核对就建议装帽。** 下次记录实物状态并核对是否提供外部 CLK。
- PA1 在板图中与 LAN8720A 的 REFCLKO 网络共用。已有换到 PG15 的对照支持其影响 START，但没有把 IRQ 边沿计数冒充 50 MHz 的示波器实测。

## 4. 当前采集配置

| 项目 | 当前BIO_V2源码值 | 解释/限制 |
|---|---|---|
| CONFIG1 | 01 | 名义250 SPS |
| CONFIG2 | E0 | 内部参考配置；不是实际参考电压测量 |
| CH1SET / CH2SET | 40 / 40 | 正常输入，增益4；CH1为呼吸、CH2为ECG |
| RLD_SENS | EC | CHOP字段保留、RLD缓冲开启、选择CH2正/负感测 |
| LOFF / LOFF_SENS | F0 / 00 | 当前未启用各输入导联检测；零导联状态不能证明接触良好 |
| RESP1 / RESP2 | EA / 03 | 呼吸调制/解调的当前正常配置 |
| GPIO | 0C | 回读低位为实际输入电平，核验需使用mask |
| SPI1 | mode1，/128 | 名义84MHz/128=656.25kHz；有界收发和CS结束等待 |

以上是源码配置；2026-10-13正常轮有相应寄存器回读，但本次没有读取 B 板。`CC/2A` 是后续 ECG 单独输入的候选配置，尚未作为本轮 B 版应用或烧录。

数据手册定位：连续读/START/RDATA 见第47–50页；寄存器表及 CONFIG1/2、增益、RLD、RESP 见第51–60页附近。内部测试 MUX 通过旁路外部模拟输入，不能验收保护/滤波、导联与实际 RLD 负载路径。
