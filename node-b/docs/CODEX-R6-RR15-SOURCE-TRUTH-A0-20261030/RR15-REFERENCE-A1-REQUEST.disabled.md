## 要解决的问题及两段范围

**A1-S（优先申请）**：SKX源端、独立参考仪器，B/C/A、RLD反馈及电脑/J-Link/USB/CAN对源电极完全断开；判断未加载RA–LL在正常ECG正控制和RESP15待测设置下的实际差分信号。可先证实源自身是否携带QRS，不使用BioV2当裁判。

**A1-L（单独待批，不随A1-S自动授权）**：如需标签化实际B输入，必须保留历史RA–LL/RLD负载条件并同步取得独立参考和CH2/CH1原码。由PI另行冻结B采集入口、SDK/数据隔离/同步及供电接线；不含C→云链路或B5START，不沿用旧420s窗口。A1-S阴性且没有A1-L证据时，B输入仍SOURCE_UNKNOWN。

## 时标和标签

每条参考数据保留原采样计数、时钟频率/漂移、量程、过载标志和原始电压；B保留原ADC码、IRQ ms/cycles/seq/flags。A1-L设计目标为参考与B时标映射误差≤1ms（另列B的约4ms量化），必须用独立共同触发/隔离同步口或≥3个已核验独立标记来测残差和漂移。无安全既有同步通路则A1-L NOT_READY；不得向电极/RLD/未经批准GPIO注入同步信号，也不得靠BioV2峰值反向配时。

标签按事实矩阵：ECG_PRESENT需要独立端子波形与冻结标注；ECG_ABSENT只在批准的幅值/带宽/时段/加载域内成立且控制成功；低于检出下限、同步/加载有缺口、正负控制不合格或参考冲突，一律SOURCE_UNKNOWN。两位独立审阅者按事先固定的QRS模板/节律和工频、RESP区别做标注；不能将同一BioV2算法复制到参考通道来循环自证。
