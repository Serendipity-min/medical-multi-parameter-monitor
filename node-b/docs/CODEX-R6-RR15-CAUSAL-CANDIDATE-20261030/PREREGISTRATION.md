在算法改动和留出波形分析之前登记：

1. 开发反例：本轮六事件 R6 RR15 原始 ADC；独立已通过的新 ECG60 是真实正例。旧 ECG60/90/120 各 `matrix-ecg*-r3-01` 为额外开发正例；`*-02` 为独立留出。原 R5 RR15 是独立负例留出，其历史失败标签已知，但本次开发不得先看其波形或据其调参。已知历史标签不冒称全盲测试。
2. 所有输入先验证已封存 SHA 链、帧来源、两份一致资格、seq、IRQ ms/cycles、状态和flags。缺口/启动epoch/主机与板端状态不一致须先解释；不得丢样后压缩时间，也不得补值来通过。
3. 原 C 代码不修改，先核对当前600个SWD诊断中六事件的逐seq回放、候选峰、接受峰间隔、资格计数和失效原因。仅Process回放不含真实UI/getter Tick时间线；差异未解释时因果门关闭。host浮点/初始化影响也列为模型限制。
4. 使用真实IRQ时基分析50/100Hz、低频RESP相关性、峰宽/幅值和QRS形态。去工频/去线性RESP耦合是诊断干预，变换后的数据不得伪装原始ADC或真实QRS标注。波形相似/相关本身不能证明物理耦合方向或排除小幅真实QRS。
5. 只有来源、回放一致性及非QRS证据共同支持质量门缺陷，才允许一个模式无关最小候选。不得从六事件单独挑阈值、按RR模式屏蔽HR、伪造导联脱落或放宽冻结标准。
6. 若有候选：真实ECG正例正确率与valid覆盖不得劣于基线超过1个百分点，稳定率值误差保持原±2bpm；不达基线要求的正例单列BASELINE_LIMITATION。已有host ECG40/60/90/120/180及呼吸6/12/15/24/30/40、工频/宽带/DC/正弦、wrap、缺口、削顶/恢复及ABI必须全跑。新低幅/相位偏移/调幅噪声正负例与固定随机种子留出在候选前固定。必须报告真实、合成、留出三个层级，不能互相替代。
7. 任何候选必须保留ADC码、原始时间戳、250Hz源与50Hz下采样连续性、ABI120字节与字段offset，不修改冻结评测器。若根因或正例门未闭合：`ROOT_CAUSE_UNRESOLVED / ALGORITHM_PATCH_NOT_IMPLEMENTED`，交付工具修复、证据与下一步受限方案即可，不能用一个“噪声门有效”实验冒称修复完成。
