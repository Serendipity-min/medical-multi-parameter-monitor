# 新旧算法与厂家移植例程对比

## 1. 先区分版本

本包旧版是**已修过连续性、显示与首拍恢复的旧工程快照**。最初静态报告里的 `HP_SPIKE_STEP=5000`、送显倍率100000等不能直接当作今日旧代码：当前快照分别为80000、1000000，波形峰初值也已改。历史报告保留原文，本表以实际归档代码为准。

厂家 F407 目录同样不是不可变的原厂版本：其 README 只列部分移植变化，源码还包含诊断、增益/RLD配置及周期 LOFF 读取。文件原字节和 SHA 随包提供，避免把后来的改动错误归因于厂家。

## 2. 处理链比较

| 维度 | 本地厂家F407移植版 | 项目旧版（修复后快照） | 当前BIO_V2 |
|---|---|---|---|
| 应用/库 | HAL + CMSIS FIR | 标准外设库 + CMSIS FIR | 标准外设库；新生理算法纯C |
| START | PA1，仍与当前B接线不匹配 | PG15 | PG15 |
| 采样交付 | 单帧数据和 `flog`；没有当前128帧队列 | ISR取帧、FIFO、采集时戳 | 沿用已修复ISR/FIFO，不在ISR跑算法 |
| ADC输入 | 当前本地增益12，RLD_SENS=CB，呼吸开 | 按该快照驱动理解，不能套用BIO的新SPI修改 | 增益4，RLD=EC、RESP1=EA、SPI /128 |
| ECG滤波 | 标称5–40Hz、129抽头FIR | 实际约3.8–29.2Hz FIR，5点中值/伪迹抑制、微分、平方、152ms积分 | 50/100Hz陷波、DC跟踪、约5Hz高通及25Hz低通、有界IIR状态 |
| ECG判拍 | 局部极大及动态幅度，`point_cnt*4`换算周期 | 自适应信号/噪声、200ms不应期、T波抑制、回搜、5个间隔中位及显示限幅 | 绝对带内幅度、RMS门槛、滞回宽度12–160ms、273–2000ms新间隔；最近3–5间隔均需接近中位数20%内 |
| ECG预热/有效 | 没有当前完整原因码语义 | 学习期与首拍恢复；输入/率值超时清资格 | 5秒预热，至少3个新间隔；质量/新鲜度逐项控制valid |
| 呼吸处理 | 2Hz FIR输出呼吸波；本地示例未形成当前RR引擎 | DC估计+低通、局部极大、幅度包络、至少2个间隔；无完整慢漂移验收 | 首点DC初始化、慢DC+约0.8Hz低通、完整谷峰起伏、10秒预热、至少3个新间隔和稳定资格 |
| 数据断流 | 按样本数换算的时间可受丢样影响 | 已增加采集时间戳接口，但历史仍有重置瞬态等限制 | 序号/flags/时间缺口分段；失效不复活旧周期 |
| 单路顶轨 | 没有当前明确隔离策略 | 依该版本处理链 | 最新逐路保护；共同源故障才共同失效 |
| 诊断证据 | `B:/A:/C:`及本地诊断打印 | 多模块同名静态变量，旧导出容易取错类型/归属 | 固定120B `BioV2Diag`，原因位、候选/受理数、新鲜间隔、原始码和质量指标 |

厂家当前 `main.c` 每约2秒停连续读去读取 LOFF，随后主动跳过20帧。其 `CH1SET/CH2SET=60/60`、`RLD_SENS=CB` 也是当前本地字节，不可用 README “其余与商家一致”代替真实版本审查。该参考副本不提供直接烧录入口。

## 3. BIO_V2有效资格和限制

原因位：WARMUP=1、NO_CYCLES=2、UNSTABLE=4、EXPIRED=8、DISCONTINUITY=16、CLIPPED=32、MAINS=64、BROADBAND_NOISE=128。允许按位同时出现，不能把末帧原因当全程唯一根因。

- 合法周期窗口是工程检测范围，不是“落在范围内就正确”。应与外部参考逐峰比较误检、漏检和速率偏差。
- 宽度是本算法的滞回峰持续时间，不是独立测量的生理 QRS 宽度。
- 固定250Hz滤波系数假设输入时基可靠；当前DWT测得约249.8SPS，不是外部时钟校准。
- 20%周期稳定窗偏向规则工程输入，不能据其通过推断对不规则节律均适用。
- 呼吸正弦码夹具验证的是周期算法，不是已校准欧姆量或患者呼吸。
- UI“探头接入”还依赖近期有帧及至少一路valid；两路invalid时不能仅凭UI判定ADC停采。LOFF配置也未提供导联接触证据。

## 4. 通道独立修复的精确意义

`reference/biov2-before-isolation/HARDWARE/bio_v2.c` 能复现“呼吸顶轨导致心率资格被每帧清空”。当前版对两路分别执行 `accept_input()`；仅故障通道停止滤波并清周期，恢复后重新预热，不复活旧结果。健康通道在相同输入下逐帧结果不变。

本次公开合成专项为28/28；历史29/29还包含一项8412帧开放输入回放，该原码不公开，本轮不重跑，也不把28写成29。原算法普通合成回归27/27。源码未改心率/呼吸阈值。

当完整、身份明确的已知输入仍被错误拒绝时，才针对门槛、宽度、周期恢复或滤波做可回放的最小修复。当前不以降低保护门槛来制造持续数字。
