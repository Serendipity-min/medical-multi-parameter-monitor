## 唯一一次操作顺序

1. 执行者先确认本轮工具无串口/调试会话；G1云工具不操作实板。负责人关闭B、C原J5供电开关，拔下C的USB线及J-Link连接电脑的USB线，阻断USB/探针供电。**不先带电移动B端JTAG排线**。
2. 目视确认B、C、ADS及屏幕指示全部熄灭，保持10秒。若仍亮、不能确认断电、有发热或反常，立即停止，不继续拔板端探针、不探细脚测量。
3. 在探针也断USB的情况下，仅从B取下整只JTAG排线，按原接口键位/方向接C，不挪单根线。接头/方向不确定则停，不试插。不触碰BOOT、P4/P6、RESET、CAN/参考地或ESP。
4. B的J5保持关闭。仅按原J5方式给C供电，再将J-Link的USB接回电脑。C原USB线保持断开，本次备份不用串口；不按两板RESET，不给任何下载/START命令。
5. 一次回报：“已断电10秒并转接，J-Link在C，C由J5上电，B断电，C USB断开”，并说明异常。执行者据此绑定G2-RO现场附件；未收到完成事实前，不打开调试器。

限额：每板关电至多1次、C重新上电1次、探针物理转接1次；人工RESET0、跳帽/电极/CAN/ESP更改0、烧录/配置写0。整组完成上限180秒，不成功不追加复位/插拔。ESP保持原装板状态，不把此动作宣称为其电气隔离或AT/TLS验证；本卡不发送ESP命令。

本次重新上电是已批准时的准备动作，不构成CPU根因或独立冷启动验收。随后G2-RO若见ROM/HALT或意外复位即停止，无自动恢复；C24104全片/身份若漂移也停，不重刷。G2-RO完成后不自动把探针转回B、不重新给B上电；后续状态改变另行批准。
