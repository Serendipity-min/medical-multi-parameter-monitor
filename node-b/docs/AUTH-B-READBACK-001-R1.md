## 4. 只读地址白名单

以下为F407ZGT6条件下的精确对象，所有区间末端不含；不读取旧算法RAM地址，不抓波形，不访问串口/ROM下载器。

| 对象 | 区间 / 字节 | 用途 |
|---|---|---|
| CPUID | [0xE000ED00,0xE000ED04) /4 | 核类型佐证 |
| DHCSR | [0xE000EDF0,0xE000EDF4) /4 | 初态、halt/go及异常状态确认；读含状态位语义须保留原值 |
| DBGMCU_IDCODE | [0xE0042000,0xE0042004) /4 | DEV_ID低12位预期0x413，记录REV_ID；不单凭此识别唯一芯片 |
| 96位UID | [0x1FFF7A10,0x1FFF7A1C) /12 | 当次身份私有绑定 |
| Flash容量 | [0x1FFF7A22,0x1FFF7A24) /2 | 预期1024KiB，小端；非预期停止 |
| FLASH_SR | [0x40023C0C,0x40023C10) /4 | BSY/错误观察，只读、不清标志 |
| FLASH_OPTCR | [0x40023C14,0x40023C18) /4 | 保护/WDG/BOR/nWRP原值，只读 |
| options原件 | [0x1FFFC000,0x1FFFC010) /16 | 双份保存，逐字节核对；不读取OTP |
| 全用户Flash | [0x08000000,0x08100000) /1048576 | 独立双读，仅型号/容量/RDP准入后 |

FLASH/options范围按 [ST RM0090](https://www.st.com/st-web-ui/static/active/cn/resource/technical/document/reference_manual/DM00031020.pdf) 及本库STM32F4 CMSIS结构核定。RDP非Level0（FLASH_OPTCR.RDP不为0xAA）、BSY/异常保护/器件不符均停止，不尝试解锁或解释成“空白板”。

“完整备份”在此定义为当次完整1MiB用户Flash、原始options与保护状态、身份和步骤日志；其恢复可行性另裁定。不会把候选BIN前缀、历史备份或活动RAM当成本轮全Flash。

因B当前断电且本卡采用正常上电后attach，备份时点明确为“本次获准上电后的暂停点”，不宣称保存了上电前尚未观测的字节状态；若要求在用户固件启动前冻结Flash，须另审明确的复位保持/连接动作，不能隐式改用connect-under-reset。

## 5. 条件步骤、次数与末态

以下为受控入口必须实现的确定分支，不能一次性将所有命令串发给目标。

| 步骤 | 允许动作与准入 |
|---|---|
| 0 主机准备 | 新建唯一受限run目录；核工具/入口/卡SHA、ACL、磁盘可写；确认负责人允许的本次起止时刻，电源仍未触发 |
| 1 供电/连接 | 负责人完成已批准的单路上电1次；Codex正常SWD attach最多1次；失败不重试、不reset、不unlock |
| 2 初态/身份 | 读CPUID/DBGMCU/UID/容量/OPTCR/SR及DHCSR，登记初态；UID与照片角色建立首次绑定。型号/容量/保护/BSY不符立即STOP |
| 3 条件halt | 初态RUNNING时发h最多1次，≤3秒确认S_HALT；初态已HALTED则不发h、不擅自恢复。LOCKUP或初态不明停止 |
| 4 冻结态核对 | 记录DHCSR；重读UID/容量/OPTCR/SR。初次attach前既有RESET状态与本窗口新增reset区分；建立状态基准后再出现reset立即STOP。不修改看门狗冻结位 |
| 5 读第一份 | 先确认HALTED/无新增reset及SR允许；savebin保存options-read-1.bin 16B和flash-read-1.bin 1048576B；每次读取后确认状态 |
| 6 读第二份 | 同一暂停窗口独立保存options-read-2.bin及flash-read-2.bin，独占新文件；再次确认UID/容量/OPTCR/SR及暂停状态 |
| 7 磁盘核验 | 重开两份磁盘文件，分别核长度、逐字节一致、SHA一致；options/身份/OPTCR稳定。失败保留原件，不能只拷第一份伪装第二次读板 |
| 8 条件恢复 | 仅全部成功且初态RUNNING、由本卡halt且未有异常reset时，发g最多1次；两次DHCSR确认RUNNING。初态HALTED则保留HALTED。恢复失败不追加reset/go |
| 9 关闭与封存 | 关闭行为已事先禁止自动go；保存真实末态。生成manifest及同ACL独立恢复副本，并核其SHA；负责人按已批准计划断电1次，记录其回报 |

`h/g/savebin`是本地已核手册中的动作名称，以上不是可直接执行的命令文件。目标长读单次≤45秒，普通请求≤5秒，条件halt≤3秒，从attach开始总窗口≤180秒；以最先达到者为限。host磁盘核验/封存可在断开后完成，无延长硬件窗口。

本卡允许成功路径条件性h≤1、g≤1；**主动reset=0、Flash/options/RDP写=0、擦除=0、源输出/导联接入/采集=0**。正常连接仍会使用调试控制资源，不承诺没有任何调试内部寄存器变化。看门狗自然复位、意外供电变化或J-Link错误均触发STOP，不用额外debug寄存器写入压住异常。
