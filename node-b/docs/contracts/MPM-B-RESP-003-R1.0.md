## 2. 关键技术判据与计算方法

呼吸阻抗等效模型仅用于解释：`Z(t) = Z0 + A*sin(2*pi*f*t)`，真实源可能不是正弦、Z0和A的定义未知，不据此计算Ω。ADS1292R内部32kHz调制/解调后，将低频变化作为CH1采样（250SPS）。取按同一单调时钟记录的稳定谷/峰，`T_i = (t_{i+1}-t_i)`；`RR_est = 60000 / median(T_i[ms])`。例如12/18/24次/分对应5.000/3.333/2.500秒，250SPS分别约1250/833/625样本/周期；15/30次/分对应4.000/2.000秒。

**RR频率工程验证不要求ΔΩ绝对值；ΔΩ（Ωpp、峰值、RMS、基线定义）必须单列NOT_CALIBRATED。** 按菜单设置的数字只能称名义参考，若无独立标定不写为源频率实际误差或医疗精度。

三层结论互不代替：L1有真实CH1原始变化；L2变化周期随模拟器菜单15→30、12→24等改变；L3 BIO_V2在连续、非削顶、已完成预热的输入中给出稳定有效RR且与名义频率一致。L1不等于L3。

## 6. E2 可辨识性复试：两种呼吸率分别采样

仅E1安全且观察到可信CH1动态后另开两窗。优先比较15→30rbpm（若实际菜单允许，且确有完整设置确认）；分别建议45–60秒，必须每次独立起止并保留首10秒以上完整预热。15rbpm目标周期约4秒，30rbpm约2秒；两种设定应使CH1周期近似按2:1缩放。若菜单只支持特定档位，选择实际可确认的两个明显不同的设定，不编造设置成功。对比后再做离线回放与失效原因分析，不进行即兴阈值优化。
