## 3. B2-1 / B2-2｜已知 ECG 真机输入与 HR 验收

**B2-1 物理前置门禁**：B 与 C/A 断开，所有设备断电，先核验电极触点、供电、电平、参考/隔离路径。外部模拟器电源及地回路不可臆断。先通过不触碰人体的低风险输入、模块状态和原码稳定性检查，发现顶轨、持续近工频/25Hz、供电超标、异常发热或明显共模风险时立刻停。

**B2-2 建议验收矩阵（须在授权卡中冻结精确源与模式）**：

| 条件 | 采样窗口 | 首要评价 |
|---|---|---|
| ECG 模式，60 BPM | 连续至少60秒 ×2 | CH2原始采样、独立削顶、R峰/HR参考 |
| ECG 模式，90 BPM | 连续至少60秒 ×2 | 同上，算法无旧波形续活 |
| ECG 模式，120 BPM | 连续至少60秒 ×2 | 同上，参考变速后恢复时间 |
| 无已知ECG/断线/异常 | 有界负例 | 不伪造有效HR，不影响采集计数 |

先登记预热、参考的确切值及其允许误差，再确定 HR 容差，例如洁净工程输入稳态建议 `|HR−参考|≤2 BPM`；这是**建议验收阈值**，尚未授权为医学精度标准。若无同步逐拍真值，则只做速率比对，不声称逐峰漏检率或敏感性。须保存每次的 raw/filtered/quality flags、峰事件、来源/供电/导联、真实SPI寄存器回读、250SPS统计、STOP与最后稳定窗口；保留失败、不补点。

**先输入再算法**：若 CH2 已严重削顶、RLD/共模不稳定或源幅值不确定，不得通过降低 `MAINS`、`NO_CYCLES` 等阈值硬造PASS。合格源条件下软件仍失败才允许做原因定位的最小修复提案，改变固件需新软件回归并另行获得写板授权。

## 4. B3｜已知动态阻抗的 RESP/RR 验收

B2 ECG取得可靠输入后才进入 B3。必须先证明模拟器**实际**向 B 的 CH1 电极路径提供动态阻抗变化，且与 ADS1292R 的阻抗呼吸激励/解调兼容。固定基线约1kΩ没有问题；`0.3R–3.0R` 是否等于变化欧姆数及幅度定义、RA–LA还是RA–LL，均要有厂家电路说明或实测依据；仅示波器上的低频呼吸电压不能替代阻抗证据。常规DMM静态测量不能单独证明在工作调制频率下的复阻抗行为。

仅在电气准入PASS且真值明确后，建议12、18、24次/分，每档连续至少90秒×2；主看CH1是否顶轨、调制解调是否响应、RR与来源一致、ECG/HR无交叉退化。恢复、断流、呼吸停止、RLD单变量按一次一个因素进行。优先不要同步更改 ECG 滤波参数和呼吸调制参数；所有测试保留完整周期与失败结果。

若变化电极对不匹配，`B3_BLOCKED_ELECTRODE_PAIR`，不临时短接RL/LL或自行猜接；若变化量无法核验则`B3_BLOCKED_REFERENCE`。两者都不是算法FAIL或算法PASS。
