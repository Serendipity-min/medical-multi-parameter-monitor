# M1入口、原码窗、评测与退出口径

本轮只完成离线实现与Mock，现场入口默认禁用。新代码不修改旧采集系统：BLink继承原Open/原生read/Close，M1覆盖G3 gate和精确地址/计数；b4_runtime沿用120B解码、BIO→TEMP→BIO夹逼、CPU/ADC推进；原稳定槽读者沿用至少两份相同记录，不重写投票或HR算法。

## 时间窗和采样

预检身份/全片/options、CPU和两秒真实推进在165s之外。采集使用128槽环形缓冲的首个“两次完全相同”合格原码锚，不等HR/RR有效再起计。最早稳定帧通常比本机首读早约半秒；将这个原始IRQ锚绑定为0ms。直到连续两次块读均覆盖锚+165000ms才结束，主机采集阶段仍不得超过165s。若原生读慢、环形余量不足或末端无法两份确认，失败/停机，不延窗和补点。

预热[0,45000)ms、评价[45000,165000)ms。原码与原始状态全部保留；评价边缘容差12ms、全窗名义SPS247.5–252.5沿用现有只读连续性依据，不是晶振校准。序号要求逐点+1；IRQ整数毫秒允许3/4/5ms量化，cycles必须推进，flags/ADC状态/内部缺点、乱序或跨启动不通过。原始两路均250Hz，RESP50只按原序号%5抽取，保留seq/ms/cycles，不能称独立50Hz ADC或绝对阻抗。

所有块有独立索引/偏移/SHA，采集完成后把原件哈希封存到输入manifest，再由授权绑定记录其SHA；评测先核对这些原件，不能自己重算当前文件SHA后当作采集时参考。原码不合格的单次暂态版本按既有稳定规则排除；评价内因此产生的缺口/冲突仍失败，不能补插。预热期间新增ADC/队列/采样错误也不豁免。

授权原文、实际签名和公钥副本一并保存、核验SHA并重做Ed25519数学验证。数学验签不等于密钥属于PI；信任根未配置的P0/Mock评测只能给离线指标且field_scope_PASS=false，不能据exit0标现场PASS。现场评测根已配置时，公钥指纹不一致必须拒绝。

120个1秒半开槽各取首条原生观察，缺槽计入固定分母；诊断顺序不得倒退，额外2Hz观察全部报告。正确有效槽≥118且所有原生有效目标值在HR±2/RR±1内。有效覆盖不等于逐拍敏感性；保存快照只能报告观察簇和时间分辨率，不能补造连续有效时长。HR无效/有效与reason原件保留；RESP组即使HR有效也不抹去，RR只判名义速率子功能，HR真值UNKNOWN，整窗RR PASS不得宣称。

## 权限、计数和停机

签署固定M1 scope、run_id、plan、当前commit/tree、全部本地工具依赖SHA、DLL、参考bundle、现场/冷启动记录、输出目录及人工责任。实际PI公钥指纹必须预先配置，不能从来件自选；签名验证是实际Ed25519数学验证，非“签名非空”。根未配置立即拒止，不读用户自填授权，更不构造Link。旧G3/P1-B签署与nonce不继承。

本场仅一OpenEx、至多一显式Connect、一次探针选择；完整Flash/options各一次、结束BIN前缀一次，块读取至多3304次，总SDK调用≤20000，活动阶段预留64次收尾。Device可能隐式连接，计数不证明内部无其他动作。构造即加载DLL，因此factory必须在授权/nonce之后；构造失败、OpenEx失败但部分初始化、Close异常后的原生状态均UNKNOWN。

父进程只监督不连接目标；SDK心跳按单次native deadline（含Close5s）处理，Stop/总时限/监视器故障终止唯一worker并保留真实OS退出码。不存在自动再连、reset/go/Flash或补跑。父进程nonce先独占消耗，worker再次独占claim，后者不能以手工直接调用旧worker重用同一许可。

| 码/层 | 语义 |
|---|---|
| 0 / capture | 原码采集、末态/身份/前缀与Close完成，仍待工程评测；不是最终工程PASS |
| 0 / review | 本M1目标速率子功能通过；RESP保留HR真值UNKNOWN，非完整RR或临床PASS |
| 1 / capture | 构造/Open/原生/身份/固件/CPU/Close等停止；reason/type/原件与原生返回单列，不能由Close成功覆盖失败 |
| 2 / entry | 未授权/信任根/签署/绑定/输入/工具冻结不符，SDK前拒止；监视器自身错误也单列type，不当作板故障 |
| 2 / review | 原件/哈希/时序/ADC/seq/IRQ等完整性失败；未完成采集/Close也不得评成PASS |
| 3 / review | 有效率覆盖或目标有效量值不满足工程阈值 |
| 4 / capture/supervisor | STOP、阶段/硬预算或native超时；worker原生返回/强杀码独立保留，不能把-9/Windows终止码改写成0 |
| null / NOT_RUN | 未获批的现场运行、其他23场、C/云阶段，不能填exit0 |

Open/Close只有主机控制流程经Mock。硬件SDK隐式暂停/复位、Close后目标运行、冷启动ROM、真实CPU/USB最坏耗时不由此证明。P0不签SDK_RESIDUAL_RISK_CLOSED；SIGTERM/强杀可能没有native Close，标UNKNOWN并由人工处理，不为退出“恢复”目标。
