# F/R/L设计映射复核 R2

2026-10-22，Asia/Shanghai。结论：**F对应模块第三路RLD功能，资料级设计映射可确认；实物通断和SKX兼容性尚未实测。** 这是结合原理图、厂商演示和负责人“同款模块、同款线缆”声明作出的设计归属判断，不把照片当成导通表。

## 证据链

1. 模块V2.0/2020.09原理图A1接口：3为ERA、4为ELA、1/2标RLD、5/6未连接。ERA进入CH2 IN2N，ELA进入CH2 IN2P；第三路RLD来自芯片RLDOUT经外部反馈及100k输出电阻。芯片32针封装的RLDOUT为30脚，外部接口编号不等于芯片脚号，插头观察面也尚未核定。
2. 资料包F103/F429演示照片均采用RA/LA/RL三端，LL空置。旧演示图用绿色接RA、黄色接LA、红色接RL；图中是SKX-2000，不能自动认证当前SKX-2000D+的电气兼容。
3. 负责人确认模块和线缆为资料包同款，并提供夹子照片：**F绿色、R红色、L黄色**。照片可以确认字母/颜色，不能显示夹子到模块插头的导通关系。负责人说明同款，加上ERA/ELA/RLD三线电路及演示功能，支持R→ERA、L→ELA、余下F→RLD的设计映射。
4. 模拟器实物照片端子标RA/R、LA/L、LL/F、RL/N。模拟器自己的F=LL与该模块第三根线的RLD功能不是同一层映射，不能只按F字母对接。

## 作为未来授权卡的拟定对照

| 负责人这套导联 | 模块设计网络 | 拟对应模拟器端 |
|---|---|---|
| R，红 | ERA → IN2N | RA / R |
| L，黄 | ELA → IN2P | LA / L |
| F，绿 | RLD主动反馈输出 | RL / N（若有RF标记则同RL） |

本表可作为接线设计依据；**不是现在接线指令**。仍需在另行批准的断电核线/电气准入窗口确认真实线缆端到端映射及主动RLD兼容性。F不按模拟器的LL/F端直接连接；不将RL接GND，不桥接LL/RL，不接人体。

本次照片分别是模拟器/开发板现场和三只导联夹，未提供传感器模块可追踪的正反面及线缆触点视图。可以结束“第三根线设计用途完全未知”的状态，但不能声明实物通断已PASS。
