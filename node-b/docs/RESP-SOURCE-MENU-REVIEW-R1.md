## Codex流程问题与结论边界

先前把负责人报告的“呼吸率15”和“波形周期20”都按呼吸参考并列、当成可能冲突，判断过早；它们应保留为两个不同参数。本轮负责人已明确当前在呼吸波形页面、幅度1.5R、波形周期20bpm，先前报告呼吸率15及窒息0s也分别保留。不得把20字段直接替换成RR真值，窒息0s的实际禁用语义也不凭空补齐。

上次已确认的是负责人报告的菜单及B板实际输入；未独立验证源端参数确认/输出生效，且CH2实际120与手册呼吸页面60描述未对上。可能的解释包括：只切到了设置页面而实际输出未更新、源保留/共享了之前ECG参数、波形周期控制配套ECG、设备与该版手册行为不一致。现有证据不能在这些解释中定案，不归咎于负责人操作，不宣称模拟器故障或算法阈值错误。

上次RESP_PATH_NOT_OBSERVED仍准确描述那一窗实际输入，但不能推广成“已按手册完整生效的独立呼吸15测试失败”，更不能说ECG120不允许测呼吸。CH2 ECG和CH1解调呼吸是两条不同测量链；ECG心率120不能替代RESP真实参考，也不自动导致呼吸只能为120。

下一次应先分别记录并确认源端呼吸率、幅度、波形周期、窒息显示及参数生效步骤，再用当次原码同时检查配套ECG和CH1周期。当前只建议ECG60作为控制变量，不猜测性修改含义未明确的“波形周期”。新的采集卡及实际源记录未冻结之前不操作硬件；CPU启动状态问题按负责人要求保留为待查，本轮不继续展开。
