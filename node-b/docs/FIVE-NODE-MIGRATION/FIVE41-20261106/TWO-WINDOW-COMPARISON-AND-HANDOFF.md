## 分层结论与已验证软件路径

- 本次支持五节点在现有两段41Ω、约20cm台架下同时采集/通信；不承诺全部源点完整、电气裕量、长期稳定或临床准确度。四源身份/Topic来源及E/D迁移已在实物/云端/网页观察到。
- B采样与已收波形点值核对正常；RR源600次观察均为有效18。对应主通道的云端覆盖仍不足，PPG更明显不足。ECG和RR两种输入分开判定，未将对方的源资格强改或拼成同窗双有效。
- 已收生理消息进入网页后均有原样或按失效规则遮蔽的记录，缺收0；300条状态消息每窗聚合为在线状态，不是丢失。
- 实际router源码离线复现了PPG不在FIFO保护集合而被提前转存，以及实时取帧提前返回导致历史配额饥饿。复现器原生0表示复现成功，**不是修复通过**。固件未因分析而变更。
