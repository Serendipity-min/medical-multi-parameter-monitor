# 五板双段40–41Ω监督诊断准备（2026-11-06）

**本轮按负责人最新决定：暂不购买接口，先观察两段各40–41Ω时五板能否传输真实采集数据；先ECG，再RR，模拟器不能同时提供两种有效生理输入。** C计数候选已安装并完整回读通过。首次ECG准备在B采样预检时停止，未发C启动命令；负责人确认全部断电、J-Link板端在B。B启动竞态离线修复及新候选已准备，尚未安装，见[B-STARTUP-FIX.md](B-STARTUP-FIX.md)。

这覆盖了原FIELD01中“优先完成正常端接五板300秒”的当前执行顺序，但不把40Ω改称正常端接。NXP给出的TJA1050最低驱动负载为45Ω（VCC>4.75V），见[AN00020第9.1节](https://www.nxp.com/docs/en/application-note/AN00020.pdf)。本轮只交付有时限、有人在场的工程诊断，不签正常端接或电气裕量通过，不从一次诊断推断长期稳定性。

## 两个独立窗口

| 窗口 | 输入与评价 | 时间 |
|---|---|---|
| ECG60 | 沿用非人体ECG60、1mV、黄L接LA；独立血氧持续输出；D温度、E身份/PDO；时间允许时E本地人工完成一次血压 | 四源共同就绪后45秒预热＋300秒评价 |
| RR | ECG窗离线核对后再安排切换，记录模拟器实际RR设定/导联；不要求ECG/HR同时有效；A/D/E按实际状态记录 | 独立冷上电及新事务，45秒预热＋300秒评价 |

C保留既有 `B5START` 420秒硬截止。四源在线和计数协议必须在武装后50秒内准备好，45＋300秒结束不晚于第395秒发X，另留15秒停止确认，不延长设备或数据超时。若网络/四源就绪太晚，本次停止，不把评价缩短后写成300秒。

没有录音，不发送启泵命令；E泵始终由负责人本地在非人体工装上手动控制。血压原90秒有效期、其他数据原5秒规则、ECG250Hz、RESP50Hz、PPG50Hz均不改，不补点或伪有效。模拟器没有输出的另一路按实际INVALID/未知记录，不作为通信丢包。
