**结论：本窗A/D点对点和隔离网页传输工程通过；A全窗源端无损证据不足。没有执行五板300秒，也不以本窗替代该验收。**

## 实物、镜像和退出

- C.CAN1↔A.CAN1：负责人断电实测61Ω；C.CAN2↔D.CAN1：60.9Ω，参考地保留。B/E及泵断电。
- A沿用33,436B发送背压/TXFP修复；C沿用正常五板M1，boot392B＋code55,480B；D沿用24,544B。没有下载、复位、录音或启泵。
- C USB_UART为COM15，J-Link在A，ESP/TTS按原方式供电；A为独立非人体血氧输入。负责人开窗前A屏SpO₂ 95–97%、PR 81–89 bpm。
- 本窗主机采用现有 `B5START` 420秒硬截止入口，实际联网准备19.218秒、评价60.000秒后发送一次X停止。没有延长固件或业务超时。
- C主机控制器原生退出0，STOP横幅与TTS STOP ACK/QUERY/IDLE均已确认；隔离接收端原生退出0，全部自有本机子进程退出。负责人随后确认“已全部断电”。结束时屏幕、发热、复位观察未补充，保留UNKNOWN，不补写“无异常”。

## A源端证据不足与工具修正

A只读观察器由主机启动较晚：第一条在T0+47.188秒，最后一条T0+59.250秒，共7条，其中4条测量双读完全一致。工具因不足15条原生退出1，原因 `AD60_A_OBSERVATION_TOO_SHORT`，未触发超时监督器；不是MCU故障判定。原失败回执和执行时源码保留，不改写为PASS。

在这7条之前，工具已通过A实物身份、33,436B应用SHA与TXFP位核对；运行态前后检查通过，没有显式Halt/Reset/Go或写Flash，Close完成。所覆盖约12秒中ESR均0，UNO新增1451帧；CAN环丢弃累计26079、波形过期累计255均未增长。**这些累计值在首次快照前已经存在，缺少T0同步快照，发生时段未知，不能归零或证明全窗没有新增丢点。**

A全窗逐点原始输入未记录；SpO₂/PR动态范围也不能代替模拟器固定真值。A屏本窗是否出现0/探头提示、D屏当前是否动态刷新未获负责人观察回执。

离线已调整后续编排：可先启动只读A观察器，待身份/应用/运行态检查完成并收到READY后再建立共同T0；工人退出与C停止一并回收。仅完成语法和差异检查，未重新上电验证，也未自动重跑A/D窗口。本窗执行时源码SHA与修正后的工具分开保存。
