# ABC 血氧模拟输入下的语音失败分析

2026-11-05；进行中的离线分析，不是新基线或最终验收。负责人已确认全部板及外围断电，USB/J-Link电脑端拔除；本次分析不操作实板或远端服务。

## 输入与比较边界

恢复短窗口、旧调度ABC计时采用空载血氧；失败轮负责人补充已接血氧模拟器，血压未接。型号、SpO₂/脉率设定待核，负责人报告光干扰使输出不稳定。由此撤回“空载误判有效”的解释。失败事务目录仍名为`after-ABC-empty-audio`，不改原件。

|---|---|---|---:|---|
| before-BC-audio | 原调度计时参考 | A断电 | 82.819 s | 125块；导出工具原生失败，后从原件恢复PCM并逐字节核对 |

BC有相同固定2秒声学参考。ABC前后输入负载改变，不能把102.718→252.159秒当作同负载性能回归，也不能判定血氧数值准确性。

## 已确认的失败链

1. C采集32,000样本、64,000 B，DMA/溢出计数为0。音频125块均到达Broker，服务器匹配同一批packet SHA，首末块跨度252.153秒，与本地Observer252.159秒一致。
2. 原服务器组包上限为240秒。将实际125块和到达时间回放到现有组包器：完整会话0，第119块（从0计数）首次报`MIC_SESSION_OR_EXPIRY`，拒绝6块。服务器也记录6次该拒绝，未产生本会话完成回执。
3. 因此本次直接失败点是**上传过慢导致组包过期**。本会话未进入ASR/AI，不应解释为语音识别慢或TTS音量问题。最后C回合300秒到期，采集器退出1；原失败回执保持不变。
4. STOP工具退出0，ACK/QUERY/IDLE核对通过；随后负责人确认全部断电。

## 上游耗时与调度嫌疑

实装候选的C聚合计时（相对本次开始）：录音完成2,507 ms，校验完成5,923 ms，首块发送8,061 ms，上传结束260,571 ms。医疗门槛等待233,395 ms，让步等待10,311 ms，AT资格等待694 ms，间隔/在途窗口等待844 ms。门槛计数可能重叠；发送过程本身另计，不能把694 ms解释为全部AT耗时。

单块发送最大107 ms，PUBACK等待最大428 ms；音频可发送资格等待最大7,702 ms。长等待主要出现在获得发送机会之前，但聚合日志没有区分医疗门槛的各个子原因。

`gateway/b5/egress.h`中的PPG条件：只要实时队列中存在任意A.PPG，就禁止新音频，不区分该PPG是否刚到或队列是否仍有大量空位。持续到达/积压时存在音频饥饿路径。医疗QoS1在途槽满、deferred标量和音频让步之间的组合也需要处理；已有离线修复不能自动代表当前镜像已修复。**当前证据支持重点修调度，不支持把全部233.395秒归因于一条判断。**

采集到的SpO₂/PR源序号跨度推算约1Hz，不能无依据地解释为2Hz异常洪泛。加入模拟输入增加了有效标量及PPG；光干扰与输出变化可能影响A工作状态，但本轮没有固定设定对照，尚不能证明其导致语音超时。

## 医疗流完整性与离线覆盖缺口

实测约300秒窗口：B的ECG/RESP序号连续，TEMP有更新；两路CAN和ESP UART错误计数未见增量。A实收PPG99批，首末序号90–342，跨度253，存在154个未实收序号。原A路径会将同流待发项替换并转历史，因此须核查生产、路由合并和出口，不能凭序号缺口定位到CAN物理层，也不能签署完整PPG通过。

Host原正常/大载荷夹具的固定发送开销只有15/25 ms。追加同一真实Router/coreMQTT/音频状态机、55 ms固定发送开销与400 ms PUBACK延迟包络后：

- 编译退出0，运行退出3；PPG214/300批，86处序号缺口，历史缓存丢弃441，实时溢出0。
- ECG750批、RESP300批；音频125块，上传阶段144.453秒。
- 这不是现场精确复现；没有模拟8MHz目标的全部CPU开销和真实AT时序。它证明原Host通过的时间假设过于乐观，且仅放宽音频优先级可能损害波形完整性。

CRC计时的`hash_cycles_max=10/73`存在编译器重排问题，不能用来宣称目标CRC耗时极低。源码已加编译屏障，但未在本次失败实装镜像中，应在后续制品中独立核验。

## 后续修复与实测条件

继续离线修复单一AT/coreMQTT所有者下的发送预算和饥饿问题，同时保留ECG/RESP/PPG完整性、医疗5秒和血压完成后90秒规则。不得以增加240/300秒超时、关闭波形或直接并发访问同一连接换取通过。当前不宣称修好，下一次安装前冻结明确的镜像、资源与来源。

负责人要求下轮加入非人体血压输入，仍由本地屏人工触发；语音不启动泵。下一轮输入的型号、连接方式和设定统一核对后固定，前后对照保持相同血氧输入状态与血压完成时序。血压读数核对屏幕/网页/语音同一完成代次，并另验90秒失效。激光/光干扰问题若未消除，应明确记录为变化输入负载，不能同时签固定数值准确性验收。
