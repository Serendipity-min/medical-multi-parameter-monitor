## A3 三对差分直流筛查，最多六次接触

导联夹全部不接SKX、B仍OFF，仅SKX电池源与电池万用表。RL仅作本行差分参考，不是GND，不桥接端子。

| D1 | RL/N | RA/R | 待测 / 待测 |
