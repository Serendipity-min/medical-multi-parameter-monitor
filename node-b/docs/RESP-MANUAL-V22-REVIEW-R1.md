# SKX-2000D+ V2.2新操作手册复核

2026-10-23，Asia/Shanghai。负责人提供新的21页《操作手册.pdf》，并要求取消导联线电阻测量、优先排查接线和参数。本轮使用PDF提取并逐页渲染，目视核对第6/9/11/20页；未操作任何实物、连接J-Link或运行采集。新证据覆盖旧资料“未给出RESP端子对”的当前判断，旧文档和失败原件不改写。

## 直接改变排查方向的证据

**第20页明确给出呼吸导联为II，即RA–LL。** 旧12页说明书没有这一句；此前使用红R→RA、黄L→LA、绿F→RL，按既有模块设计解释，激励/感测落在RA–LA，未覆盖厂家要求的RA–LL。这是优先验证的接线不匹配，尚不能在没有新窗口前签为唯一根因或宣称已修复。

新手册第4页的I导联定标也将设备LA导联接源LL，该段属于电压幅值定标，不用于替代第20页明确的RESP导联规定。第5页一般ECG I导联接法仍是RA–LA，两种用途不同。不能因为ECG正常就推定当前端子适合阻抗呼吸。

模块V2.0原理图仍是ERA/ELA分到CH1 RESP与CH2 ECG，RLD为单独主动输出。因此新探索方案是将感测/激励的第二根线从源LA移到源LL，RLD继续独立接RL。按此前采用的同款线缆设计解释，外部接法为**红R→RA、黄L→LL、绿F→RL；LA空置**。不是把F移到LL，不桥接LL与RL，不把软件通道由CH1改成CH2。

负责人要求不进行线缆电阻测量，本轮按该要求取消，不将九格映射作为探索先决条件。线缆颜色到ERA/ELA/RLD沿用此前设计假设，仍不冒称已经逐点通断认证；两张旧厂家照片也不当作新的RESP接线依据。当前不追查小导线的串联电阻或通过改色/短路试碰端子。

## 呼吸率与波形周期必须按项目名区分

| 项目 | V2.2第11/20页 | 本轮目标 |
|---|---|---|
| 呼吸率 | 5–120bpm，步长1，默认15 | **20bpm**，接受负责人报告的实机可设范围，不再要求设置15 |
| 呼吸幅度 | 0.3R–3R，默认1.5R | 1.5R，只记文字，不换算Ω |
| 波形周期 | 20–120bpm，默认30 | 保持既有20bpm，单列记录，不能冒充呼吸率 |
| 窒息时间 | 0–120s，默认0 | 0s，记录显示，不额外推定内部禁用语义 |
| 呼吸模式所列心率 | 60bpm | 沿用ECG60；未来CH2另核实际周期 |

负责人报告“呼吸15无法调节、最低20”作为实机事实保留，不能按手册替他补写设置成功。手册同时明确两个同用bpm单位的不同项目：仅看到第四行20bpm，不能知道是呼吸率还是波形周期。此次统一选择**呼吸率20**，无需反复尝试15；若第三行确为“呼吸率”仍有与手册不符的范围，如实记版本/显示，不阻断20的探索，也不改旧记录。

第6/7/9页操作逻辑：第二行选波形，第三行选项目，第四行选数位；参数行“*”状态下增减键移动数位，确认使“*”变“?”后才编辑该位，编辑完成再次确认。“只浏览到呼吸波形页面”不等于已确认生成对应输出。每个参数须退出“?”编辑态，最后回到呼吸率20并确认，不进入保存设置或厂家设置。

## 调整后的测量方案

新[R2操作卡](AUTH-B-RESP-PATH-MEASURE-001-R2.md)取消旧R1九格电阻测量。先冷隔离，导联不接源；只做独立呼吸20/1.5R/波形周期20/窒息0的菜单确认及RA–RL、LL–RL、RA–LL三对直流筛查。新拓扑和上电须待这些读数审阅，不能先带电把黄线挪到LL。

电气门通过后，后续探索按厂家RA–LL路径冷接；软件仍读原CH1，不修改RESP1/RESP2、相位、增益、RLD或BIO_V2阈值。旧45秒工具冻结了15/原三线且已消耗，不能仅换接线重跑；新的源记录/profile/窗口须另外准备，并保留本次物理接法和实际菜单。

后续若名义呼吸20真正进入CH1，应优先观察约3秒周期，再另窗对照30时约2秒周期。两档都在现有6–40次/分周期范围内，无需改阈值。若CH1先有相干周期而BIO仍报130，再按冻结C回放定位能量门/周期资格；若仍无周期，再查调制/解调兼容性，不先将错误归因于算法或小导线干扰。不用万用表交流档证明32kHz或用通电Ω档测SKX。

旧45秒的“未见相干周期、实板RR无效”保持。新手册支持“原接法未覆盖指定呼吸端子”的解释，但不追溯断言当时实际呼吸率一定15或20，也不补算准确率。
