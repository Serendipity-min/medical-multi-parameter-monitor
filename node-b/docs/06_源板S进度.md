## 3. 已准备但未启动的下一步

`observe_bias.py` 在一次连接内核对初始OFF，发一次BIAS，每2秒查询数字状态，最多300秒，异常不重连/不重新启用，退出请求OFF并如实记录确认状态。普通负向测试9/9；**没有该工具新的真实BIAS窗口数据**。

它只证明查询时刻的数字状态，不保证查询间未短暂复位，也不代替端子物理测量。下一步应先把DMM同一测点、可靠接触与模式时段对齐，再考虑动态模式；无需据目前读数改写DAC或BIO算法。

源板S尚未成为已验证的ECG模拟器；即使将来输出验收通过，也只有工程电压波形功能，不自动提供呼吸阻抗、导联安全或患者测试认证。衰减/偏置网络及接B必须另行完成实际验证。
