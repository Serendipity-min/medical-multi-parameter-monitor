## 原理图能确定的模块网络

V2.0/2020.09模块原理图A1插座：3/5脚为ERA，4/6脚为ELA，1/2脚为RLD。这是电路网络编号，不是3.5mm插头上可直接从外观读取的编号。实物PCB/插座接触结构及线缆颜色尚无端到端实测记录。

| 网络 | CH2 ECG支路 | CH1 RESP感测/激励支路 |
|---|---|---|
| ERA | R4 56kΩ→IN2N，U3脚5 | C10 100nF→节点；C9 2.2nF→IN1N，U3脚3；另经C11 2.2nF、R11 39kΩ→RESP_MODN，U3脚32 |
| ELA | R15 56kΩ→IN2P，U3脚6 | C12 100nF→节点；C14 2.2nF→IN1P，U3脚4；另经C13 2.2nF、R12 39kΩ→RESP_MODP，U3脚31 |
| RLD | 非差分采样端 | RLDOUT脚30经R5 0Ω和R10 100kΩ到A1，含R6/C8反馈；主动输出，不能当GND或挪作另一个呼吸输入 |

所以模块实际测量、激励的是**ERA–ELA**。若实际R红→ERA、L黄→ELA、F绿→RLD，当前接法才等价于测SKX RA–LA；这个颜色映射需要与实际线缆核对，不能仅用R/L/F名称替代实测。普通TRS的Tip/Left、Ring/Right、Sleeve/Common对应关系只能作插座约定解释，不能替代该实物插座的验证。

TI原版[ADS1292R Rev.C](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)第60–63页支持CH1调制/解调、CH2另采ECG的架构。冻结配置RESP1=EA、RESP2=03名义上为内部32kHz、112.5°、调制/解调开启；它说明配置意图，不证明载波已从当前导联实际通过SKX，也不证明解调幅度足够。既有缓存是初始化回读，不称本轮实时SPI测量。

网上还可检索到其他SKX型号的RA–LL呼吸说明，但型号、版本及来源不足以确证本机D+端子定义，本轮不以此作技术定论或自动换线依据。RA–LL仅列为**待实物检验的候选路径**；RA–LA未观察到周期也不证明RA–LL一定有效。

## 原因130的准确含义

已完成45秒窗：11346稳定帧，无序号缺口、近轨或ADC错误；评价段38次实板观察全部RR无效，原因130。CH2实际ECG60得到原码周期互证，CH1没有可交叉验证的4秒周期。详见[原实板结果](RESP-VALIDITY45-001-RESULTS-R1.md)。

冻结`bio_v2.h`定义NO_CYCLES=2、BROADBAND_NOISE=128。`bio_v2.c`第219行附近的触发条件为：

```text
有效输入，clean_power > 1，且 band_power < 0.05 × clean_power
→ 清除呼吸周期历史，记BROADBAND_NOISE
未形成合格候选速率 → 发布时另加NO_CYCLES
```

clean_power是50/100Hz陷波后信号的平滑能量，band_power是呼吸低通后的平滑能量；两者是不同阶段的算法状态，不是源端功率测量。原因位可保留在周期状态里，不能从38次保存观察推断每一个样本都即时低于5%。120B诊断未直接导出这两个功率，不能从resp_rms或resp_mains_fraction精确倒推出比例。

该判定防止宽带噪声经低通后形成慢起伏而被误计为呼吸。当前原因不等于已证明50Hz工频、J5电源、SPI或SKX本身故障；评价段工频能量比例约0.019–0.087，未出现MAINS原因位。NO_CYCLES也不等于ADC没有输出：CH1有变化，但未建立合格的新鲜周期。

## 不改阈值的排查顺序与解决条件

1. **先核线缆**：执行新[离线线缆及源端直流测量卡](AUTH-B-RESP-PATH-MEASURE-001-R1.md)，仅在导联线完全脱离模块、SKX和人体后测TRS三触点到三夹头的电阻。查是否错色、串联保护电阻、开路或串线。若TRS/插座网络仍无法对应，记录这一缺口，不凭蜂鸣猜RLD、不碰密集SMD引脚。
2. **再核候选路径电气条件**：同卡只允许源端电池供电的差分直流筛查，加入LL对RA/LA/RL的比较。电压表不能测出ΔΩ，也不能认证32kHz兼容。保持Z0_ohm、delta_Zpp_ohm、reference_rpm为null。
3. **有映射和安全记录后，再另卡作RA–LL有限探索**：只有在实际ERA/ELA/RLD对应清楚后，才设计将两路感测/激励分别落到RA/LL、RLD仍单独落RL的冷接线；不预先按颜色安排，不桥接LL与RL，不照抄照片。独立RESP源/profile记录新物理接法，先短窗看CH1，再按结果安排15→30周期跟踪。旧45秒工具会拒绝新接法，不能改其常量、冒用旧profile或重跑消耗过的卡。
4. **若候选路径也无周期**：检查调制载波是否到ERA/ELA、源负载是否有周期变化、模块耦合元件/接触是否正常，再检查解调相位/载频适配。当前仅有万用表，无法独立观测32kHz包络；可以继续有界工程输入探索，不要求先取得厂家ΔΩ定义。涉及探头、注入已知无源负载或寄存器改变的实验，需各自明确部件与电气卡，不能用通电Ω档代替。
5. **若CH1有清晰周期而BIO仍拒绝**：用原码与冻结C回放区分带内能量不足、幅度门、预热、间隔不稳等原因，再设计单变量工程验证。本轮不改变5%门、20code门、滤波、相位、增益或RLD设置。单纯增加低通、放宽门限、加大到3.0R或重复延长相同接法，都不能解决尚未建立的输入路径。

成功先定义为原码中出现可复核周期，并在随后15→30时近似由4秒变2秒；RR有效与绝对阻抗准确度分开评价。本轮交付的是测量方案，不签INPUT_SEEN、RATE_TRACKING或绝对阻抗通过。

线缆矩阵若与同款V2.0插座的设计约定相符，可将该明确记录的设计假设作为后续有界探索依据，不必等待整板逐网认证或厂家ΔΩ定义；若矩阵不符、存在串线或无法判断主动输出，则先定位该具体异常。不得把“仍非完整端到端认证”转化为无限追加测量，也不得把它省略写成实物已认证。
