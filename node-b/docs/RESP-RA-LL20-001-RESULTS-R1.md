PCSR和VTOR是**这次卡已读到的准入证据**，并非停止后追加调查。它们共同支持观测时在运行系统ROM，不能推导最初为何进入ROM。Flash里有正确固件不等于该固件正在运行，更不能把未初始化的RAM随机内容当作ADC或呼吸数据。

现入口先尝试解码准备诊断，随后才汇总运行门，因此最终错误名呈现为RAM ABI失败，遮蔽了更直接的ROM运行证据。这是诊断报告顺序的不足；不说明本次序号/通道被解析成另一种真实信号。已执行工具、卡和日志保持原字节，待批的新恢复入口先核Flash运行环境再解析RAM，以免再次混淆原因。
