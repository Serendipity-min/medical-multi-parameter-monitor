# CAN后续设计备忘｜本轮仅记录

MPM-B4-001继续暂停。本轮未开展CAN驱动移植、CAN配置/接线、B/C联动或云部署；已有冻结应用中继承的CAN代码不修改。此文不是启动后续合同的许可。

后续独立审核优先比较两段500kbps总线：Node-A CAN1 ↔ Gateway-C CAN1；Node-B CAN1 ↔ Gateway-C CAN2。每段仅在各自两个物理端点各设120Ω，两段CAN_H/CAN_L不互接，不用三位面包板永久并联。

届时核对C板CAN2收发器及供电、PB12/PB13与I²S2资源冲突、CAN1共享时钟/过滤器、双总线接收、NMT/TIME、节点有效性与Gateway汇聚逻辑。实施范围、资源分配、故障隔离、总线负载及测试窗口均须在新合同中单独冻结。当前不修改C固件或任一CAN驱动。
