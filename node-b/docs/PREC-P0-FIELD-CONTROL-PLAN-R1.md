# PREC P0单变量现场计划 R1（除独立S0卡外均未授权）

2026-10-23。当前普通ECG60，源/电极/供电/屏幕不动。先完成离线审计，S0卡只取当前状态；下列是后续卡的设计，不是任何插拔、断电、复位或连接许可。

| 单元 | 唯一受试动作 | 其余条件 | 必须取得的证据 |
|---|---|---|---|
| S0，单次 | SDK连接一次并关闭一次 | 无物理变化、reset/halt/go0 | 首次及后续PC/VTOR/DHCSR/RCC/Fault/计数；关闭后未知 |
| D0，独立卡待写 | J-Link物理断开 | B和源不复位、不切模式 | 断开前后屏幕MCU输出是否继续；持续30秒的独立观察 |
| M0，独立卡待写 | 已无调试器时人工NRST一次 | 不断电、不动BOOT/源/导联 | 复位前后MCU输出与启动时间；随后单次受控连接读取是另一个阶段，不冒称其读值为介入前 |
| C0，独立卡待写 | 已无调试器时B完整冷启动一次 | 其他条件固定且先审阅防反供电方案 | 无调试器的完整启动过程；随后受控连接的状态对照 |
| A0，独立卡待写 | 从独立运行态进行SDK连接/关闭一次 | 无人工复位、无源变化 | 外部输出连续证据、SDK逐调用轨迹及关闭前状态；不能用再连接代替关闭后无调试器证据 |

现有串口屏可作独立观察通道，但屏自走RTC、缓存画面、局部暂停和界面版本不符均不能当成CPU采样计数。优先辨别由MCU每秒刷新的控件/连续新波形，记录不同时间的原值；若只能看到静态画面，明确INDEPENDENT_STARTUP_EVIDENCE_NOT_ESTABLISHED。没有新接USB串口的许可，不打开COM端口，不启动自动下载软件。

冷启动涉及停电/源端反供电风险，不能在此直接指示执行。后续C0卡须先冻结共用的安全隔离初态；必要的源/模块断开只在独立的准备步骤获准后做，并保持该初态用于所有对照，不能把换线和复位混为一个变量。不会给出通电欧姆测试、主动RLD接地或LL/RL短接方案。

BOOT静态电平检查若确有必要，另列万用表电压档卡，指出真实可达测点、参考地、范围和停止门；PB2 GPIO读值只表示当下电平。无高速记录手段时，不承诺取得BOOT锁存瞬间电平。不得改跳帽、写BOOT/PC/MSP/VTOR或刷固件试碰。

探索每单元只做一次，异常保留后停止；不自动重复。得到可证实机制及对应纠正措施后，另行冻结验证矩阵：相同条件下2次独立冷启动、2次无调试器人工复位、2个连接/关闭窗口，均有外部应用推进证据及规定的寄存器证据；每次独立授权，无ROM/Fault/采样停滞才可签该纠正措施的有限工程验证通过。这不替代机制证据，不作统计可靠性认证。若未复现或机制未知，不能以全窗口正常签P0 PASS。

当前所有后续单元均未开始。S0无论读取到正常或异常，也不单独满足P0关闭标准。P0未关闭，P1保持BLOCKED_BY_P0，不切源做同步试验。
