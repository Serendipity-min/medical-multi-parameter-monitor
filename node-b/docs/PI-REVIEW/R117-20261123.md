### 6.2 17:08 前后：负责人说明只有左臂移动去戴指夹，没有其他动作
- **时间线**（MQTT 原件）：QRS 正峰从 17:07:45 起逐步下降（30 s 窗：602 → 573 → 520 → 488 → 505 → 422 → 353 µV），A 的 PPG 首批在 **17:09:29**，PR 首次有效 17:09:31，17:09–17:12 有几段明显的动作伪迹。
- **戴指夹在电学上不会让 QRS 变小**：A、B 是独立的板子，各自电池供电；PPG 的 LED 驱动如果串扰，只会让噪声变大，而 5–25 Hz 噪声全程保持约 110 µV。所以指夹本身不是原因。
- **左臂动作可能是原因**：黄片贴在左侧腋前线，左臂的位置会牵动这里的皮肤和胸壁，改变电极与心脏的相对位置。是否如此，需要实测验证。

### 6.3 是不是算法的问题
- **算法里没有分钟级的状态**。C2（R89）的检测阈值 = max(30, 2.5 × 检测带 RMS)，功率估计的时间常数约 1 s；HR 需要最近 5 个间期在中位数 ±20%（锁定后 ±30%）以内，预热 5 s。没有任何会“几分钟后变差”的计时或累积量。
- **QRS 变小是信号本身的变化**：上面的 QRS 幅度是从原始波形直接算的，不经过板上算法。
- **但算法放大了这个变化**：有效率对 QRS/噪声比非常敏感。

  | 志愿者 | QRS / 5–25 Hz RMS | HR 有效（30 s 窗） |
  |---|---|---|
  | R116 甲，17:05:30–17:07:30 | 4.5–5.4 | 62–100% |
  | R116 甲，17:08 以后 | 2.3–3.8 | 0–25% |
  | R87 甲（旧色标） | 4.1–6.0 | 39–92% |
  | R108 乙，14:42–14:43:30 | 3.3–3.6 | 82–96% |
  | R108 乙，14:44 挪动以后 | 3.0–3.7 | 7–78% |

  QRS 只降了约 35%，有效率就从 90% 掉到 15%。阈值随检测带 RMS 走，而 RMS 本身包含 QRS 的能量，所以算法在这一带有一个陡坎。
- **以往“几分钟后变差”的规律**：甲（R87、R116）和乙（R108）都是贴好后头 1–3 分钟最好。甲两次都表现为 QRS 逐渐变小（R87 从约 570 降到约 400 µV），乙是 14:44 有一次大动作伪迹，之后噪声升高。丙、丁没有这个规律（丁是越往后越好）。
- **结论**：不是算法的计时问题，是信号在头几分钟内变弱，算法的陡坎把它放大成了有效率的大幅下降。降低这个陡坎可以作为离线研究项（用四名志愿者的 MQTT 原件回放），改固件需另行授权。
