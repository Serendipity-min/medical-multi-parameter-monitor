## S2 拼接距离

第 918 条 PPG 从偏移 378 起的 **253 B** 与第 913 条 RESP 从偏移 92 起逐字节相同。按 MQTT 3.1.1 PUBLISH 固定头、Remaining Length 编码、主题长和主题、QoS1 Packet ID 及载荷重建。第 913 至 918 条对应 RESP、SpO₂、PR、ECG、HR、PPG，长度为 **725、191、191、849、191、673 B**，其中没有订阅侧 retained 或 replay 行。源、目的在各自重建报文内的偏移为 **135、420**。可见序列的字节距离为 **2,432 B**，距最近的 1,024 或 2,048 B 整数倍均为 **384 B**。

这个值是订阅可见 PUBLISH 的重建距离。订阅原件不包含 Broker 拒绝的报文、未交付主题和 MQTT 控制报文，也不能排除 QoS1 交付顺序偏差。真实 STM32→ESP 流距离为 UNKNOWN。当前可见距离未显示固定环大小对齐。旧数据插入、替换与前段字节缺失都与原件相容，缺少接下来被拒报文的字节，无法区分。

## R22 RESP 扩到 ±60 秒

将异常 RESP 从偏移 574 起的 109 B 后缀，与 ±60 s 内 **1,145** 条可解析载荷比较。≥15 B 的连续匹配有两条，都是数字片段，分别为 +16.158 s 的 PPG **17 B** 和 +29.715 s 的 PPG **15 B**。没有字段级拼接证据，也没有可唯一定位的重复块。
