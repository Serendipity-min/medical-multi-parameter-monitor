## 5. 问题
1. **ECG/HR/RR 在真人下无效（FAIL）。**
   - R72 接模拟器时，同一条链路持续有效，所以问题在电极这一侧：导联位置、接触或导联插头。
   - B 屏会显示探头状态（`node-b/firmware/biov2/实验固件/HARDWARE/hr_page.c:571-582`）：
     - 导联脱落时为红色；
     - 质量 <60 或没有有效值时为橙色“信号弱”；
     - 其余情况为绿色。
   - 本轮 B 屏的状态、质量值和电极位置都没有回报，记为 UNKNOWN。
   - 下一次真人测量前，先在 B 屏上确认绿色、质量 ≥60，再开窗口。
2. **改用电池供电后出现 3 次断线（UNKNOWN）。**
   - 9 分钟内断了 3 次，每次都是从 ONLINE 直接跳到 OFFLINE，13–31 s 后自动恢复。正常断电时则是先 STALE 约 11 s，再转 OFFLINE。
   - 恢复时间比 C 冷启动（33–38 s）短，更像 Wi-Fi 或 MQTT 重连，而不是 C 复位。没有控制台录制，无法证实。
   - R72 在同一套硬件上用市电，30 分钟内断线 0 次。
   - 候选原因（未证实）：开热点的设备在电池模式下节能，或者 C 侧的 MQTT 会话重建。负责人补充（2026-11-17）：热点为**手机热点**，倾向于信号波动。仍未证实，修复后复测时验证。
   - 断线与血压泵运行时段没有明显对应（断线 1 和 3 都不在加压期间）。
3. **SpO₂ 读数质量差。**
   - 已知诱因有两个：血压 1 时指夹和袖带在同一只手臂上，加压期间 PR 到过 167；手部移动。
   - 37%、66% 这类明显不合理的值仍被标为 VALID，A 的有效性判定过宽。
   - 维持 R43 的结论：云端 AI 不能按单个读数播报“偏低”。
4. **流程偏差：** 见 §2，在上电和确认之前就已佩戴。
5. **缺少的对照：** 60 s 人工数呼吸、对照设备读数、D 的测量部位，都为 UNKNOWN。TEMP 是物体表面温度，不能当作体温。
