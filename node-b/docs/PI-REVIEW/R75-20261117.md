## 5. 问题
1. **ECG/HR/RR 在真人下无效（FAIL）。**
   - R72 接模拟器时，同一条链路持续有效。真人下无效有两类可能：
     - 采集问题：导联位置、接触、导联插头、工频干扰；
     - 算法问题：门限和周期稳定性要求对真人过严。
   - 本轮 B 屏的状态、波形和电极位置都没有回报，记为 UNKNOWN。
   - **2026-11-17 更正（离线代码核对，见 §9）**：此前写的“导联脱落为红色、质量 ≥60 为好”不正确，作废。
     - B 的“探头”状态只反映 HR/RR 是否有效；
     - “质量”值只反映 SPI 帧完整率，不反映信号质量；
     - 固件没有启用导联脱落检测。
2. **改用电池供电后出现 3 次断线（UNKNOWN）。**
   - 9 分钟内断了 3 次，每次都是从 ONLINE 直接跳到 OFFLINE，13–31 s 后自动恢复。正常断电时则是先 STALE 约 11 s，再转 OFFLINE。
   - 恢复时间比 C 冷启动（33–38 s）短，更像 Wi-Fi 或 MQTT 重连，而不是 C 复位。没有控制台录制，无法证实。
   - R72 在同一套硬件上用市电，30 分钟内断线 0 次。
   - 候选原因（未证实）：开热点的设备在电池模式下节能，或者 C 侧的 MQTT 会话重建。负责人补充（2026-11-17）：热点为**手机热点**，倾向于信号波动。仍未证实，修复后复测时验证。
   - 断线与血压泵运行时段没有明显对应（断线 1 和 3 都不在加压期间）。
3. **SpO₂ 读数质量差。**
   - 已知诱因有两个：血压 1 时指夹和袖带在同一只手臂上，加压期间 PR 到过 167；手部移动。
   - 37%、66% 这类明显不合理的值仍被标为 VALID，A 的有效性判定过宽。
   - 维持 R43 的结论：云端 AI 不能按单个读数播报“偏低”。
4. **流程偏差：** 见 §2，在上电和确认之前就已佩戴。

## 9. ECG/RR 无效判定的离线代码核对（2026-11-17）
B 实际编译的 CAN 代码是 `node-b/canopen/b_canopen_app.c`（`node-b/tools/build_b4_arm.py:85-124`）。下文 `H/` 指 `node-b/firmware/biov2/实验固件/HARDWARE/`。

1. **四项无效同源。**
   - B 的 ECG 波形有效位就是 HR 有效位，RESP 波形有效位就是 RR 有效位（`b_canopen_app.c:108-114`）。
   - HR/RR 只在 BIO_V2 的 reason 为 0 时有效（`H/bio_v2.c:180-192`）。
   - reason 包括：预热、周期不足、周期不稳、超时、断帧、削顶、工频、宽带噪声（`H/bio_v2.h:8-15`）。
2. **HR 的判定。**
   - 门限为 max(30, 2.5×带内 RMS)，峰宽 12–160 ms，峰值至少为门限的 1.05 倍（`H/bio_v2.c:146-157`）。
   - RR 间期 273–2000 ms，4 s 内必须再出现一次。
   - 至少 3 个新鲜间期，最近 5 个间期都在中位数 ±20% 以内。
   - 工频判据：50/100 Hz 能量超过原始能量的 95%，并且原始能量 >1e4。
   - V1 的 HR 有效值 57/43 与 PR 约 87–93 相比，接近漏检一半心搏（推断）。
3. **RR 的判定。** 呼吸峰谷差必须超过门限，周期 1.5–10 s，同样要求 3 个间期和 ±20% 的稳定性。自然呼吸不规则，容易被判为不稳（推断）。
4. **没有导联脱落检测。**
   - `LOFF_SENS=0x00`，检测电流已关闭（`H/ads1292.c:72-75`）。
   - 屏上“探头未接入”的条件是“5 s 内有帧并且 HR 或 RR 有效”，否则就显示未接入（`H/hr_page.c:366-372`）。
   - “质量”值是 SPI 帧通过率乘以时间覆盖率（`H/hr_page.c:527-543`），电极再差也会接近 100。
5. **没有不接调试器的诊断输出。**
   - reason、RMS、工频占比只存在 RAM 结构 `g_bio_v2` 中。
   - CAN 只携带有效位和数值。
   - 现场唯一能看的是 B 屏上经过滤波、自动缩放的 ECG/RESP 波形（`H/hr_page.c:206-218,305-320`）。
6. **以往没有真人 ECG 成功的记录。** 此前全部是模拟器（例如 `node-b/docs/B-ALG-001-FINAL-HANDOFF.md:104` 写明真人采集不在范围内）。R74 是第一次真人测量。
7. **ADS1292R 配置。**
   - 250 SPS，增益 4；
   - CH2 = LA−RA，即 I 导联，用于 ECG；
   - CH1 为阻抗呼吸，同样使用 RA/LA 电极；
   - RLD 开启，RL 是驱动输出，不是地（`H/ads1292.c:36-105`，`node-b/docs/02_模块资料与接线.md` §3）。
   - I 导联在胸前贴法下 R 波可能偏小（推断）。
