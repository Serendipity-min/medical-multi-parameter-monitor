## 一、背景与上次实采结论（`R68–R102`）

## 二、为什么 ECG 软件优化已达上限

1. **已排除离线时间轴展开误差造成的假象：**
   - [`R99`](R99-20261119.md) 修复了历史分析脚本按批首展开批末时间戳的协议违背（改为 `t[i] = ts - (N - 1 - i) * 1000 / fs`）。修正后 A 板 PPG 帧重叠全面归零（`R87: 162→0`、`R94: 488→0`），QRS 相对 PPG 峰的生理传导超前收敛至物理合理的 `-80 ~ -172 ms`，但 **QRS 峰峰值几乎无变化**（`R87: 594→597 µV`、`R89: 406→398 µV`、`R91a: 75→79 µV`、`R94: 271→254 µV`），证明低信噪比来自物理前端而非脚本。
2. **`R96` 与 `R99` 离线实证：软件算法撞上“覆盖率 vs 误报率”物理互斥墙：**

   | 候选方案（验证轮次） | `R87 P2` | `R89 S5` | `R91` | `R94` | 与 PR 一致率 | 阴性对照（脱落 / 重连） | 实证结论 |
   | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
   | `C2` 固件基线（[`r98_ecg_eval.txt`](analysis-r83-r96/results/r98_ecg_eval.txt)） | 65.5% | 4.0% | 6.1% | 0.7% | 82% | `0.0%` / `0.0%` | 弱信号下漏检多，但保守安全、零误报 |
   | **`ALC (50 Hz NLMS) + C2`**（[`R99`](R99-20261119.md)） | 64.4% | 2.1% | 8.8% | 2.2% | **86%** | `0.0%` / `0.0%` | 最安全微幅增益（踝部 R83 +12.6 pp），胸部低 SNR 仅 +1.5~2.7 pp |
   | `Pan-Tompkins + 去异常 C`（[`c3_evalc3.txt`](analysis-r83-r96/results/c3_evalc3.txt)） | 48.6% | 0.0% | 5.7% | 19.7% | **26%** | — | 低 SNR 下将噪声峰当心搏，中位绝对误差暴涨至 `46.0 bpm` |
   | `NeuroKit (NK)`（[`r98_ecg_eval.txt`](analysis-r83-r96/results/r98_ecg_eval.txt)） | 60.1% | 3.7% | 14.4% | 5.5% | 67% | **20.9%** / **13.3%** | 导联断开空噪声中持续误报 `60–72 bpm` |

3. **结论：** 当单拍 `SNR` 跌入 `0.5–1.8`、QRS 幅度低于带内噪底且存在 50 Hz 起伏和肌电叠加时，**放大检出灵敏度必然触发导联脱落/运动伪迹误报，收紧多算法/形态门控又会把有效率压成 0%**。除可安全附加的 `ALC` 微调外，ECG 软件侧已触及物理上限。

## 三、结合 `node-b` 原理图与固件源码定位出的真实硬件瓶颈

直接核对 [`ADS1292模块电路原理图.pdf`](../../../ADS1292R模块资料V4.1_ECG/原理图PDF/ADS1292模块电路原理图.pdf)（凌智电子 `ADS1292模块 V2.0`，与 `node-b` 硬件手册一致）、[`STM32F407_原理图.pdf`](../../hardware/STM32F407_原理图.pdf) 以及实板驱动源码 [`ads1292.c`](../../firmware/biov2/实验固件/HARDWARE/ads1292.c)、[`bio_v2.c`](../../firmware/biov2/实验固件/HARDWARE/bio_v2.c)、[`spi.c`](../../firmware/biov2/实验固件/HARDWARE/spi.c)、[`b_canopen_app.c`](../../canopen/b_canopen_app.c)，定位出以下 **5 项真实硬件/底层耦合瓶颈**：

### 1. 模拟电源绕过板上 LDO 且与内部参考/外部偏置中点失配
- **原理图实据：** 模块板载两颗超低噪声 LDO `U1`、`U2`（`ADP150AUJZ-3.3-R7`），分别输出 `AVDD_3V3` 与 `DVDD_3V3`。但芯片 `U3`（ADS1292R）第 12 脚 **`AVDD` 实际直接连向 `AVDD_5V`**（由 `J1 +5V → Q1 (AO3401A) → FB1 磁珠 → AVDD_5V` 供给），并未接入 `U1` 产生的 `AVDD_3V3`；`U1` 的 `AVDD_3V3` 仅供给 CH1 的两颗 `10 MΩ` 上拉偏置电阻（`R7`、`R13`）。
- **底板噪声叠加：** [`STM32F407_原理图.pdf`](../../hardware/STM32F407_原理图.pdf) 第 3 页显示整板 `+5V` 来自 `VUSB` 或 `SY8120` 同步开关降压电路（`U14`, `L5 = 4.7 µH`），开关纹波未经 LDO 抑噪即通过 `AVDD_5V` 进入模拟供电脚。
- **电平失配：** [`ads1292.c`](../../firmware/biov2/实验固件/HARDWARE/ads1292.c#L88-L94) 配置 `RESP2 (0x0A) = 0x03`，即 `RLDREF_INT = 1`（内部右腿驱动参考 `(AVDD - AVSS)/2 ≈ 2.5V`），而外部 CH1 通过 `R7/R8`、`R13/R14`（`10 MΩ` 上下拉至 `AVDD_3V3` 与 `GND`）建立的直流偏置中点为 **`1.65V`**，两者存在静态共模失配。

### 2. ECG 与 RESP 共用两电极 + 单端对地容性负载失配放大共模转差模工频
- **CH2 (ECG) 无跨差分电容与直连直流偏置：** 原理图接口 `A1` 定义为 `RLD (1/2)`、`ERA (3/5)`、`ELA (4/6)`。`ERA` 经 `R4 (56 kΩ)` 接 `ADS1292_IN2N` 并对地接 `C7 (3.3 nF)`；`ELA` 经 `R15 (56 kΩ)` 接 `ADS1292_IN2P` 并对地接 `C25 (3.3 nF)`。**`IN2P` 与 `IN2N` 之间没有跨接更大的差分滤波电容，也没有直连直流偏置网络**。
- **共模转差模（CM-to-DM）放大机制：** 两条单端对地电容（`C7`/`C25`）的容差失配，叠加三线非屏蔽导联拾取空间工频以及人体左右贴片皮肤接触阻抗的不平衡，会直接与 `56 kΩ` 串联输入电阻形成不对称分压，将共模 `50 Hz` 干扰转化为差模电压进入 `CH2`。这高度解释了 `R92/R93` 模拟器（接触阻抗理想且极平衡）下 `50 Hz` 残余只有 `0.2 µV`，而一旦上人体（`R89/R91/R94`）即飙升至 `48–310 µV`、拔掉 RL（共模失去抑制）直接暴增 >1000 倍至 `264 µV` 的现象。
- **双通道并行耦合与 32 kHz 载波衰减：** 呼吸通道 `CH1` 与激励脚 `IN3N/IN3P` 通过 `C10/C12 (100 nF)`、`C9/C14 (2.2 nF)`、`C11/C13 (2.2 nF)`、`R11/R12 (39 kΩ)` 与 `10 MΩ` 分压共用同一对 `ERA/ELA` 电极（注：原理图 PDF 中 `C10–C11` 与 `C12–C13` 公共节点之间绘有一段纵向连接线，疑似原理图绘制勘误或与实际量产 PCB 网络存在差异，尚待拆解核实）；按照该前端阻容参数，`32 kHz` 呼吸载波经 `39 kΩ` 串联电阻与 `nF` 级耦合/旁路电容（`2.2 nF` 在 `32 kHz` 下容抗仅约 `2.26 kΩ`）分压后调制灵敏度明显受限，同时 `nF` 级对地容抗也拉低了导联线在工频处的共模输入阻抗。
- **单导联生理几何敏感：** 当前仅采集单一向量 `LA − RA`（增益 `4`，满量程 `±605 mV`，[`ads1292.c`](../../firmware/biov2/实验固件/HARDWARE/ads1292.c#L63-L66)），[`R91`](R91-20261118.md) 已实测同一志愿者甲在同一胸前区仅因贴片微调，QRS 峰峰值即出现 `~80 µV` 到 `601 µV`（约 `7×`）的剧烈波动。

### 3. `250 SPS` 采样体制、片内时钟容差与高次谐波拍频敏感性
- 当前 [`ads1292.c`](../../firmware/biov2/实验固件/HARDWARE/ads1292.c#L37-L42) 配置 `CONFIG1 (0x01) = 0x01`（`250 SPS`），`J3` 悬空使用内部 `512 kHz` 时钟（`±0.5%` 规格容差）：
  - **时钟偏移削弱固定陷波：** `origin/gpt/ecg-rr-research-plan-20261119` 分支的 `R98 §4.3` 已按 `C2` 实际系数算出，若真实采样率偏离至 `248.75–251.25 SPS`，固定 `50 Hz (Q=35)` 陷波器衰减将从理论深谷退化为仅 `-7.51` 到 `-7.57 dB`。
  - **工频谐波混叠假设与边界：** `250 SPS` 下电网 4 次（`200 Hz`）与 6 次（`300 Hz`）谐波在离散频谱上折叠回 `50 Hz` 附近，若电网频率微偏将产生 `5·Δf` 低频拍频（与 `R94` 实测 `40–60 s` 周期的 `4–277 µV` 起伏及过零倒相高度吻合）。需要客观标注的是，`R98 §4.4` 也计算出 ADS1292R 片内 `sinc³` 抽取器对理想 `200/300 Hz` 小信号本身分别有 `-37.86 dB` 与 `-48.43 dB` 衰减，因此 **谐波混叠尚属优先待验证假设**，需通过升频 `500 SPS` 实测来最终证伪或证实。

### 4. 硬件导联脱落检测完全禁用（`LOFF_SENS=0x00`）与底板引脚复用风险
- **脱落盲区：** [`ads1292.c`](../../firmware/biov2/实验固件/HARDWARE/ads1292.c#L72-L75) 将 `LOFF_SENS (0x07)` 设为 `0x00`（注释写明顾虑电极串联 `56 kΩ` 会导致 DC 电流压降顶轨饱和；另需注意代码第 47 行 `LOFF=0xF0` 实际设置 `ILEAD_OFF=00` 即 `6 nA` 挡而非注释所写 `6 µA` 挡）。关闭硬件 `LOFF` 检测电流后，MCU 完全依赖“是否有连续周期脉冲”来反推 `Probe Off`，无法在前端物理层区分“电极半脱落高阻接触”与“微弱心电信号”。
- **底板引脚复用冲突：** [`STM32F407_原理图.pdf`](../../hardware/STM32F407_原理图.pdf)（第 4–6 页）与 [`ads1292.h`](../../firmware/biov2/实验固件/HARDWARE/ads1292.h#L6-L10) 对照显示：`PA1` 已因与板载 `LAN8720A` 以太网 PHY 共线（`RMII_REF_CLK`）而迁移 `START` 至 `PG15`；但当前 **`PA7`（`SPI1_MOSI -> ADS1292_DIN`）在底板上依然物理连往 `LAN8720A` 第 11 脚 `RMII_CRS_DV`**，且 `PA2/PA3`（`CS/DRDY`）复用外设排针 `P3`。任何意外启用 PHY 或插错跳线都会污染 SPI 控制总线。

### 5. MCU 存储资源实测约束与早期参考文档口径偏差
- **主控与内存实况：** `STM32F407ZGT6` 以外部 `8 MHz` 晶振倍频至 `168 MHz` 运行（`PLL_M=8, PLL_N=336, PLL_P=2`，见 [`system_stm32f4xx.c`](../../firmware/biov2/实验固件/USER/system_stm32f4xx.c#L316-L331) 与 [`stm32f4xx.h`](../../firmware/biov2/实验固件/USER/stm32f4xx.h#L123)），带单精度硬件 `FPU2`。根据 [`b4_recovery.py`](../../tools/b4_recovery.py#L11-L12)，应用代码严格锁定在 Sectors 0–2 共 **`48 KiB`（`49,152 B`）** 内（`0x0800C000` 起为配置保留区）。
  - R89 `C2` 固件产物已占 **`40,576 B`**（来源：`origin/codex/r89-b-c2:node-b/docs/PI-REVIEW/R89-B-C2-RECEIPT-20261118.md`），**Flash 仅余 `8,576 B`**，不适合塞入重型查表或复杂算法库；
  - 主 SRAM（`128 KiB`）仅使用约 `19.6 KiB`，**SRAM 余量超 `100 KiB`**（适合滑动窗静态缓存）。
- **早期设计文档与当前实装的偏差提醒（防止后续改版看错基准）：** 早期 [`多参数心电监护仪系统硬件方案与元器件开发参考手册.md`](../../../doc/多参数心电监护仪系统硬件方案与元器件开发参考手册.md) 与 [`00_系统硬件防损坏与工程落地复核确认报告.md`](../../../doc/00_系统硬件防损坏与工程落地复核确认报告.md) 中记载的“`ADP150` 直供 `AVDD_3V3`、`CH1SET=0x60`（增益 12）、`CH2SET=0x00`（增益 6）、SPI1 用 `PB3/PB4/PB5`、DRDY 用 `PE9`、使用 CMSIS-DSP 129 阶 FIR”均**与当前实际硬件/源码不符**；此外主目录下的 [`bio_v2.c`](../../firmware/biov2/实验固件/HARDWARE/bio_v2.c) 仍未合入 `R89` 的 [`bio_v2_c2.c`](analysis-r83-r96/scripts/r89/src/bio_v2_c2.c)。

## 四、ECG 下一步可落地的分层优化措施

按工程改造成本与收益比，建议分三步推进：

### 阶段 1：固件与寄存器层低成本试验（不改 PCB、保留 48 KiB Flash 与 250 Hz 传输协议）
1. **统一合并并固化 `C2 + 轻量 ALC` 作为新软件基线：**
   - 把经过 57/57 主机测试的 [`bio_v2_c2.c`](analysis-r83-r96/scripts/r89/src/bio_v2_c2.c) 正式合并回 [`bio_v2.c`](../../firmware/biov2/实验固件/HARDWARE/bio_v2.c)，避免后续构建误抓旧源码；
   - 在剩余 `8,576 B` Flash 预算允许范围内合入 `R99` 验证安全的 50 Hz NLMS `ALC` 模块（`0%` 阴性误报、总 PR 一致率从 `82% → 86%`）。
2. **升频至 `500 SPS`（`CONFIG1=0x02`）片上采集 + MCU 内抗混叠抽取回 `250 Hz`：**
   - 保持 CANopen 与云端 `250 Hz` 包格式不变，在 STM32 端实现 `500 Hz → 250 Hz` 低通抽取（如在 500 Hz 域完成自适应/数字陷波后再二抽一），**直接实测能否消弭 `R94` 的 40–60 s 50 Hz 拍频并抑制高频折返**。
3. **验证开启 AC 交流导联脱落检测（`FLEAD_OFF=1`）：**
   - 重新评估并实测打开 AC 激励脱离检测（绕过 `56 kΩ` 直流压降偏置限制）或极低档直流检测的真实通道余量，恢复 `STATUS` 位级物理接触诊断。
4. **物理锁定底板复用脚：** 上电排查清单固定确认 `LAN8720A` 处于复位/掉电禁止输出且 `P3` 排针无短接，防止干扰 `PA7` (`MOSI`) 与 `PA2/PA3`。

### 阶段 2：模拟前端（AFE）与导联线硬件改版（突破人体 SNR 1.1–1.8 上限的根本方案）
1. **重构干净的模拟供电与统一参考：**
   - 修改 ADS1292R 模块电源走线，使 `U3` 第 12 脚 `AVDD` 真正由低噪声 LDO（`ADP150` `3.3V`）供电，隔断来自 `SY8120`/`VUSB` 的开关纹波；同步使 `RLDREF` 与外部电极直流偏置中点统一到同一 `1.65V` 基准。
2. **改用医疗级带屏蔽导联线 + 主动屏蔽驱动（Active Shield）：**
   - 将 `ERA` / `ELA` 从非屏蔽细线升级为医疗级一体屏蔽心电导联线，屏蔽层接至独立缓冲的 `RLD` 信号，降低人体与线缆拾取的 `50 Hz` 共模与工频磁场耦合。
3. **优化输入 RC 拓扑与差分平衡（消除共模转差模）：**
   - 在 ECG 通道 `IN2P`–`IN2N` 之间跨接对称的**高比例差分电容**（通常取单端对地电容的 `10×` 以上，用于旁路高频/抑差模容差失配），减小过大的对地电容 `C7/C25` 与不平衡寄生；
   - 为 `CH2` 补齐高阻对称直流偏置（或按 TI 参考设计将导联共模偏置稳健耦合至内部 RLD），并核实消弭原理图 `C10–C11`/`C12–C13` 跨线隐患，视情况改用无大共模容性串扰的解耦电阻/电容网络或专片分立呼吸通路。
4. **规范贴片标准：** 制定酒精脱脂清洁、避开肋骨/肌群与固定电极间距的操作 SOP，避免出现 `R91` 中同一位置 `80 µV vs 601 µV` 的 7 倍落差。

### 阶段 3：系统结构与多模融合演进（中长期升级）
1. **单导联升级多导联（ADS1294 / ADS1298 或电子切换向量）：** 彻底解决单向量电极角度/体位差异导致的 R 波极低问题，允许算法实时切换高幅值主导联。
2. **A 板 PPG 辅助门控边界：** 只有在上述硬件降噪使主体 SNR 提升并稳定在 `~2.5–3.0` 以上后，方可在边缘片段探索基于 `R99` 已校准的 `QRS → PPG 峰 (-80..-172 ms)` 窗口协同权重，且严禁在无局部 QRS 波形证据时以血氧 PR 伪造 ECG 有效标志。

## 五、RR 优化的软件空间与有限提升总结

1. **路线收敛：** `R100`/`R101` 已彻底证明指尖 PPG 提取 RR（`PPG-RR`）因受限于 `~0.1 Hz` 血压/Mayer 慢波统治，**应终止继续投入**；而 **Node-B 胸阻抗 `RESP` 频域谱峰估计** 是正确且值得收口的软件优化方向。
2. **B 板 RESP 还有哪些可落地的软件优化空间：**
   - **以滑窗谱域替代苛刻的时域逐周期稳态门：** `R101`/`R102` 表明 `bio_v2.c` 失效的主因是 `τ=6 s` 去直流导致 `55 s` 阶跃拖尾、高幅值谷峰门槛与零漏检桥接；将其替换为类似 [`resp_r1.py`](analysis-r83-r96/scripts/r98/resp_r1.py) 的 **`32 s` 滑窗 10 Hz 抽取谱峰估计**，仅需约 **`1.3 KiB` SRAM**（现有 `>100 KiB` 充足），且在 Flash 上可用轻量化定频点数 **Goertzel / 实数 DFT** 实现（无需引入整套 FFT 库）安全装入 `8,576 B` 剩余 Flash。
   - **针对 `R102` 失败点的定向微调：**
     1. 改一阶固定超慢去直流为较短周期基线恢复或窗内线性去趋势，摆脱 55 s 大阶跃恢复盲区；
     2. 适度下调 `q >= 0.50` 严苛门槛并改为“锁定态放宽维持 + 次峰抑制比 + 瞬态隔离”（`R102` 中 `P20` 有 `15/24` 窗是因 `q < 0.50` 被拒绝），有望明显抬升 `15–20 /min` 中深规律呼吸的覆盖率并保持极低误报。
3. **为什么 RR 的软件提升注定有限（硬件天花板边界）：**
   - **浅呼吸 SNR 的物理分压制约：** 原理图中 32 kHz 激励通过 `R11/R12 = 39 kΩ` 与 `C9/C14 = 2.2 nF` 对地容抗分压，且当前 `CH1SET=0x40` 仅设增益 `4`，使人体自然浅呼吸幅度（`R89 S4` 定标约 `~0.2–1.0R` 边缘）微弱——即便在 `R102` 谱域下，自然浅呼吸（`R91`/`R94`/`R87`/`R100 N1–N5`）有效覆盖率也只有 **`0.3%–31.8%`**。
   - **慢呼吸与基线漂移频段重合：** `<8–10 /min` 呼吸（`0.13–0.17 Hz`，如 `P10`）与皮肤接触阻抗慢漂移（`0.05–0.12 Hz`）高度重叠，过度下调 `q` 或下放频率下限会直接破坏 `0%` 阴性误报防线。
   - **32 s 频谱窗的响应延迟：** 与逐拍更新不同，频谱窗决定变呼吸率、屏气或体动切换存在十余秒至半分钟滞后；要彻底提升浅呼吸信噪比，最终仍须配合硬件重调 `CH1` 32 kHz RC 网络、评估提高 `CH1SET` 增益（在基线不顶轨前提下）或改为四电极阻抗法。
