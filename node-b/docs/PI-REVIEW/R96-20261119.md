## 3. 解读
1. **为什么救不回来**：
   - 在单拍 SNR 1–2 的数据上，逐拍检测必然错检；
   - 窗内周期估计确实能提取出一部分心率（R94 从约 1% 提高到 17–29%，并且与 PR 基本一致），但它分辨不了“规律的心跳”和“规律的伪迹”。阈值放低，导联断开和接线伪迹段就会报出数值；阈值提高，收益就没了；
   - 这和 R90 的结论一致：只看节律的判据，无法区分规律伪迹和心跳。
2. **门槛 2 的问题（如实说明）**：C2 基线在同一组数据上的一致率也只有 80%。A 的 PR 本身有误差，还有约 1 s 的延迟和平滑，所以 85% 这个绝对门槛对任何候选都偏高。R95 应该写成“不低于 C2”。按“不低于 C2”来看，并联方案（79–81%）算持平。但门槛 1 和 3 本身就不满足，所以结论不变。
3. **可以保留的结论（工程口径）**：
   - 并联方案在 R87 这类 SNR 约 3 的数据上能把有效率从 66% 提到 74%，在 SNR 1–2 的数据上也有 10–17 个百分点的提升，数值基本一致；
   - 代价是在接线伪迹和导联断开时会多报出几秒到十几秒的错误数值；
   - 是否接受这个代价，属于产品取舍，本项目不做。
4. **真正的瓶颈在采集端**：单拍 SNR 需要稳定在约 3。改进方向依次为：
   - 屏蔽导联线，加强 RL 驱动，靠近人体端做抗工频设计；
   - 多导联：换用 ADS1294/1298，或加一颗芯片；
   - 电极位置和皮肤处理的规范化；
   - 在这些改进之后，再引入窗内周期估计。同时要加一个独立的伪迹判别，例如 QRS 形态模板或幅度一致性，或者结合 PPG 交叉验证。

## 4. 结项口径（补充 R91 §4）
- **真人 HR**：只有信号好的一次（R87，单拍 SNR 约 3）板上有效率达到 63%；另外四轮单拍 SNR 只有 0.5–1.8，基本无效；硬件链路经模拟器自检正常（R93）。
- **算法**：
  - C2 已上板，在同一份数据上比 C1 高；
  - C3 研究表明，SNR 1–2 时，现有采集条件下的任何算法都无法在“提高有效率”和“不误报”之间取得满意的平衡。
- **后续改进**：见第 3 节第 4 条。
