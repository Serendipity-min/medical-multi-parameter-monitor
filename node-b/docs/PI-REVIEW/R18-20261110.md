### 3.2 授权对象与上限（沿用 R10 §3.2–3.3 接法）
- 五板 A/B/D/E 与 C 一起上电（与 W3 同接线，**非人体输入**，A 工装**不要求** PPG 有效），C 仅 USB_UART，J-Link 仅 SWD+GND，J5 不接。
- C sector0/4 安装 ≤1 次（验证失败再 ≤1 次）；上电会话 ≤4；热点人工开关 ≤4 次；隔离 Broker ≤2 次运行；**不使用** `FIELD01 START/STOP`（本镜像是生产候选，上电自动运行，该自动运行含在本放行内）。
- **不包含：**sector3/Options/ESP 固件、`AT+UART_DEF`、UART 改速、真人、KEY/音频、**J-Link 复位**（会锁死候选，见 R17 §3-2）。
- 有效期 7 天。

### 3.3 流程（Codex 自治，负责人只拨开关/热点）
1. **安装与冷启动：**仅 C 上电安装、读回；断电后五板全部上电；用**开关断电再上电**得到新启动，COM15 出现即采集；读 60 s 启动摘要。
2. **稳态 ≥ 8 min：**记录 Broker 逐流到达、`B5 DIAG`（DWT、队列、槽位、PUBACK 分布 p50/p95/p99/最大）。
3. **短断网：**热点关 40 s 再开。记录 `GW PASS_*` 序列、重入计数、重连耗时；ESP 是否自行退出透传（**两种结果都可接受，只记录**）。
4. **稳定清零：**重连后保持 ≥ 5 min，应出现 `PASS_REENTRY_STABLE_RESET`。
5. **长断网：**热点关 3 min 再开。期望接入按 2…30 s 退避重试、**不进 LINK 停止**、热点恢复后自行建链。
6. 收尾：开关断电；C 保留候选，是否回退由负责人决定。

### 3.4 预登记预测（不得事后改）
| 项 | 预测 |
|---|---|
| 启动 | 开关 ON 后 ≤15 s 内 `boot_escape=1 boot_at=1`，无 `PASS_BOOT_RESET_LOCKED`；首次入网成功 |
| 稳态 ≥8 min | Broker 实收/C 入队 ≥99%（生产无收尾排空，**全窗计**）；队列高水位 ≤16/24；0 丢弃/0 顶替；UART/CAN 错误 0；非法帧 0 |
| 实收速率 | 与五板输入一致（约 10.4–11 批/s，视 NIBP/事件） |
| 短断网 | 热点恢复后 ≤120 s 重新有数据；重入计数 1；无 `PASS_MODE_UNKNOWN` |
| 清零 | 重连后 300 s 出现 `PASS_REENTRY_STABLE_RESET` |
| 长断网 | 无 LINK 停止；恢复后 ≤90 s 有数据；接入退避不耗额度（`reentries` 不增） |
| 硬/软复位路径 | **预期不触发**；若出现 `PASS_HARD_RESET*`/`PASS_SOFT_RESET*`，逐条记录，不算失败，算重大发现 |
| 数据缺口 | 断网期间与恢复后的缺口、补传量：**只记录** |

### 3.5 停止条件
R10 §3.5 全部沿用，另加：`PASS_BOOT_AT_UNCONFIRMED`、`PASS_BOOT_RESET_LOCKED`、LINK 停止（长断网之外）、`PASS_HARD_RESET_UNAVAILABLE/UNCONFIRMED` 持续、任何异常发热/复位。触发后保存原件、不自动再上电，一次性汇报。

### 3.6 回执
台账（条目数与 SHA）、串口与 Broker 原件 SHA、各步骤时间线（主机单调时钟）、逐流到达、DIAG 摘要、重连耗时表、`GW PASS_*` 全序列、断电口径；**Host/Windows 与实板分栏，推断与实测分栏**。
