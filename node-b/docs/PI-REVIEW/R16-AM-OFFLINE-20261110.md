# R16 WP-AM 入队上界与 QoS1 槽位对照

**连续采样、连接稳定、无故障事件时，常态入队上界为 10.5 批/s。** E 的血压结果按正常 PDO 定时保守计 1 批/s，得到本次离线扫点的 **11.5 批/s**。PPG 分批、节点状态变化和 EMCY 另计。11.5 批/s 是明确定义的运行包络。

## KEY 音频增量

当前透传候选关闭音频，增量为 0。旧有音频构建中，KEY 打开一轮 16 kHz、16 bit、1–2 秒录音，64,000 B PCM 最多切成 125 块。每块应用负载 544 B，按 MQTT QoS1 和现有主题计算，每块上行 564 B，每轮最多 **70,500 B 和 125 个 PUBACK**。语音独立于 Router，医疗入队增量为 0，仍竞争 TX 和 ACK 处理。另有每次建链的订阅控制与每轮成功回复的下行流量。

每次最多一个语音块在途。调度器让路分支检查 250 ms，但空闲主循环也直接调用语音推进，所以 250 ms 不能当作全路径上行硬限。115200 的 8N1 物理线速在只发这种块时约为 20.4 块/s，实际还受命令、ACK 和医疗让路限制。音频与当前透传构建互斥，本次模拟仅给出音频关闭的容量结果。 [音频推进](../../../gateway/microphone/unified_audio.c) · [MQTT 音频路径](../../../gateway/mqtt/src/gateway_transport.c) · [出口仲裁](../../../gateway/b5/egress.h)
