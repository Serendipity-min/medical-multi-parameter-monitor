### 下轮工程建议

当前 B 端用 H/R 判定 CAN 有效位，原因码本身没有送到 C，因此现存 MQTT 和 WSS 无法还原短暂出现的 H。建议下轮单独新增低频诊断消息，带 B 的采样时间、序号、H/R 当前值、ECG 和 RESP 各自的工频占比，以及这一秒内见过的 H/R 原因位按位或的结果。这样能复核短暂的 64，也能与 HR、RR 和波形对齐。正式遥测模型拒绝未知字段，诊断链路需单独审核 B→C→MQTT 的格式、权限和现场范围。R83 未执行此改动。当前 ECG/RESP 录制为 B 侧滤波后波形，用于离线分析时需按该输入语义处理。
