## SOURCE 定位与复测前纠正

PPG 最后一次到达约在 T0+43.134 s，全部 38 批已出队。T0+45 s 至停止没有 PPG，期间 SpO₂ 和 PR 各到 3 批且均为 INVALID。ECG 和 RESP 入队继续增加。CAN1 的 A/E 心跳持续、NMT 仍为 5，boot 计数稳定。没有证据显示出口丢掉了已入队的 PPG。负责人确认 A 屏 PPG 一直在滚动。

A 屏可以在 UNO 的 SpO₂ 暂时无效而原始 IR 和 UNO HR 仍在时继续画波形。A 发送 CAN PPG 的条件更严，`canopen_app_produce()` 要求探头及结果有效、结果新鲜且没有暂停，否则清空 CAN 专用波形环。Host 以真实 A 应用和 CANopenNode 重现：保持输入采样和心跳，模拟 SpO₂ 无效、UNO HR 非零 5.2 s，CAN PPG 停发；恢复有效输入后，PPG 随即恢复。统一 Host 18 组通过，现有 C 侧 5 s 源失活看门狗测试通过。

这个机制与 W2 的记录吻合。现场缺少 A 的 UNO 原始状态、CAN 专用环及 `0x181`/`0x681` 同窗证据，工装耦合、模块出值和 A 端波形输出之间的具体起点仍为 UNKNOWN。复测前把准入从「屏上波形连续」改为「非人体模拟输入连续，A 屏波形、探头状态以及实时 SpO₂/PR 同时稳定」，并用单独获批的源检查确认持续性。若显示持续有效而 CAN PPG 仍停发，先对照 A 的源质量 PDO 与波形 PDO。保留 SOURCE 看门狗和数据有效性语义，冻结固件未改，本批没有再上电。
