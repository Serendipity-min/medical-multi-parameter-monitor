- C 安装 code `056d74e05e3270d4b23e2d03fc74d38b9d81c265f0f33fca3f60fd4833215587`，55,900 B。安装前核对 boot、code、HEX 三项 SHA 及现有 WP-AR 整片读回。只写 sector0/4，整片 Flash 和 Options 写后读回一致，J-Link 会话正常关闭。原生调用为 Halt 1、BeginDownload 1、WriteMem 2、EndDownload 1、Reset 0、Go 0。安装后用板上开关断电，再冷启动。
