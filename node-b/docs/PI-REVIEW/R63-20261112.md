## 3. AZ-0 受阻 → 改走 C 板路径；喇叭安全前提（必须先解决）
- 负责人指示：现场没有 USB-TTL，**先复用之前的路径**，也就是由 C 板直接驱动 TTS 发声（2025-11-02 台架上用过的方式）。这样 AZ-0 的台架项（读法、电流、回码）并入 AZ-3，需要先刷写 C（AZ-3），**须单独放行**。
- **喇叭规格问题**：负责人给出的喇叭是 **8 W / 1 Ω**。常见 TTS 模块的板载功放按 4–8 Ω、0.5–3 W 设计（TW-TTS 的具体规格 UNKNOWN）。接 1 Ω 负载接近短路，可能导致：功放过流或过热损坏；5 V 电源电流尖峰和压降，通过共地干扰 C 和 ESP 的串口（R31 曾记录 ESP 对电气扰动敏感）。**PI 建议**：改用 **4–8 Ω、额定 ≥1 W** 的喇叭；或者先查到 TW-TTS 手册中允许的最低负载阻抗，确认支持 1 Ω 再用。另外请确认 2025-11-02 台架发声时用的是不是这只喇叭。
- 5 V 电源独立供电，与 C 共地；第一次上电时观察模块和喇叭是否发热，用手背接近感受即可。
