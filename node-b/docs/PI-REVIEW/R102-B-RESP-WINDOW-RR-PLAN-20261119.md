# R102 · B 阻抗 RESP 窗内谱峰 RR：离线研究方案（门槛先定）

2026-11-19，PI 签发。负责人原话：“选2，先做B RESP离线研究”。依据为 R101 §4–§5。
- **范围**：只做离线研究，不涉及设备、云端或真人。
- **脚本**：`analysis-r83-r96/scripts/r98/resp_r1.py`、`resp_eval.py`。

## 1. 候选 R1（以下参数在运行任何评估之前写定）
**输入**：B 的 MQTT RESP，即固件滤波后的 r，50 Hz；时间轴用 `load2.py` 按批末时间戳修正。

1. **窗口**：32 s，步长 2 s。窗内样本覆盖不足 90%，或有超过 1 s 的缺口，这个窗就无效。
2. **瞬变门**：窗内 (max−min) > 3×(p95−p5) 时，判为有瞬变，窗无效。
3. **幅度门**：(p95−p5)/2 < 60 r 时，窗无效。约合 0.2 个模拟器 R（按 R91 的约 330 r/R）。
4. **谱峰**：
   - 先去线性趋势、加 Hann 窗，在 0.1–0.7 Hz 内找主峰；
   - 主峰须在 8–39 次/分之间，不能贴着边界；
   - 主峰 ±0.03 Hz 内的功率占带内功率的比例 q ≥ 0.50。
5. **持续**：连续 3 个合格窗的估计两两相差 ≤2 次/分，才输出这 3 个值的中位数；任一窗不合格，立即无输出。
6. **新鲜度**：输出对应最近 32 s 的窗。输入中断或窗不合格，立即失效。

## 2. 数据集
- **阳性（模拟器，有真值）**：R89 S4 定标的干净段（R91 §2 第 1 条的表）：
  - 1.5R、20 次/分；
  - 1.0R、20 次/分；
  - 1.0R、12 次/分；
  - 0.5R、20 次/分，只记录。
- **阴性**：
  - R92 自检中模拟器 ECG 模式段（没有呼吸输出）：16:31:00–16:33:50，以及晃线、拉夹段 16:33:50–16:42:00；
  - R83 导联断开到贴电极：15:00:15–15:04:00；
  - R89 S4 中切换设置时的大瞬变段：18:12:40–18:13:14、18:14:30–18:15:40；
  - 合成噪声：白噪声经 0.8 Hz 低通后，取 r 幅度约 200 的量级，20 个种子，各 300 s。
- **开发集（真人，已经看过，不能当独立检验）**：R100 的 P10、P15、P20 段。
- **真人只报告、不判定**：R87、R89 S5、R91、R94 的自然呼吸段（没有真值），只报覆盖率和数值分布。

## 3. 门槛（离线阶段，全部满足才进入真值采集）
1. **阳性**：1.5R@20、1.0R@20、1.0R@12 三段，每段的输出覆盖 ≥80%，输出全部在真值 ±1 次/分以内。
2. **阴性**：
   - R92 的 ECG 模式段和晃线段、R83 的导联断开段、R89 S4 的瞬变段：**输出为 0%**；
   - 合成噪声：输出 ≤1%。
3. **开发集**：R100 的 P15、P20 两段，每段覆盖 ≥60%，并且输出 ≥90% 在 ±2 以内。P10 只记录。
4. **资源**：在 B 上，32 s 窗按 10 Hz 抽取约为 320 点，需约 1.3 KB 浮点缓存，每 2 s 做一次小规模 DFT。离线阶段只做估算，C 实现在通过之后再写。

**全部满足**：PI 写独立的真值采集卡（新志愿者或同一志愿者，加 12 次/分节拍段和较浅的自然呼吸段，**必须报人工计数**），门槛沿用 R100 §4，并加上“自然呼吸段与人工计数相差 ≤3 次/分的比例 ≥80%”。

**不满足**：把 R1 写进结项文档的“后续改进”，不做采集。

## 4. 结果（2026-11-19，`results/r102_resp_r1.txt`、`r102_resp_r1_amended.txt`）
- **原方案评估**：R1 按 §1 原样运行，门槛按 §3。
- **修订评估**：看过原方案结果后补做，**只**把重放的缺口容忍放宽为“覆盖 ≥75%、单个缺口 ≤2.5 s”，用来抵消 MQTT 丢批；算法参数和门槛都不变，所有数据集一起重跑。

| 项 | 原方案 | 修订 | 门槛 |
|---|---|---|---|
| 模拟器 1.5R@20 | 0%（覆盖不足） | 0%（覆盖不足） | 覆盖 ≥80%，误差 ±1 |
| 模拟器 1.0R@20 | 段长只有 30 s，放不下一个 32 s 窗 | 同左 | 同上 |
| 模拟器 1.0R@12 | 0%（覆盖不足） | **78.6%，全部为 12.0** | 同上 |
| 阴性：R92 无呼吸、晃线，R83 导联断开，R89 瞬变 | **全部 0%** | **全部 0%** | 0% |
| 合成噪声（20 个种子） | 0.19% | 0.19% | ≤1% |
| 开发集 R100 P15 | 58.3%，100% 在 ±2 以内 | 同左 | 覆盖 ≥60%，≥90% 在 ±2 以内 |
| 开发集 R100 P20 | 20.8%，100% 在 ±2 以内 | 同左 | 同上 |
| R100 P10 | 0%（主峰贴着频带边界） | 同左 | 只记录 |

**自然呼吸（没有真值，只报告）**，修订评估下有输出的窗：
- R89 S5：32%，数值 13.6–18.4；
- R87：18%；
- R100 N1–N5：27%，数值 12.6–15.5；
- R91、R94：不到 3%。

**判定：FAIL**，原因是覆盖不足：模拟器阳性段评估不了或差一点；开发集 P15 差 1.7 个百分点，P20 差得较多。

**特点**：
- 所有阴性对照零输出；
- 凡是有输出的地方，数值都正确：模拟器 12.0，P15 为 14.9–15.2，P20 为 18.2–18.4；
- 也就是说，R1 **不误报但保守**。失败的主要原因是谱峰占比门槛 q≥0.5，在真人 20 次/分时过严；另外 MQTT 丢批让模拟器阳性段无法评估。

**按 §3，不做采集**，R1 写进后续改进。是否在开发集上下调 q 再做一轮（必须另做独立的真值采集来检验），由负责人决定。
