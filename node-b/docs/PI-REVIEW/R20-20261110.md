## 3. 裁定与一个观察点
**WP-AQ ACCEPT（Host）。** 修复范围小，不屏蔽基线之后的真错误，风暴有上限，基线值通过 `boot_uart_err0` 保持可见。

**观察点：**静默判据（200 ms 无 RX 无新错误）可能落在 ESP 的"ROM 日志结束 → AT 固件 `ready`"之间的间隙。若如此，后续转义的 1,001 ms 静默期内 `ready` 行会被当残留丢弃，AT 仍应在随后确认；但这是 Host 夹具不模拟的真实时序。S1b 若 `boot_at=1` 但耗时偏长，不算失败，记录即可。
