## WP-AD / WP-AF 补充

窗 B 末次增加前的 DWT 快照在 T0+140.201 s，累计服务峰值为 48,553 周期。T0+150.131 s 首次读到 169,670 周期（21.21 ms）。服务峰值于 T0 清零，因此峰值属于这个末段区间。两份快照跨越 142 s 停发和 150 s STOP，证据无法在排空与 STOP 回调间进一步定位。`service()` 可调用 `stop()`，后者含队列切换、CAN 停止和串口报告，均是后续分段 DWT 的观测点。 [R11 分段插桩与 DMA 设计](R11-OFFLINE-NOTES-20261109.md)

W3 安装计划已做离线核验，目标为 C 的 sector0/4。现场仍需 PI 独立位级复核及负责人按完整 SHA 放行一次安装与一次五板窗口。工作段按 R12 预登记判读，收尾段单列；容量上限与 300 秒完整性尚待后续批次。
