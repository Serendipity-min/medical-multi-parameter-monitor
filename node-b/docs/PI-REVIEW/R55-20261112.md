**允许**
- C 使用**当前正式镜像**（code `125c4b61…`）正常上电和断电，最多 3 个上电周期。A/B/D/E 按正式接线正常工作。
- 体温：把 D 探头放在皮肤或固定物体上，连续 **≥7 min**（覆盖首条播报和第一次 5 min 限频后的第二条）。
- NIBP（**仅在有真人时**）：在 E 板操作屏上按正常流程启动，**最多 2 次，两次间隔 ≥2 min**，袖带按说明书佩戴。
- 页面：在正式大屏或浏览器中点一次"朗读播报"，听一条完整播报；可以展开历史查看。
- webai：在 LIVE 状态下做 1 次只读快照检查（健康接口或现有的只读快照读取），确认新增字段后仍能读取。

**禁止**
- 刷写任何板子，或写任何 Flash（包括 C 的 sector3 和 Options）；通过串口或远程发送 START、调试或写入命令。
- 改动服务器配置（S4-B 范围之外）；打开 HR 播报。
- 人为制造异常读数，比如压迫手指、屏住呼吸、反复测血压；SpO₂/PR 持续越界只用离线序列覆盖（R54 §3）。
- 用演示模式或 MOCK 数据作为证据。

**停止条件**（立即停止并保留现场，不在现场改代码）
- 电气异常（发热、异味、冒烟），或受测者不适：立即断电或给袖带放气。
- 播报出现禁用词或分类错误；由非 LIVE 数据触发播报；断电后 20 s 内没有清空；复电后补播旧播报；播报进入报警区或触发报警。
- 后端健康状态不是 `ok`，或服务重启循环：执行 §3.5 回滚。
- 窗口总时长上限 60 min。

**通过标准**
1. 上电并进入 LIVE 后，体温连续 VALID 满 60 s（允许误差为一次心跳周期），出现 1 条 TEMP 播报，播报中的数值与页面显示的体温相差 ≤0.1 °C；约 5 min 后出现第二条，期间不重复播报。
2. （有真人时）每个 NIBP 结果恰好产生 1 条播报，分类与 E 屏读数按 R54 §1 判定的结果一致。
3. 断电后，网关 OFFLINE ≤20 s，`broadcast` 变为 null、`broadcast_history` 变为空数组，页面播报条隐藏；复电后，前 60 s 内没有任何旧播报重新出现。
4. 朗读：开启后每条播报只读一次，读出内容包括免责声明；播报不进入报警区。

**证据分工**
- PI：在 VPS 上无令牌记录正式 WSS 快照摘要（每秒 1 行：网关状态、标量、播报和历史 id），覆盖整个窗口。
- 现场（负责人 / Codex）：时间线（上电、放置探头、NIBP、断电的时刻），页面截图或录屏，NIBP 读数时的 E 屏照片，webai 检查结果。回执写在 codex 分支，命名为 `R55-WP-AY-S4-W-RECEIPT-…`。
- 开窗前通知 PI 启动记录，结束后通知 PI 停止。PI 对照两边记录完成复核，WP-AY 判定 PASS 或 NOT_PASS。
