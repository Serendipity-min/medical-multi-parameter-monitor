## 2. 实现要求
1. **冻结源码不动。** 在 `node-b/tools/build_b4_arm.py` 中新增 `--diag-reason` 开关（默认关闭）。开启时，对构建副本里的 `HARDWARE/hr_page.c` 做一次 `replace_once` 注入：
   - 锚点为 `TxtGB(HP_SCR_PROBE, HP_TXT5_ADVICE, adv);`（必须唯一）。
   - 替换后把下面的诊断串写入同一控件 `HP_TXT5_ADVICE`（探头页“处理建议”，控件 12），其他控件不变。
2. **诊断串格式**（纯 ASCII，最长 26 字节）：`H%lu R%lu M%u/%u E%lu`。
   - **H**：`g_bio_v2.hr_reason`；
   - **R**：`g_bio_v2.rpm_reason`；
   - **M**：`ecg_mains_fraction` 和 `resp_mains_fraction` 乘 100 四舍五入，钳位在 0–100；
   - **E**：`ecg_rms_codes` 取整，钳位在 999999。
   - **不用浮点 printf**，先转成整数再输出。
   - 示例：`H66 R6 M97/12 E1234`；最长：`H255 R255 M100/100 E999999`。
3. **刷新**：沿用 `ProbePageRefresh` 现有的 1 s 周期，不新增定时器或任务。只在探头页（screen 5）显示。
4. **测试**：
   - 新增主机测试（例如 `node-b/tests/test_build_b4_diag_reason.py`），覆盖三点：注入锚点唯一；不加开关时副本与原逻辑一致；最坏值格式化后不超过 26 字节。
   - BIO_V2 算法没有改动，`run_host.py` 不需要重跑。
5. **构建门槛**（任一项不满足就 STOP，不下载）：
   1. 冻结源码检查通过。
   2. **可复现性**：同一环境下只加 `--candidate-r6` 构建，BIN 必须与 `f2276540…` 逐字节一致。不一致时上报差异，不继续。
   3. 带 `--candidate-r6 --diag-reason` 构建：
      - 退出码 0；
      - BIN 不超过 **49,152 B**，确保仍只占 sector0–2；
      - 记录 BIN/AXF/MAP 的 SHA-256，以及 Code/RO/RW/ZI 资源用量。
6. **安装器**：
   - 仿照 `b5_b_temp_update.py` 新建一个 scope，绑定三个基线：写前应用区 `f2276540…`（前 40,040 B）、写前整片 `328d48e3…`、新候选的 SHA 和字节数。
   - 扇区固定为 [0,1,2]；写后核对整片、options、身份，以及 sector3–11 不变。
   - 默认禁用，需要显式传入 `--execute` 和授权文件。
   - 写前整片读回原件就是回退包，存入受限 EFS，不入库。
7. **分支**：基于 `claude/closeout-ai-wss-test-fix` 中包含本卡的提交，建 `codex/r78-b-diag-reason`。代码、测试和回执放同一分支。不合并，不建 PR。

## 3. 现场步骤（负责人通知后执行）
**S0 准备。** 只给 B 上电，A、C、D、E 和 GT 保持断电。不接触人体，所以本轮 B 和电脑可以用市电。B 接 ECG 模拟器。J-Link 只接 B 的 SWD/GND。

**S1 写前核对。**
- 整片读回两次，两次必须一致。
- 读回的应用区（前 40,040 B）必须等于 `f2276540…`，整片必须等于 `328d48e3…`。
- 任一项不符：STOP，保存原件，不写入。

**S2 写入。**
- 一次写入 sector0–2，写后整片读回核对，确认 options 和身份不变、sector3–11 不变。
- 安装器按标准流程 Reset/Go，然后 Close。
- 物理拔掉 J-Link。

**S3 本地验收（模拟器，不接触人体）。**
1. B 断电再上电。主页 HR 显示 60，有 ECG 波形，与改动前一致。
2. 切到探头页，“处理建议”处显示诊断串，每秒刷新，例如 `H0 R0 M../.. E....`。拍照记录。
3. 断开模拟器的 ECG 导联 30 s（这是传感器输入，不是 CAN 故障注入）。H 应变为非 0 值（预期含 2 或 8），拍照。
4. 重新接上导联，H 应在约 10 s 内回到 0，主页 HR 恢复 60，拍照。
5. 其他页面、报警和蜂鸣与改动前一致。

**S4（可选）云端不变性。**
- 提前 5 分钟通知 PI，PI 开始录 WSS。
- 按 GT → B → C 上电，A、D、E 断电。
- PI 核对 B 的 HR 和 ECG 在云端为 VALID、HR 为 60，证明 CAN 和云端链路不变。
- 完成后按 C → B → GT 断电。

**S5 收尾。** 全部断电，接线保持不变。

## 4. 停止条件（STOP_TARGET）
以下任一情况：立即停止目标侧动作，保存原件，不重试，不额外执行 Go 或 Reset：
- 构建门槛任一项失败（不下载）；
- 写前核对不符；
- 出现 HALT 或 ROM，身份或 Flash 漂移，写后核对失败；
- 安装后 B 屏不亮、反复复位，或主页 HR/波形与改动前不同。

只有负责人已按 §0 授权回退时，才可以用写前原件恢复 sector0–2 一次，并核对整片等于 `328d48e3…`。

## 6. 原因码速查（现场判读用，`bio_v2.h:8-15`）
H 和 R 是十进制位掩码，可以叠加，例如 66 = 64 + 2：

| 位值 | 含义 |
|---|---|
| 1 | 预热（HR 5 s，RR 10 s） |
| 2 | 周期不足 |
| 4 | 周期不稳（超出 ±20%） |
| 8 | 超时 |
| 16 | 断帧 |
| 32 | 削顶 |
| **64** | **工频** |
| 128 | 宽带噪声（只用于 RR） |

M 是工频占比。**M ≥ 95，且 H 含 64，就证实 R77 的工频假设。**
