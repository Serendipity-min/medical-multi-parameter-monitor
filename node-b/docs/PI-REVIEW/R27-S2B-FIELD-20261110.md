# R27 S2-b 断链诊断回执

**15 分钟诊断窗口完成，复现两次非人工断链。** Mosquitto 原生原因分别为 MQTT 协议错误和畸形报文。两次均为 Broker 对同一 C 客户端记录的判定。 [R27 批次卡](https://github.com/Serendipity-min/medical-multi-parameter-monitor/blob/3c32b22/node-b/docs/PI-REVIEW/R27-20261110.md) · [既有五次断链离线追查](R27-DISCONNECT-OFFLINE-20261110.md)

## 日志与范围

使用 C 已有的 S2 候选，code SHA `056d74e05e3270d4b23e2d03fc74d38b9d81c265f0f33fca3f60fd4833215587`。此次使用隔离 Broker 1 次、五板冷启动 1 次、窗口内热点切换 0 次。全程非人体工装，安装、J-Link 复位、START 和血压泵均为 0。

独立临时配置开启 `connection_messages true`，将 `error/warning/notice/information` 输出到服务 journal。上电前已核验隔离 TLS、认证、观察账号写入拒绝，以及两次预检连接和断开的 journal 行。订阅记录采用十六进制载荷保存，最终逐条核对原字节与解码副本。第一次观察器 SSH 连接关闭，第二次在同一次 Broker 运行中取得 SUBACK 后才进入窗口。

## 断链证据

从 C 首次记录 MQTT 建链到断电提示为 **909.313 s**。下表以该建链时刻为零点。Broker 原生行与遗嘱使用同一 VPS 时钟，C 时刻使用主机采样对齐，最小 RTT 845.888 ms。

| 次数 | 遗嘱相对首次建链 | Mosquitto 原因 | 原生原因行相对遗嘱 | 遗嘱至 C 开始退出 | C 开始退出至重连 |
| --- | ---: | --- | ---: | ---: | ---: |
| 1 | +441.345 s | `Client [C] disconnected due to protocol error.` | +0.305 ms | 5.657 s | 17.610 s |
| 2 | +622.151 s | `Client [C] disconnected due to malformed packet.` | −0.197 ms | 6.460 s | 29.781 s |

两次都自动恢复，全程未触发 LINK 锁存。断电确认之后 Broker 另记录 C 的 keepalive 超时，属于停机收尾。观察器先退出，因此订阅原件只有两条窗内非人工断链遗嘱。

订阅端收到的 **9,768 条载荷全部可解析为 JSON**。Broker 在订阅交付之前拒绝的字节无法从订阅原件重建。原生原因支持 R27 的 MQTT 报文异常分支，并与旧 S2 的 PPG/RESP 载荷拼接相呼应。故障字节产生的位置仍为 UNKNOWN，现有证据未区分 STM32 TX、ESP 接收和 ESP 透传内部路径。
