**旁证也一致**：
- W5 取下红夹，仍能稳定测到 60 bpm，说明红夹是右腿驱动 RLD，少了它只是失去共模驱动。

**附带结果**：W0 与 W2 都是 −144 µV，说明模拟器的 RL 端子在内部与 LL 等效。W0 测到的其实是 LA−LL，即 −III 导联。W1、W3 是 I 导联，+352 µV。

## 2. 结论（事实）
- **对应关系**：导联线 **绿（F）→ ERA（RA，IN2N）、黄（L）→ ELA（LA，IN2P）、红（R）→ RLD（右腿驱动）**，与厂家例程注释和照片一致。项目一直沿用的“红 R→RA、绿 F→RL”是错的。
- **验证方式的局限**：这是功能性验证，用的是模拟器的极性、幅度和取下单根夹子的反应，不是万用表通断测量。不过三类现象相互独立又彼此一致，足以据此改正接法。

## 3. 对既往结果的重新解读
- **R83 踝部**（负责人确认完全照厂家照片贴）：实际是**标准 II 导联**（右腕 → 左踝），是唯一一次方向正确的真人采集，主峰 77% 正向，HR 约 60% 有效。R85 §1 说“两踝之间”是错的。
- **R85 双腕**：ERA 实际在右踝，测的是左腕 − 右踝，约为 −III 导联，所以偏弱、没有主导极性。
- **R87、R89、R91、R94 胸前 P2**（负责人确认红夹贴右锁骨下、绿夹贴右下腹）：ERA 实际在**右下腹**，右锁骨下那片是右腿驱动。测量方向是右下腹到左下胸，几乎垂直于心电轴，所以：
  - QRS 小，只有 80–600 µV，而且三相、多为负向；
  - 对贴片位置极其敏感，同一人两次相差 7 倍；
  - 单拍 SNR 只有 0.5–3。
  - 这些都是测量方向的问题，不是采集硬件或算法的问题。
- **阻抗呼吸**：CH1 在 ERA–ELA 之间测阻抗，P2 的实际路径是右下腹到左下胸。R100、R102 的 RESP 结果也是在这条路径上得到的。
- **R93 S6 需更正**：当时“取下 F（RL）夹”实际取下的是 **ERA**，所以那次的工频暴增和带内 8.7 mV 都是输入悬空造成的，**不能**用来说明“失去右腿驱动后工频升高 1000 倍”。ECG-RR-CEILING 原文 §三.2 和 R103 引用了这一条，需要同步更正。
- **不受影响**：模拟器链路自检的幅度、噪声、HR 结论（R92、R93 S2），以及固件等价性的结论（R103–R105），都与导联方向无关。
- **其他文档**：`02_模块资料与接线.md`、`B-ALG-002-CONNECTOR-REVIEW-R2.md` 中“R→ERA、F→RLD”的设计映射需要更正。B-ALG-002 阶段的模拟器 RESP 试验也是按旧接法做的，引用时要注意。
