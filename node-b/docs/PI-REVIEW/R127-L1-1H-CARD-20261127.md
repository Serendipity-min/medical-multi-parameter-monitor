## 0. 目的、授权与边界

- **目的**：
  - 在五板全开、真人测量与模拟器信号同时存在的条件下，连续运行 1 小时，检验：
    - 稳定性：节点不意外重启，断链能自动恢复；
    - 数据完整性：标量覆盖率，以及上传连续性；
    - 各通道链路一致性。
  - 用 USB-TTL 录下 C 的串口日志，为 R126 中两次网关掉线找原因。
- **镜像**：五块板全部保持现装镜像（B 为 R125 K5 `9619761b…`），**本卡不刷写任何板**。
- **放行**：已获“放行 R127 长测，志愿者随机”（修订 1）。实际参与的志愿者代号由负责人在现场报告。
  - 本卡的人体接触为指夹、袖带和红外测温，不贴电极。
  - 只在 §3 的测量时点接触：每个时点约 2–3 分钟，共 6 个时点，累计约 15–20 分钟，在以往卡片“累计接触 ≤30 分钟”以内。
- **录制**：一次只读 MQTT 录制，前缀 `r127l1`，上限 90 分钟。
  - **订阅须覆盖 `mpm/v1/GW-C-001/#`**，即包括 NODE-D、NODE-E 和网关状态；R125 的录制只含 A、B。
  - 一次 C 串口被动录制，见 §2。
- **不在范围**：
  - 刷写、回退；
  - 改 sector3、云端配置或网络；
  - 电极接触人体；
  - 2 h 和 24 h 长测（负责人决定只做 1 h，24 h 记为 NOT_RUN，已接受）。

**电气安全**：
- 电脑全程拔掉充电器，用电池供电。USB-TTL 的地经 C、CAN 与各板相连，志愿者接触 A 的指夹和 E 的袖带。

- 有任何不适、袖带不放气、发热或异味，立即停止测量并断电，然后报时刻。

## 2. C 串口被动录制（开测前先验证）

- **接线**：USB-TTL 的 **RXD 接 C 的 PA9（USART1_TX）**，**GND 接 GND**。TXD 和 VCC 不接。不用 C 板载的 USB 口。
- **串口参数**：115200，8N1，无流控。原件保存为 `r127l1-…-c-comNN-raw.bin`，另存接收时刻索引 `…-receive.jsonl`，格式同 R125。
- **预检**：R125 的 COM18 录到 10:18:56 就异常中断了。所以 C 上电后，先确认连续接收 **5 分钟**无中断，再开始计时。
  - 预检不通过：换线或换 USB 口，最多重试两次。
  - 仍不通过：串口记为 NOT_RUN，其余照常进行。

## 3. 步骤（每一步都报时刻，精确到秒）

1. **S0**：PI 开 WSS 监看；Codex 启动 `r127l1` 录制，同时开串口录制。
2. **S1**：按 GT → A、B、D、E → C 上电。PI 确认五个节点在线。然后做 §2 的串口预检。
3. **S2**：B 接模拟器 ECG 60 bpm，**这一刻记为 W0，窗口开始**。志愿者此时不接触。
4. **S3 ECG 段**：W0 到 W0+25 min，ECG 60 bpm。
5. **S4 换接线**：W0+25 min 时 B 断电，改 RESP 接线（1.0R），再上电，报两个时刻。
6. **S5 RESP 段**：上电起到 W0+45 min 为 20 次/分；随后**只在模拟器上**改为 12 次/分（B 不断电），持续到 W0+60 min。每次改档都报时刻和屏上 RR。
7. **测量时点**：W0+5、+15、+25、+35、+45、+55 min，共 6 个。每个时点依次做：
   - 戴指夹，A 屏出数后报 SpO₂/PR 和时刻，约 1 分钟后摘下；
   - 测温，报 D 屏读数和时刻；
   - 测一次血压，结果出来后报时刻和屏上 SYS/DIA，然后取下袖带。

   两次血压之间至少间隔 5 分钟。
8. **每个时点同时报**：B 屏的 HR 或 RR，以及网页上网关和五个节点是否都在线。
9. **S6 收尾**：W0+60 min 结束窗口，先摘指夹和袖带，再按 C → A、B、D、E → GT 断电。Codex 停止两份录制并交付原件和 SHA。

**任何卡外事件**都要记录时刻，例如误碰、断电、热点异常、网页掉线、志愿者离开。判读时按记录对症。

## 4. 判定（脚本 `r128_l1_eval.py`，采集前提交；采集后只填现场记录 JSON）

- **现场记录 JSON 的字段**：`window [W0, W0+60 min]`、`ecg`、`resp`、`power`（B 的换线断电等人为断电）、`nibp`（每次的时刻与屏上读数）、`serial`、`serial_index`。
- **判据**（七项全部满足为 PASS）：

| 编号 | 判据 | 门槛 |
|---|---|---|
| G1 | 节点不意外重启 | 各节点会话变化只能出现在已登记断电时刻的 ±60 s 内 |
| G2 | 断链自恢复 | 遥测收包间隔超过 5 s 计一次中断；每次都须在 ≤180 s 内自行恢复，合计 ≤5% 窗口时长（3 min） |
| G3 | 标量覆盖（按 2 s 分格，剔除中断和断电时段） | SpO₂、PR、TEMP ≥99%；B 的 HR、RR ≥90% |
| G4 | 模拟器数值 | ECG 段自开始 +60 s 起 HR 有效 ≥90%，全部在 60 ± 2；RESP 各档自开始 +45 s 起 RR 有效 ≥80%，全部在设定值 ±1 |
| G5 | 无错误有效值 | ECG 段内 RR 有效帧为 0；全程各标量“有效的 0”为 0 |
| G6 | 波形 | 各段本段信号 VALID ≥95%；剔除中断后 ECG 丢失 ≤7%；缺口 ≥20 个时，2 s 周期 ≤5% |
| G7 | NIBP 链路 | 每次屏上读数在 ±120 s 内都有一致的 MQTT 有效帧（±1 mmHg） |

- **G3 中 B 的门槛为什么是 90%**：在 R125 的两份录制上试跑，B 的 HR/RR 按 2 s 分格的覆盖率为 93–95%（`results/r128_l1_dryrun_*.txt`），A 的 SpO₂/PR 为 100%。B 的标量存在 2 s 以上的空洞，原因未查明，可能需要 C 串口诊断（例如未授时帧计数）才能分清，列为已知限制。门槛依据已有数据确定，并在本次采集前写定。
- **只记录**：
  - SpO₂/PR/TEMP 的有效率与 5/50/95 分位数（只在测量时点有效；没有参照仪器，不判精度）；
  - NIBP 的次数；
  - 每次中断的起止时刻；
  - C 串口的覆盖范围，以及中断前后 ±30 s 的日志行。
- **试跑**：判读脚本已在 R125 的两份录制上试跑，能完整执行。试跑判 FAIL 在预期之内：那两份录制没有 D、E 的主题，也没有 NIBP 记录，各段时刻也不是为本卡划定的。
