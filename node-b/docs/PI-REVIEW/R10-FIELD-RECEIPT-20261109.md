## 停止与现场判断

| 事务 | 结果 | 可核对的证据 |
| --- | --- | --- |
| W1 上电协调 | NOT_RUN | 首次回复晚于协调窗口，检查当时 COM15 未枚举，随后曾枚举。已确认断电，未复位或发 START。 |
| W1-A | STOP / SOURCE | 主机观察 T0 后 5.000 s 锁存 `reason=15`。PPG 入队为 0，ECG 入队 11 批、RESP 入队 5 批。对端 SpO₂、PR 各 4 批，均为 INVALID。负责人事后报告第一次很可能未及时装好模拟工装。 |
| W1-B | STOP / LINK | 主机观察 T0 后 4.000 s 锁存 `reason=13`。停止快照中 A 的 NMT 从 5 到 0、`observed_boot` 从 1 到 3，C 的 `network_fault=0`。负责人确认窗口内操作过 A 的电源或复位，并确认 PPG 传感器未供电。 |
| W1-C | NOT_RUN / PRE-T0 | 现场确认 A 有连续 PPG。C 接受 START 并入网，9 次 SNTP 查询返回的时间均低于有效 UTC 范围。START 在 COM15 枚举后 25.921 s 发出，主机启动预算只余约 19.2 s。主机到期发送 STOP，未收到 T0 或固件 STOP 回执，对端捕获 0 批。 |
| W1-D | STOP / TLS → LINK，PRE-T0 | 现场确认 A 有连续 PPG，C 上电触发主机开串口、纯复位并绑定横幅。START 在 COM15 枚举后 1.500 s 发出。SNTP 第 13 次查询取得有效 UTC，历时 24.015 s。其后 `GW FAIL TLS`、`reason=13`，没有 T0，对端捕获 0 批。 |
| W2 | NOT_RUN | F-P230 冻结制品已核验。W1 未达到完成门控，现场追加事务均只覆盖 W1。 |

`SOURCE` 看门狗检查 ECG、RESP、PPG 每一路的入队计数。A 的标量包可以定时发送而不携带有效值。A 端 `canopen_app_produce()` 依赖探头有效、测量新鲜和独立 CAN 波形环才发 PPG TPDO1。R10 的 C 串口没有保留 A 的逐 PDO 计数，无法仅凭 W1-A 区分模块输入不足和后续波形路径筛除。W1-B 的 A 状态变化与现场电源或复位操作吻合。W1-C 截止时仍处于授时阶段，无法区分暂时的授时延迟与持续不可用。

W1-D 在有效 UTC 和 SSL 参数设置之后停在 `AT+CIPSTART` 的 TLS 步骤。`GW FAIL TLS` 没有子码。留存的 Broker 日志没有给出本次握手归因，DNS、TCP 和 TLS 之间的失败边界仍为 UNKNOWN。固件还报告关闭未确认，现场随后已全部断电。W1-D 证明提前触发能给授时留出时间，这次遥测窗口仍未开始。
