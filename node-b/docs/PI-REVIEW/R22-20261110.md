## 1. S1b-2 裁定：PASS（长断网恢复）

镜像 `fd8479b4…0597`，安装 0、J-Link 复位 0、START 0、上电 1、热点切换 4、Broker 1，均在 R21 批次卡额度内。

### 1.1 对照 R21 §2.1 预登记
| 项 | 预测 | 实测 | 判定 |
|---|---|---|---|
| 长断网无 LINK 停止 | 无 | 无；无 PF6/软复位 | 达到 |
| `ACQUIRE_BACKOFF` 递增 | 2→4→8→16→30 s | 2.015/4.000/8.000/16.000/30.000/30.016/30.000 s（7 次） | 达到 |
| `reentries` 不增加 | 不增加 | 仅一次 `REENTRY_ATTEMPT`，之后 7 次失败无第二次 | 达到 |
| 恢复 ≤90 s | ≤90 s | 回执后 14.6 s 首条新消息、15.7 s 首条实时遥测 | 达到 |
| 恢复后队列 ≤16/24、0 丢弃 | ≤16/24、0/0 | DIAG 采样最大 2/24；600 s 内丢弃/顶替无新增 | 见 §1.2 |
| UART 增量 | 0 | 0（始终 223） | 达到 |
| `boot_uart_err0`（第三次冷启动） | ≈220 | **223** | 达到 |
| 300 s 清零 | 出现 | 重连后 300.031 s | 达到 |

- **断网实际 210.685 s，不是 3 分钟。** 物理切换时刻没有独立测量，回执已如实写明。这比目标更长，对恢复路径更严，不影响判定。
- **三次冷启动的 `boot_uart_err0` 为 225/222/223，之后恒定。** 与"ESP8266 ROM 在 74880 波特率打印固定长度日志"相容，仍是"相容、未证实"。
- **第 7 次失败之后第 8 次成功**，从 `REENTRY_ATTEMPT`（212.8 s）到 `REENTRY_OK`（444.0 s）；其间无任何 `PASS_MODE_UNKNOWN`。R17 的退避修复（获取失败不耗额度）现已有 3 轮和 7 轮两次实板证据。
- **"队列 ≤16/24"只能判采样值。** 稳定段 DIAG 每 5 s 采样一次，最大 2/24；回执自己也把独立峰值列为 UNKNOWN。丢弃/顶替是单调累计计数，窗内零增量是精确的，因此"稳态无溢出"成立，但高水位判据不记为严格 PASS。
- **补传阶段累计高水位 21/24**，是回补期间的读数，不计稳态。

### 1.2 恢复后 600 s 稳态（PI 重算名义速率）
| 流 | 到达 | 名义 | 比例 |
|---|---:|---:|---:|
| ECG（100 点/批） | 1,501 | 1,500 | 100.1% |
| HR / SpO₂ / PR / RR / 温度 | 600 | 600 | 100% |
| RESP | 601 | 600 | 100.2% |
| **PPG** | **587** | 600 | **97.8%** |
| 状态（A/B/D/E/C） | 120×5 | 120 | 100% |

- 总速率 **10.482 条/s**，与此前 10.456、10.458 一致。
- **PPG 在 S1b（467/480=97.3%）和 S1b-2（587/600=97.8%）两个窗口都缺约 2.2–2.7%。** 传输侧两次都是 0 丢弃，因此归因于 A 的源头间断仍是推断；两次一致说明它是**稳定特征而非偶发**，值得单独立项（见 §3）。
- 以名义速率为基准的推算，不是固件内部的实收/入队比。

### 1.3 断网期间的数据缺口（当前实测行为）
| | S1b（约 57 s） | S1b-2（约 210 s） |
|---|---:|---:|
| 补传 | 58 | 56 |
| 设备累计丢弃/顶替 | 220/10 | 185/8 |
| 遥测空档（Broker 视角） | 72.7 s | 241.6 s |
| 按名义速率该产生的批数 | 约 595 | 约 2,190 |
| 计数能对上的批数（补传+丢弃+顶替） | 288 | 249 |

- **两次的补传条数都约 56–58，说明缓存上限与断网时长无关，约为一个固定容量。**
- **计数对不上：** S1b-2 约 2,190 批中只有 249 批被"补传/丢弃/顶替"计数覆盖，约 89% 的批没有出现在任何一个计数里（S1b 约 52%）。原因 UNKNOWN。候选解释（均未证实）：断网重连期间 CAN 入口、路由器或会话获取阶段不入队；或丢弃计数只覆盖某些流。**不要在此解释上做设计结论。** WP-AR 的 `enqueued` 与分流计数正是为此设计，下一个窗口可以直接闭合账目。
- 无论怎样，**"设备侧在断网 >1 分钟时有大缺口"是实测事实**，需要负责人给出保留要求（§4）。

### 1.4 仍不签
容量 PASS 和五板 300 s 完整性（RESP/RR 的 VALID 比例、A 输入证据、非人体工装）；真实 PF6 复位；ESP 是否在 `+++` 前已自行退出透传（UNKNOWN）；USART3 冷启动错误的电气来源。
