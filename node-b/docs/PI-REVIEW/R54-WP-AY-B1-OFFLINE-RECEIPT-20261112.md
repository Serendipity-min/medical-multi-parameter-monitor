2026-11-12。依据 [R54 §0–§2、§5](https://github.com/Serendipity-min/medical-multi-parameter-monitor/blob/26b8380/node-b/docs/PI-REVIEW/R54-WP-AY-CARD-20261112.md)。基线 `2ac41a1`，源码提交 `d30f7e7ae848b7557d5071257e24760abf4ca5a7`。本轮只做 B1，未部署或重启服务，未修改 VPS 环境配置，未连接 C 或写 Flash。

## 行为

- 后端启动时读取 `MONITOR_BROADCAST=1`，HR 另由 `MONITOR_BROADCAST_HR=1` 启用，两项默认关闭。仅正式网关 `GW-C-001` 的合格采集帧可以产生播报。正式固件的合成状态帧仅用于连通性和会话门禁。规则引擎全程确定性执行。
- 采集时间用于数据新鲜度判断，持续时间、滚动窗和限频使用可注入的单调时钟。连续读数按现有快照的 5 秒新鲜度判断。60 秒窗口形成后才开始累计越界时长。连续数据过期时清空窗口，网关离线、心跳失效或换会话时也清空播报历史。重连等待新的网关心跳，旧读数不补播。
- NIBP 以采集会话和结果时间去重，年龄须小于 90 秒，按新结果计次，混合高低边界按任务卡顺序优先判低，高界优先于正常高值。NIBP 偏低、偏高及持续越界提示为 `notice`，其余播报为 `info`。温度按一位小数格式化。
- 快照开启时带 `broadcast` 和 `broadcast_history`，毫秒 epoch 与 `server_time` 同一时钟，进程内字符串 ID 唯一。最新项 10 分钟内有效，历史最多 10 条，文本与免责声明分开。关闭时字段缺席，三节点、五节点各 4 份代表性快照与基线逐字段一致。

## 三段合成快照及生成原文

合成夹具以假时钟模拟通过 LIVE 门禁的采集序列。以下只列播报字段，发出后对应快照的 `broadcast_history` 首项与 `broadcast` 相同。

### NIBP 偏高

t=12 s 到达一条新的 LIVE/VALID 结果，145/92 mmHg。

```json
{"server_time":1700000000000,"broadcast":null,"broadcast_history":[]}
{"server_time":1700000012000,"broadcast":{"id":"1","ts":1700000012000,"param":"NIBP","level":"notice","text":"本次血压约 145/92 mmHg，偏高。建议静坐 5 分钟后复测。","disclaimer":"仅供参考，不构成医疗建议，如有不适请咨询医生"}}
```

### SpO₂ 持续低于阈值

t=0–180 s 每秒输入 89%，60 s 窗口建立后再持续 120 s。t=179 s 的快照仍为空。

```json
{"server_time":1700000179000,"broadcast":null,"broadcast_history":[]}
{"server_time":1700000180000,"broadcast":{"id":"2","ts":1700000180000,"param":"SPO2","level":"notice","text":"请检查指夹佩戴后复测。","disclaimer":"仅供参考，不构成医疗建议，如有不适请咨询医生"}}
```
