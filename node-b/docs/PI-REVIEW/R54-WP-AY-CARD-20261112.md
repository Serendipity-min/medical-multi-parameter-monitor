## 1. 规则（R44 §3，原样实现，阈值全部写成常量并在测试中覆盖边界）
| 参数 | 触发 | 文本要点 |
| --- | --- | --- |
| NIBP | 90 s 内的新结果帧（VALID、LIVE），每个新结果播报一次 | 收缩压 <90 或舒张压 <60 → 偏低；120–139 / 80–89 → 正常高值；≥140 或 ≥90 → 偏高；其余 → 在一般参考范围内。均附"建议静坐 5 分钟后复测" |
| SpO₂ | VALID 读数的 60 s 滚动中位数，持续 ≥120 s 低于 90% | 只说"请检查指夹佩戴后复测"，不说缺氧或偏低；不播报单次读数 |
| PR/HR | 60 s 中位数持续超出 60–100 bpm（持续时长与 SpO₂ 相同，取 120 s） | 只提示复测。HR 规则上线前需要一次真人 ECG 验证，在此之前**默认关闭**（配置项） |
| 体温 | 连续 VALID ≥60 s 之后 | 只说"当前体表温度约 X °C（体表温度低于体温，不作判断）" |
| RR | 不播报 | — |
| 频率 | 同一参数至少间隔 5 分钟；NIBP 按结果计次 | — |
| 免责 | 每条附带"仅供参考，不构成医疗建议，如有不适请咨询医生" | — |
| 门禁 | 只用 `source=LIVE`、`synthetic=false`、validity=VALID 的数据；网关 OFFLINE 或数据过期时清空所有窗口，不补播 | — |

## 5. 接口补充约定（2026-11-12 晚，B2 已按此实现：`claude/cloud-ui-v2@6bca1bc`）
- `broadcast.ts` 为毫秒 epoch，与快照 `server_time` 同一时钟；`id` 为字符串，同一后端进程内唯一。
- `MONITOR_BROADCAST=1` 时快照始终带 `broadcast` 键（无有效播报时为 `null`）和 `broadcast_history`（可为空数组，按时间新→旧或任意顺序均可，页面自行排序）；关闭时两个键都不出现，快照与现状逐字段一致。
- `level` 只取 `info` / `notice`；`text` 不含免责声明，`disclaimer` 单独给出（页面分开显示，朗读时拼接）。
- 页面显示前会再按 `server_time - ts ≤ 10 min` 过滤最新一条，并丢弃字段类型不符的条目。
