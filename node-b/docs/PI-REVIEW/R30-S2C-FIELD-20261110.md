## 收尾过渡事件

断电提示后 **3.592 s**，Broker 先记录离线遗嘱，同一 C 客户端的 `disconnected due to protocol error` 原生行比遗嘱晚 **0.720 ms**。C 在遗嘱后 **6.675 s** 开始退出透传，COM15 在遗嘱后约 **12.5 s** 消失。遗嘱后约 3 s 仍收到 A、B、D、E 四节点的运行态快照，心跳年龄均小于 0.5 s。现场实际拨动时刻没有独立记录。

前后两个周期行覆盖 **5.029 s**，增加 19,384 B、29 个事务，三项异常计数和累计最大字节间隔增量均为 0。退出快照的最后一次 `req/wr` 为 727/727。完整报文环有 16 条，最早 tick 为 1,238,654，晚于遗嘱对齐估值，无法代表触发报文。

退出 ACK 环收齐 61 条。以周期快照对齐，估计遗嘱在 MCU tick **1,236,670**，对时和串口误差边界约 **±309 ms**。中心口径的遗嘱前 5 秒有 23 条 PUBACK，间隔依次为下列毫秒值。

```text

```

中心口径中间隔最大 422 ms、中位数 157 ms、末次写入到 ACK 最大 443 ms。扣除对时边界的 21 条记录最大间隔仍为 422 ms。一次 **1,468 ms** 的间隔落在估计遗嘱后 **181 ms**，在误差边界内，先后 UNKNOWN。Broker 订阅归档的 12,697 条载荷均可解析为 JSON。

这次收尾事件复现了 Broker 协议错误，期间 STM32 的可观测发送计数无异常。它支持继续排查 ESP 接收与透传路径，仍无法定位线路字节或故障报文。正式观察窗口的断链条件判据和三分钟标量无损验收未执行。
