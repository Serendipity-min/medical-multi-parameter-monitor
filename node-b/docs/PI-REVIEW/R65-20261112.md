## 3. 观察（不阻塞）
1. **复电后 TEMP 晚到（92 s）的原因已查明**：同一参数 5 min 的重播间隔（`emitted_at`）在离线时不清零。上一条 TEMP 是 19:02:35.06，加 300 s 正好是 19:07:35.06，与实际 19:07:35.23 吻合；只看 60 s 就绪窗口的话，19:07:08 就该播。这符合 R54 规则（同一参数 5 min 内不重复），不算缺陷。如果希望复电后 60 s 就播，需改为离线时清空 `emitted_at`，是否改由负责人决定。
2. **重启后端会重新播报**：历史和重播间隔都存在进程内存里，所以 S8 重启后 102 s 又播了一次 TEMP。运维上要知道：每重启一次 webbackend，约 60 s 后会补播一条。
3. **HR 喇叭朗读缺少逐条确认**：若负责人记得现场听到过"请静坐后复测心率"，请在下一条消息里补一句，R65 即改为完全 PASS。否则把这一项作为证据缺口写入问题总结，不需要再开窗。
4. 回执 §AZ-3 列出的受限证据（快照、截图、刷写日志）只有 SHA，PI 没有原件；本次判定以 PI 独立 WSS 记录为主。
5. R63 中的观察仍然成立：`tts_enable(power_good=true, protocol_confirmed=true)` 是固件直接设定的，没有真正检测模块电源或协议。本次实物发声证明默认值可用，但模块断电时固件察觉不到。
