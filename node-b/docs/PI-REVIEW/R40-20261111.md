## 2. 安全前提（不可取消；任一项不满足不贴电极）
依据仓库既有纪律（`doc/00_系统硬件防损坏与工程落地复核确认报告.md`：人体实测必须电池/充电宝供电，严禁 220V 开关电源直连；HKB-08 手册：295 mmHg 硬件超压泄气，泄气阀常开）。
1. **整条导电链不接市电**：五板、工装、血压泵 5 V 均由电池或充电宝供电；**记录 COM15 的笔记本必须拔掉充电器、用电池运行**，贴电极期间不得插回。示波器、J-Link 等任何接市电的设备在贴电极前全部断开。需要插电时，先取下全部电极和探头。
2. **志愿者**：无植入式电子医疗器械（起搏器等），电极部位皮肤完好，测压手臂无外伤、输液或其他禁忌；可随时口头叫停。
3. **血压**：上臂袖带，坐姿，手臂与心脏同高。现场先确认三种停止手段都可用：E 屏"停止"（发 `0xA1`）、关 E 电源（泄气阀失电常开）、直接解开袖带。
4. **监督分工**：一人只负责志愿者安全（随时可断电、解袖带），另一人操作与记录。

## 3. 额度
安装 0、Flash 写 0、五板上电 1（上电异常可断电重来 1 次）、隔离 Broker 1、热点切换 0；**血压启动 ≤3 次**（1 次空载 + 志愿者 ≤2 次，间隔 ≥2 min）；START 0、J-Link 复位 0。**总时长 ≤45 min，电极佩戴 ≤30 min。**

## 4. 流程
1. **断电状态布线**，逐项核对 §2 第 1 条（拍照或口头回报"笔记本电池运行、无市电设备连接"），志愿者暂不接触任何电极。
2. **C 镜像核对**：用 R36 安装器的只读核验路径确认 C 上是 `ce8d3490…`，完成后断开调试器；不一致即停止，本窗不安装。
3. 五板冷启动，等 AT、MQTT 与四个源节点就绪。
4. **血压空载试验**：袖带卷在硬质圆柱物上，不接触人体；启动 1 次，确认加压、`0xA0` 实时压、结束或按"停止"后 5 s 内泄压。异常即停用血压，本窗 NIBP 记 NOT_RUN。
5. 志愿者就座，佩戴 SpO₂ 指夹、体温探头（固定部位与距离）、ECG 贴片（按 ADS1292 导联定义）。安静稳定 ≥30 s 后取**连续 300 s 窗口**，期间尽量静坐、少说话。
6. 300 s 后做**志愿者血压第 1 次**；需要时 ≥2 min 后做第 2 次。如有电子血压计、指夹血氧仪或体温计，测后记录读数和时刻，**只作对照，不作判据**。
7. 继续在线观察，总佩戴时间不超过 30 min。
8. 收尾：**先取下全部电极、指夹、袖带**，再关 C，再关其余四板与工装，记录动作时刻（按 R38 §6 打点）。

**血压单次中止条件**（任一满足立即按"停止"；5 s 内不泄压则关 E 电源或解开袖带）：志愿者不适或要求停止；显示压力 >260 mmHg；单次测量超过 90 s 未出结果。

**整窗停止条件**：志愿者任何不适、刺痛、发热、皮肤反应；发现导电链接入市电；冒烟、发热、异味；加上 R36 §3 的设备停止条件（身份/Flash/Options 漂移、HALT/ROM、异常复位、记录器失效、时限到）。网络断链按恢复路径观察，不作停止条件。

## 5. 预登记（不得事后修改）
**传输层**（同 R36 §3，覆盖 300 s 窗口）：ECG 名义点 ≥99%；SpO₂、PR、HR、RR、温度各 ≥297/300，零重复、保序；入队/发布/Broker 差 ≤0.1%，10.4–10.6 条/s；队列 ≤16/24，丢弃/顶替 0，UART/CAN 增量 0；`console_max` ≤40 ms；稳态 `B5 LINKRES triggers` 0。PPG 覆盖单列，<99% 时可归因于 A 质量门控的记 SOURCE_LIMIT。

**真人信号合理性**（静坐 300 s 窗口；只判合理，不判准确）：
| 项 | 预测 |
|---|---|
| HR | VALID ≥90%；VALID 值 40–120 bpm |
| SpO₂ / PR | VALID ≥90%；SpO₂ 94–100%；PR 中位数与 HR 中位数相差 ≤10 bpm |
| 体温 | VALID ≥90%；数值随部位而定，只记录范围与稳定性 |
| RR | 只记录 VALID 比例，属已知限制，不作判据 |
| NIBP | 每次启动在 90 s 内得到结果帧或明确错误码；结果帧到达 Broker；SYS 80–180、DIA 40–110 mmHg 记为合理；按 90 s 有效期规则在 Broker 侧标注实时/历史 |
| 非人工断链 | 记录；若发生，期望无 LINK 停止、自动恢复、在线满 300 s 后 `consecutive_drops`=0 |

## 6. 数据与隐私
真人生理数据属于敏感个人数据：原件只存本机受限归档，**不入库**；回执只写统计量、计数、SHA-256 和合理性结论，不写志愿者身份，不提交原始波形或可识别截图。答辩材料如需展示波形，需负责人另行确认使用哪一段、如何去标识。
