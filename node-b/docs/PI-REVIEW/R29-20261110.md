# PI 审查 R29：不做 UART 抽头，按 R28 §4.1/§4.2 走离线 + 多一轮窗口

**日期** 2026-11-10　**审查人** Claude（PI）　**承接** [R28](R28-20261110.md)

## 1. 决定
负责人 2026-11-10：当前没有 UART 逻辑抓取器，**不做 §4.3 硬件抽头，多加一轮窗口定位**。

## 2. 离线工作（Codex，不需新授权；本文不放行板级动作）
1. R28 §4.1：发送路径字节完整性审读（短写处理、重入、缓冲复用、临界区、声明长度失配），给源码位置和结论。
2. R28 §4.2：WP-AU `B5 TXCHK`（总 TX 字节、报文数、`written!=required`、TXE 超时、报文内最大字节间隔、重入计数、退出前最近一次发送上下文），Host 测试，新 SHA，不改发送行为，控制台开销 ≤30 ms。**发现 §4.1 的明确缺陷时先报 PI，不要自行修复后再叠加诊断**，避免窗口里变量混在一起。
3. 因为没有外部抓取器，**判别全靠排除法**，请额外在 TXCHK 里补两项以收窄 ESP 侧：
   - 每个 QoS1 报文从写完到 PUBACK 的耗时和 PUBACK 间隔最大值（已有 PUBACK 分位，需补"遗嘱前最后 5 s 的逐条 PUBACK 间隔"）；
   - 断链前最后 N 个报文的流类型、长度、写入耗时环形记录，在自行退出透传时输出。

## 3. S2-c 窗口草案（需 WP-AU 经我 VPS 位级复核，且负责人按新完整 SHA 放行；本文不放行）
- 对象：C 刷写 sector0/4（新 SHA），沿用 R22/R26 的安装与读回流程；回退 WP-AR `dff9cfb9…`；额度：安装 1、上电 ≤2、**热点切换 0**、Broker 1（开 `connection_messages`）、无 START/J-Link 复位/血压泵。
- 流程：冷启动 → 稳态观察 **20 min** → 断电。人工断网不做。
- 预登记：
  | 情形 | 预测 | 含义 |
  |---|---|---|
  | 窗内出现 ≥1 次非人工断链 | 概率约 70%（S2-b 2/909 s；S2 4/506 s） | 才有判别价值；若 20 min 内无断链，只能说未复现，继续累计，不下结论 |
  | 断链时 `written==required`、无 TXE 超时、无重入、发送间隔正常 | 我的先验约 60% | STM32 发送侧完整，嫌疑落在 ESP 接收或透传内部 |
  | 断链时出现短写/超时/重入 | 约 25% | 缺陷在 C 的发送路径，按 §2.1 的位置做最小修复 |
  | 以上均无法判别 | 约 15% | 需要外部抓取器，另议 |
  | 稳态首段速率 / 队列 / `console_max` | 10.4–10.6、≤16/24、≤40 ms（TXCHK 多一行后留余量） | 超出则分散输出 |
  | Broker 原因行 | protocol error 或 malformed packet（同 S2-b） | 其他类型则重评假设 |
- 若 S2-c 仍不能区分，下一步是 §4.4 的停滞感知节流作为**缓解试验**（不是定位），由负责人决定是否接受试验性改动。
