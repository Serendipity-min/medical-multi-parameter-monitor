## 2. ECG：信号已够，瓶颈转到算法
1. **三种贴法并表**（同一套脚本；“峰检幅度”是 B 峰检选中峰的 |y| 中位数；“TP 段噪声”取 R 后 550–800 ms 的 RMS，只算间期大于 850 ms 的拍，比 R86 的全信号 RMS 更接近真实噪声）：

   | | 踝部 R83 | 腕部 R85 P1 | **胸部 R87 P2** |
   |---|---|---|---|
   | PPG 锁定集合平均 QRS 峰峰值 | 约 250 µV（R84 峰值口径） | 260–290 µV | **460–770 µV** |
   | 峰检幅度中位数 | 251 µV | 332 µV | **433 µV** |
   | TP 段噪声 RMS | 80 µV | 126 µV | **60 µV** |
   | B 实发 HR 有效率 | 约 60% | 0.7% | **63%** |
   | C1 重放有效率 | 36% | 0.2% | 47% |
   | C2 重放有效率 | 50% | 3% | **68%** |

   全信号 RMS（R86 口径）在 P2 为 93–120 µV。这个值偏高，是因为 QRS 变大了，并非噪声增加。

2. **波形（事实）**：以 B 的峰检锚点对齐 282 拍。滤波后的 QRS 呈三相：−32 ms 处 +113 µV，0 ms 处 −450 µV，+40 ms 处 +250 µV。T 波很小（约 −100/+60 µV），不会触发误检。

3. **有效率上不去的原因**（按 5 个间期的判稳窗口统计；B 的 273 ms 不应期已计入）：
   - 48% 的窗口稳定；
   - 23% 含漏检拍，间期约为 2 倍；
   - 25% 是节律变化或锚点抖动，超出 ±20%；
   - 4% 含多检。

   PI 曾怀疑锚点在双相波两叶之间跳动，于是离线试了“120 ms 内两叶只取大者”（C3），有效率没有提高（67.8%，C2 为 68.1%）。**这一假设不成立**，抖动主要来自真实的呼吸性窦律变化，加上个别拍幅度低于自适应门限。

4. **C2 在 P2 上的作用**（离线重放：漏检容忍，加 ±30% 判稳）：
   - 有效率从 47% 提高到 68%，各分钟提高 10–32 个百分点，数值不变（中位数 66）；
   - 对照：导联开路和白噪声仍为 0%，模拟器 87%（与 C1 相同）。

   重放受 MQTT 缺段影响（ECG 时间约 8% 缺失，每次缺段后重放重新预热），所以绝对值低于板上实发：C1 重放 47%，板上实发 63%。**推断**：C2 上板后，P2 下 HR 有效率可能接近 80%，但没有验证，不能当作结论。

## 3. RESP：胸部贴法也没有改善
1. **幅度**：P2 下 RESP 每 30 s 标准差为 200–290 r 单位，不高于腕部（R86：250–450）。阻抗呼吸的路径改为经过胸腔后，起伏并没有变大。
2. **频谱**（30 s 滑窗）：
   - 0.15–0.25 Hz（12 次/分附近）的占比在所有窗口都不超过 30%，没有一个窗口以它为主；
   - 多数窗口的主峰在 0.27–0.4 Hz（16–24 次/分），自相关 0.3–0.6，各阶段都有。这一成分是志愿者真实的快浅呼吸还是伪迹，**UNKNOWN**。
3. **参照也定不下来**：A 的 PPG 基线以慢漂移为主；用 PPG 心搏间期估计的呼吸性窦律，峰位散布在 4–24 次/分。两者都无法确认真实呼吸率。
4. **重放**：
   - 现行算法以原因码 6 为主。部分 30 s 窗口里重放会出现 0，但板上 RR 全程无效。差异可能来自重放无法重建的位，即削顶、工频或宽带，**UNKNOWN**；
   - R2 原型在个别窗口有 27–60% 有效，数值 16–25，无法确认是否正确。
5. **结论（推断）**：三种贴法下，真人阻抗呼吸的起伏都只有约 200–450 r 单位，且没有清楚的呼吸周期，问题不在贴法。是 RESP 通道对真人的灵敏度不足，还是 r 单位与欧姆的换算不明，目前无法区分。模拟器 RR 能通过（R81 §6，1.5 R、20 次/分），但那一次没有做 MQTT 录制，不知道模拟器在 r 单位下的幅度。
