## 2. R94 复盘（事实与推断）
1. **有效帧只出现在工频残留最低时（事实）**：
   - 17:08:10（45–55 Hz 为 34 µV）、17:23:00（29 µV）、17:26:00（18 µV）、17:26:20 前后（约 25 µV）；
   - 其余时间残留 60–277 µV，B 的峰检只找到应有心搏数的 37%，峰值中位数只比门限高 25%。
2. **工频残留周期性起伏（事实）**：在 50 Hz 处逐秒解调，残留幅度在 4–277 µV 之间变化，大约 40–60 s 一个周期；每次幅度接近 0 时相位跳变，其余时间相位持续漂移。
   - **推断**：这是两个频率很接近的成分在拍频。B 每秒采样 250 次，工频的 4 次、6 次谐波会折叠到 50 Hz 附近，与基波相差约 0.02–0.05 Hz。固定在 50 Hz 的窄陷波压不住这种起伏。
   - 关灯和移走插线板都没有改变它。
3. **信号**：PPG 锁定的 QRS 为 250–460 µV，单拍 SNR 1.1–1.6，与 R89 S5 相当。
4. **离线试验（事实）**：在录到的 ECG 上加一级 5 点滑动平均（20 ms 梳状），45–55 Hz 残留从 122 µV 降到约 1 µV，峰检数量回到正常。但只有 18% 的峰间隔落在真实心搏周期的 ±15% 以内，QRS 也被削弱约 40%。
   - **结论**：单靠压工频不够，检测器本身也要改。
5. **五轮汇总**：

   | 轮次 | 志愿者 | QRS 峰峰值 | 主要问题 | 板上 HR |
   |---|---|---|---|---|
   | R87 | 甲 | 601 µV | 正常，SNR 3.3 | 63% |
   | R89 S5 | 甲 | 399 µV | 噪声偏高，SNR 1.8 | 4% |
   | R91 第一次贴片 | 甲 | 约 80 µV | 信号太弱 | 接近 0 |
   | R91 第二次贴片 | 甲 | 约 200 µV | RL 在脚踝，工频高 | 0 |
   | R94 | 乙 | 250–460 µV | 工频拍频起伏，SNR 1.1–1.6 | 约 10 帧 |

   - 硬件链路正常（R93）；
   - 现在的检测器在单拍 SNR 约 3 时可用，在 1–2 时基本失效；而真人采集多数落在 1–2。

## 3. C3 离线研究方案（门槛在看结果之前定好）
### 3.1 约束
1. **只改 B 的心搏路径**：C3 必须接在现有滤波输出 `y`（5–25 Hz 检测带）之后。这样现有的 MQTT 录制可以直接作为输入，不需要原始码。现有滤波、RESP 路径、工频判据和削顶处理一律不改。
2. **资源**：要能在 STM32F407 上逐样本运行，不用动态内存，新增 RAM 不超过 2 KB，单样本运算量为常数。
3. **安全语义不变**：HR 只在有足够证据时才报有效；时效仍为最后一拍后最迟 4 s 失效，在 5 s 实时有效期以内。

### 3.2 候选（逐项消融，看每一项各自的作用）
- **A 工频**：接在 `y` 之后的 50 Hz 梳状（5 点滑动平均），或者跟踪实际工频频率的自适应陷波。
- **B 检测器**：Pan–Tompkins 式处理（导数、平方、约 150 ms 滑动积分），双门限（信号峰和噪声峰的估计），加回溯搜索；不应期仍为 273 ms。
- **C HR 判定**：最近 8 个间期取中位数，剔除偏离中位数 20% 以上的离群间期；剔除后剩余间期不少于 5 个才报有效（取代 C2 的“5 个间期全部在容差内”）。

### 3.3 数据集
- **真人**（以 A 的 PR 为参照，±1 s 配对）：
  - R87 P2：16:42:00–16:47:51；
  - R89 S5：18:33:00–18:43:30；
  - R91：15:33:40–16:03:40；
  - R94：17:08:00–17:28:00；
  - R85 腕部：15:58:40–16:03:40。
  - R83 踝部没有 A 的参照，只统计有效率。
- **阴性对照**：
  - R83 导联断开到贴电极：15:00:15–15:04:00；
  - R89 S3 接回伪迹：17:44:40–17:45:40；
  - 合成白噪声：40 个种子；
  - R90 的准周期伪迹尖峰序列。
- **阳性对照**：R83、R89、R92 的模拟器 60 bpm 段。
- **主机用例**：`run_host.py` 的 27 例既有用例、19 例 C1 用例、11 例 C2 用例，共 57 例。

### 3.4 指标
- **有效率**：按样本统计重放输出有效的占比，C2 和 C3 在同一份输入上比较。MQTT 缺段会让重放结果整体偏低，但 C2 和 C3 受的影响相同。
- **一致率**：有效输出逐秒取值，与 ±1 s 内的 PR 配对，计算相差在 ±10% 以内的占比，以及绝对误差的中位数。

### 3.5 门槛（全部满足，才进入上板评估）
1. **收益**：在 R89 S5、R91、R94 三份数据中，至少两份的有效率比 C2 高 20 个百分点以上；R87 的有效率不低于 C2 的重放值（65.8%）。
2. **准确**：所有真人数据合计，配对一致率 ≥85%，绝对误差中位数 ≤3 bpm。
3. **不误报**：
   - 导联断开段有效率为 0%；
   - 白噪声 40 个种子的均值不超过 0.2%，最长连续有效不超过 4 s；
   - 伪迹尖峰序列各档的误报不高于 C2；
   - R89 S3 接回伪迹段不报出 ±10% 以外的数值。
4. **阳性对照**：模拟器 60 bpm 的有效率不低于 C2，数值为 60±1。
5. **回归**：主机 57 例全部通过；为 C3 新增的用例另列。
