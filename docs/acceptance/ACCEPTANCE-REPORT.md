## 1. 结论

**五板工程样机通过本阶段验收，附已接受的限制。**

- **主链路完整运行**：
  - 采集：血氧、心电/呼吸、物表温度、无创血压；
  - 板间：双段 CANopen；
  - 出口：网关经 ESP8266 TLS/MQTT 上云；
  - 云端：后端校验、公开只读网页；
  - 下行：规则播报经 MQTT 回到网关，由板载喇叭播放。
- **最终一轮真人测试**：HR 有效率 99%；RR 与实测呼吸一致。
- **1 小时连续运行**：七项判据中六项通过；体温覆盖率未达预设值，负责人已接受。
- **合同 §17 中没有做的项目**：只有 24 h 长测，负责人决定以 1 h 替代，24 h 记为 NOT_RUN，已接受。

## 3. 本阶段补测结果

### 3.1 R125 写入与模拟器验收（R126）

- **写入**：PASS。B 写后整片 SHA 与预期逐字节一致；B 现装 R125 K5，**镜像冻结**。
- **模拟器验收**：预注册判定 **FAIL**，未通过的只有 12 次/分档的上传连续性，原因是网关两次掉线（34 s、21 s）。其余判据全部通过：
  - HR 186/187，全部为 60；
  - RR 20 次/分、12 次/分全部正确；
  - 断开 RA 期间无错误数值；
  - “有效的 0”为 0 帧；
  - ECG 模式下 RR 无有效值；
  - 波形有效率 99.6–100%。

### 3.2 R125 真人（志愿者丙）

| 项 | 结果 | 判定 |
|---|---|---|
| HR 有效率 / 与脉率 ±10% 以内 | 99% / 97% | PASS |
| RR | 板上 86/86 有效，数值 10–14，集中在 11–12；直接数波形峰为 12 次/分 | 负责人按实测约 12 次/分裁定 PASS（未留 30 s 累计数，丙没有跟上 15 次/分的节拍） |
| 网页波形 | 心电、呼吸全程有效、全程显示 | 只记录 |

### 3.3 一小时长测（R127 → R128）

| 判据 | 结果 | 判定 |
|---|---|---|
| G1 节点意外重启 | 无 | PASS |
| G2 断链自动恢复 | 1 次 13 s，自动恢复 | PASS |
| G3 标量覆盖 | SpO₂、PR 100%；B 的 HR/RR 98%；体温 87.1%（门槛 99%） | **NOT_PASS，已接受** |
| G4 模拟器数值 | HR、RR 全部正确 | PASS |
| G5 错误有效值 | 0 | PASS |
| G6 波形 | 有效率 99.9–100%，ECG 丢失 1.4–2.6%，无 2 s 周期 | PASS |
| G7 血压链路 | 7/7 一致 | PASS |

**C 串口全程定位到的两件事**：
- **断链**：由 PUBACK 停滞触发（5 s 内无确认）；本地串口和 CAN 计数都正常；按设计退出透传，13 s 内重连成功。
- **体温覆盖不足**：网关收到的 D 标量帧只有标志帧的约 80%，全程稳定，B 断电期间也不变。段二总线负载约 8%，所以**不是 CAN 速率问题，也不是 B 的波形帧挤占**；机制未明，疑在 D 节点侧的发送处理。
