## 1. 方案背景与合同阻塞项 E05 澄清

针对总合同第 1.2 节关于 HKB-08A、HKB-08B+ 版本、波特率、停机指令与引脚分配的疑问，经逐页查阅规格书及电路原理图后彻底澄清：

1. **版本一致性**：HKB-08A（裸板式）与 HKB-08B+（集成外壳/接口板）底层均基于 **PW195A 硬件主板**，固件协议完全统一。
2. **通信参数冻结**：波特率固定为 **115200 bps**，8 位数据位，1 位停止位，无校验（8N1）。
3. **紧急停机放气指令**：正式明确为 **`0xFF 0x00`**（最高安全优先级，无须校验和，仅 2 字节，模块收到立即停泵并开启泄气阀放气）。
4. **引脚冲突解决**：确定连接至 STM32F407 的 **UART5（`PC12` TX, `PD2` RX）**，与 ADS1292R 的 PWDN（已移至 `PE8`）彻底解耦，互不干扰。

## 2. 测量机理与气路结构解析

### 2.1 示波法（Oscillometric Method）测量机理
1. **充气阶段**：微型气泵以固定速率对套在受试者上臂的袖带加压充气，直至袖带静压超过被测者的动脉收缩压（通常充气至 150～180 mmHg），此时肱动脉血管被完全压瘪阻断血流；
2. **匀速阶梯放气阶段**：气囊经微调阻尼漏气孔线性缓慢降压（泄气速率保持在 2～4 mmHg/s）。当袖带压力降至收缩压瞬间，动脉管壁开始克服外压开放射血，血液射流在袖带气囊内激发出微弱的脉动压力振荡波（脉搏波）；
3. **特征包络提取**：
   * 高灵敏度压阻式传感器实时检测袖带内“总静压 + 微弱交变脉冲振荡”；
   * 随着袖带压力进一步降低，脉搏振荡波幅值逐渐增大至最大极大值，此时对应的袖带静压即为**平均动脉压（MAP）**；
   * 随后动脉搏动幅度逐渐衰减。依据经典的振荡波特征比例法（如收缩压对应最大峰值的 50%～55%，舒张压对应最大峰值的 70%～80%），算法反推出**收缩压（SYS）**与**舒张压（DIA）**；
4. **快速排气**：测量结束后，常开电磁泄气阀完全通电断开或失电释放，气囊瞬间排空，恢复受试者肢体血液通畅。

### 2.2 气路与硬件组成细节
* **直流微型气泵**：输入直流 5V，工作电流峰值 350～500 mA。**具有严格极性要求（M+ 接红点正极，M- 接负极），严禁反接**，反接会导致泵电机永久烧毁。
* **快速电磁泄气阀**：常开型（Normally Open）设计，失电状态自动常开泄压，只有测量加压时才通电闭合。该设计保障了在系统掉电或死机时，袖带能自动泄气，杜绝患者肢体缺血坏死风险。
* **微压传感器**：量程 0 ～ 300 mmHg，静态分辨率 1 mmHg，静态精度 ±1 mmHg，动态测量精度 ±3 mmHg。

## 4. 通信协议与数据帧格式规范全集

采用异步串行全双工通信：1 个起始位、8 个数据位、1 个停止位、无校验（115200, 8N1）。

### 4.1 数据帧结构说明
* **常规数据帧**：
  * **帧头**：固定 2 字节 `0xFF 0xC0`；
  * **长度字段**：1 字节，表示其后包含校验和、命令及所有数据参数的字节总数；
  * **校验和（CKSUM）**：1 字节，为长度字段、命令字节及后续所有参数字节累加和的低 8 位：
    ```c
    CKSUM = (Length + Command + Sum(DataBytes)) & 0xFF;
    ```
* **紧急强制停机复位帧**：
  * **仅 2 字节**：`0xFF 0x00`（无帧头、无校验，最高优先级执行停泵与排气）。

---

### 4.2 核心业务命令与交互序列

#### 1. 启动血压测量
* **主机发送**：`0xFF 0xC0 0x03 CKSUM 0xA0`
  * `Length = 0x03`
  * `Command = 0xA0`
  * `CKSUM = (0x03 + 0xA0) = 0xA3`
  * **完整十六进制**：`FF C0 03 A3 A0`
* **充气加压过程实时回传（10Hz 连续上报袖带压力）**：
  * **传感器上报**：`0xFF 0xC0 0x05 CKSUM 0xA0 QYH QYL`
  * `QYH`：气压高字节。**关键标志位：`QYH.4 = 1` 表示当前检测到动脉脉搏跳动，`QYH.4 = 0` 表示未检出**；
  * `QYL`：气压低字节；
  * **实时袖带静压计算公式**：
    ```c
    Cuff_Pressure (mmHg) = ((QYH & 0x0F) * 256) + QYL;
    ```

#### 2. 测量完成最终结果帧（关键帧）
* **传感器上报**：`0xFF 0xC0 0x08 CKSUM 0xAC SSYH SSYL SZYH SZYL XL`
  * `Command = 0xAC`：测量结果通知码；
  * **收缩压（高压）**：
    ```c
    SYS (mmHg) = ((SSYH & 0x7F) * 256) + SSYL;
    ```
    * **关键心律失常标志位**：**若 `SSYH.7 = 1`，表示测量过程中检测到脉搏节律严重不齐（心律失常风险警示）**；
  * **舒张压（低压）**：
    ```c
    DIA (mmHg) = (SZYH * 256) + SZYL;
    ```
  * **平均动脉压（MAP）估算（若模块未直接回传）**：
    ```c
    MAP (mmHg) ≈ DIA + (SYS - DIA) / 3;
    ```
  * **心率/脉率**：`XL`（单位 bpm，量程 30～240）。

#### 3. 测量异常与错误报告帧
* **传感器上报**：`0xFF 0xC0 0x04 CKSUM 0xAD X`
  * `Command = 0xAD`：错误报警码；
  * **错误代码 `X` 的语义映射表**：

| 错误码 X | 状态描述 | 产生原因 | 应对措施与用户提示 |
| :---: | :--- | :--- | :--- |
| **`0`** | 未检测到有效脉搏 | 袖带佩戴位置严重偏离肱动脉，或受试者脉搏极其微弱 | 重新调整袖带位置，对准动脉标志线。 |
| **`1`** | 加压充气超时 | **11 秒内袖带压力未能充至 50 mmHg** | 检查气路是否漏气、五通接头是否松脱、袖带是否缠绕过松。 |
| **`2`** | 测量数值计算有误 | 脉搏波信号畸变，无法拟合出特征包络线 | 保持静息状态，重新发起测量。 |
| **`3`** | **超压硬件保护** | **袖带压力突破 295 mmHg 极限安全红线** | 模块强制切断气泵并开阀放气，防止压迫伤害。 |
| **`4`** | 体动干扰过多 | 测量过程中受试者手臂移动、肌肉颤抖或说话 | 提示受试者静止平复，严禁移动肢体。 |

#### 4. 停止测量指令
* **主机发送**：`0xFF 0xC0 0x03 CKSUM 0xA1`（完整十六进制：`FF C0 03 A4 A1`）
  * 模块收到后立即停止加压，气阀打开完全排气，并应答相同帧。

#### 5. 休眠与唤醒指令
* **休眠**：`FF C0 03 AB A8`（进入微安级休眠模式）；
* **唤醒**：`FF C0 03 AD AA`（退出休眠恢复待机）。

## 5. 静压模式脉搏波高速采集协议（选配高级功能）

在不加压测血压的平时状态下，模块支持工作于“固定压力下的肱动脉脉搏波形连续采集”模式（波形采样率 200 Hz）：

1. **启动静压测波形**：`0xFF 0xC0 0x05 CKSUM 0xD0 setQYH setQYL`
   * 设置目标静压（例如打气至 60 mmHg 并恒压保持）；
2. **高速脉搏波上报（200Hz）**：`0xFF 0xC0 0x05 CKSUM 0xD3 waveH waveL`
   * `waveH`、`waveL` 为 16 位高灵敏度脉搏波动幅值点，可用于动脉硬化（PWV/ASI）算法研究；
3. **停止静压波形采集**：`0xFF 0xC0 0x03 CKSUM 0xD1`。

## 6. 医疗安全、电源与固件状态机设计规范

> [!CAUTION]
> **气泵感性负载与电气安全核心规范：**
> 1. **反向电动势吸收**：直流气泵电机在关断瞬间会产生高达几十伏的反向感应电动势。必须在气泵引线焊盘并联高压快恢复二极管（如 **SS34** 或 **1N4007**，阴极接 M+，阳极接 M-），吸收尖峰电压，防止击穿驱动三极管或串扰主控芯片；
> 2. **大电流独立供电**：气泵启动时峰值电流达 500 mA，严禁直接从 STM32 的 3.3V LDO 引脚取电，必须由动力锂电池经过大电流 DC-DC/LDO 稳压输出 5V 单独供电；
> 3. **单片机端超时看门狗**：STM32 固件必须设置独立软件定时器（如最大充气时限 40 秒）。一旦超过 40 秒仍未完成，单片机无条件强行发送 `FF 00` 紧急停机指令，并切断外置高边供电 MOS 管，形成双重硬安全冗余。
