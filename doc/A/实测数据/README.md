# Node-A → Gateway-C 实测采集证据（2026-10-19）

本目录保存 Node-A（血氧 + 血压，双本地屏）到 Gateway-C 的 CAN 实测采集原始记录与解析结果，
用于核验两件事：**① CAN 传输是否正常；② 传输的数据是否与本地显示屏一致。**

---

## 1. 采集方式与边界

| 项目 | 说明 |
| --- | --- |
| 观测点 | **COM15**（Gateway-C 台架版 `CAN_ONLY_BENCH`，USART1 PA9/PA10 @115200） |
| 采集方式 | **单向被动接收**：打开串口后不发送任何字节，DTR/RTS 均保持 `False`，避免电平扰动目标板 |
| 未执行 | 未发送 `S`/`G`/`T`/`P`/`D` 任何台架命令；未烧录、未复位、未擦除；未连接 Node-A 的 J-Link 读 RAM（`connect` 会停核，会中断袖带测量） |
| 受测对象 | 真人血氧探头 + 血压袖带；充气与停止**全部由现场屏幕按钮控制**，采集端不参与任何充放气指令 |
| 数据来源 | 全部为 Gateway-C 实际收到的 CAN 帧统计与其载荷，非回放、非合成 |

## 3. 两个值得单独记录的现象

### 3.1 血压 90 秒时效两次独立复现

代码中 NIBP 的 CAN 时效被收紧到 90 s，而本地屏保留历史结果。实测两轮分别在
**90.0 s** 与 **90.0 s** 精确归零。这既验证了时效门限按设计工作，也说明：

> **血压屏上仍显示结果、而 CAN 已经发 0，属于设计行为，不是数据不一致。**

### 3.2 `0x181` 帧率不是固定值

PPG 波形帧为事件驱动（只在有新波形点时发送），因此**窗口平均帧率取决于探头在位时长**：
A1 含约 56 s 探头在位、A2 含约 90 s。不能把窗口均值当作波形固定采样率，也不能
用 `dt_max` 判丢帧——诊断里的 `dt_max` 是固件**自启动以来**的累计最大值，跨越冷启动，
不是本窗口内的最大间隔。

## 4. C 侧协议层状态（非 CAN 故障）

两轮控制台均显示：

```text
paused=1  A=0  B=0  time=TIME_BLOCKED  fault=0  armed=1
MODEL frames=2718 invalid=2012 valid=0
```

即**物理层在满速收帧，但 Gateway 协议层处于暂停态**，因此不判定 A 在线、不更新模型。
这是台架被 `P` 暂停后的既定状态。若需要"协议层判定 A 在线、模型有值"，
须由现场显式发 `G` 恢复协议——**本轮未执行，本记录不声称协议层验收通过**。

## 5. 未验证项

- 未验证 Gateway 协议层（`valid=0`、`A=0`），也未验证 MQTT/云端链路（本轮明确不上云）。
- 未独立读取本地屏画面，"与屏幕一致"依据操作员确认。
- 未做长时间稳定性统计（单轮最长 302 s），不能外推为长期零丢帧。
- 未验证 Node-A 侧 RAM 内部值（未连 J-Link，避免停核中断袖带测量）。
- 血氧/脉率的 21% 等低值是探头瞬态，**不作为准确度结论**；本证据不含任何生理准确度判定。

## 6. 文件与复现

| 目录 | 内容 |
| --- | --- |
| `A1_NodeA_CAN_20261019T192020/` | 第一轮：`com15_raw.bin`、`com15_text.log`、`capture_receipt.json`、`parse_summary.json`、`vitals_timeline.json` |

脚本（与本目录同级）：

```powershell
# 采集（不发送任何字节，DTR/RTS=False）
python capture_com15_passive_v2.py

# 解析（传入采集目录）
python parse_nodeA_can.py <capture_dir>
```

解码规则（依据 `node-a/STM32F407_HOSPITAL/HARDWARE/CANopen/OD.c` 的 `0x1A02` 映射）：

```text
0x381 载荷 = [SpO2 u16 /100][PR u16 /100][NIBP_SYS u16 /10][NIBP_DIA u16 /10]，小端，DLC=8
```

其中无效字段写 0：SpO2 需 `probe_state && result_valid` 且落在 1–100，PR 需 1–350，
NIBP 需 sys/dia 落在 1–400 并在 90 s 时效内。
