code != 0 → warning

# 4. 新增日志实现复核

`broker_logging.py` 使用子进程代理 Mosquitto：

```text
systemd
 ↓
Python logging proxy
 ↓
Mosquitto child
```

SIGTERM / SIGINT / SIGHUP 会转发到 Broker，满足：

- systemd 停止；
- 证书 HUP reload；
- persistence 正常退出。

结构设计合理。

日志白名单避免直接记录：

- MQTT Payload；
- Topic；
- Client ID；
- 用户名；
- 密码；
- IP 地址。

本轮没有发现明显敏感信息落盘路径。
