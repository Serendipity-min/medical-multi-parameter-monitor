# 4. 哪些 Backend 项目以后仍可能变化

以下会在后期变化，但不是本次 UI 重构的阻塞项：

- 共享 View Token → 独立用户会话；
- RAM 状态 → 历史数据库；
- RAM 离线缓存 → Flash 持久缓存；
- 真实报警规则；
- NIBP 更多测量状态；
- 真实 A/B 的标定/质量字段；
- RR 正式算法版本信息。

原则：

> 后续字段优先做 **向后兼容的 additive change**。如必须破坏 Schema，则提升 `schema_version`，不得静默修改 v1。
