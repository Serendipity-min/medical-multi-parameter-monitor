# P5 C2.5-R2 原始快照链路与 C3A 申请规约 v1.0

## 1. 状态和身份

依据 2026-10-08《P5 C2.5-R1 证据复核、快照链路审计与 C3A 准入裁定》R1-01～R1-04。本轮只完成 R2-01～R2-04 的脱机工具和操作单；**C3A 仍为 HOLD**。原 P4/P5 源码、两套诊断 Patch、原 ELF/BIN、Flash、Broker 和 Security Gate 均未变更。

冻结布局由 ARM GNU 14.2.1 对原 `probe_events.h`/`probe_config.h` 计算 `sizeof/offsetof`，并与两版冻结 ELF 的 `probe_state` 1264 B 符号及诊断标记地址核对。布局文件 `probe-layout-v2.json` SHA-256 为 `151a70d3f2bc874939844289d34ce1df48a65301a61a20a5d7884eab8ba36e7b`；P4/P5 类型偏移完全相同，但各自 marker 和 `probe_state` 地址分别保存。两次在不同忽略目录独立生成，文件 SHA 相同。生成器只调用本机 ARM 编译器和 `nm/readelf`，不改原构建脚本或生产源码。

## 2. R2 脱机证据链

1. [强化的索引器](../../../../gateway/mqtt/tests/measurement/r1_snapshot_index.py)要求独立事件日志中的每轮 `D_SENT→HALT→READ1_DONE→READ2_DONE→SNAPSHOT_PERSISTED→RESUME` 六点；同一观察时钟会话内严格递增，上一轮 resume 必须早于下一 D。事件记录带连续 SHA 链，缺点、重叠、逆序、跨观察会话均拒绝。单独填写 `saved_before_next_d=true` 不再足够。
2. [字节解码器](../../../../gateway/mqtt/tests/measurement/r2_snapshot_bytes.py)读取两份**已保存的本地文件**，核对两个独立文件的实际字节 SHA、精确 1264 B、冻结布局、magic/profile/variant/marker/时钟、稳定停止标志、聚合/最大事件、九个 M06 点、缓存/堆及丢样字段。运行中不接 COM/J-Link；修改文件、截断、尾随字节、布局或身份漂移拒绝。
3. [六轮绑定器](../../../../gateway/mqtt/tests/measurement/r2_verify_bundle.py)把每轮两份文件 SHA 与索引声明和事件链关联，再检查同一版 Heap 峰值、ENOMEM、缓存 lost/replay/drop 跨轮不回退。输出只含固定数字和摘要，独占创建，不能覆盖旧回执。原始 RAM 文件仍只在忽略 build/本地私有证据位置。

当前测试只用人工合成 `.bin` 和时刻。事件链能识别**文件内部**的局部修改，但不能证明整个日志没有被重新构造；现场真实性仍需独立采集原件。即使脱机链成功，结果固定为 `H16_acceptance=NOT_GRANTED / C3A_entry=HOLD`。旧 `analyze_h16.py` 不接收本工具的每类最大事件作为逐帧 `cycle_samples`，也不计算伪中位数。

## 3. C3A 唯一候选暂停操作单（尚未授权）

| 顺序 | 必须留存的真实来源 | 判废条件 |
|---|---|---|
| 启动前 | UID、已批准的诊断 BIN/ELF SHA、应用回读、同一 F407/ESP、环境/负载/时钟和观察器 session ID | 任一身份或条件不符立即 STOP |
| D 至 90 秒 | 外部 QPC 的 `D_SENT`，原日志与 Broker/Backend 独立观察、CAN/drop、恢复和首 VALID 业务 | 窗内不得 halt/reset；缺事件或条件漂移无效 |
| 唯一首次 halt | QPC `HALT`、PC、IPSR、控制状态、DWT 能力/递增与时钟证据；窗口终点就是此次 halt | `IPSR != 0`、活动 span、奇数 clock_seq、丢 tick/事件或延迟超出 90～92 秒无效；不反复暂停凑合格值 |
| 冻结读回 | 从本版 ELF `probe_state` 地址各读取 1264 B 两次，保存两份独立文件、QPC `READ1_DONE/READ2_DONE` 和文件 SHA | 字节不同、任一读失败/改写、PC/IPSR 来源缺失立即保存失败证据 |
| 保存与 resume | 只增保存索引/事件原件、QPC `SNAPSHOT_PERSISTED/RESUME`、CPU halt 时长 | 下一 D 早于保存+resume 或 halt 超过候选 2 秒即判废；第二次 halt 仅故障分析，不能救回样本 |
| 恢复后 | 连续候选 30 秒的正常 CONNECT/会话标识、无额外 LWT/断连、CAN/drop 与首业务；外部 Broker 观察需独立获批 | 观测诱发重连、会话变化或状态不稳时禁止直接下一 D，保留记录并申请重新裁定 |

2 秒 halt 和 30 秒恢复观察均为待审候选，不是假定已满足。Gateway keepalive 为 15 秒；短暂停顿也可能影响 ESP/Broker。当前工具**不会读取 IPSR/PC 或 DWT 现场寄存器**，单凭偶数 `clock_seq` 不证明停在前台或 DWT 全窗连续。没有独立现场事件、原始读回及 Broker 观察授权时，物理来源和扰动仍 `UNVERIFIED`。

## 4. M01～M07 字段映射与扰动

| 指标 | R2 能从冻结字节读到 | 保留的限制 |
|---|---|---|
| M01 | Q0/Q1/open/yield 成功/失败/无效计数、包容周期聚合与每类最大事件 | 仅最大事件，不是逐帧分布；完整 QoS1 发布包含匹配 PUBACK 等待 |
| M02 | `PROBE_CAN_SERVICE` 聚合/最大事件与 tick 丢失 | 名称固定 `SYSTICK_ISR_SAMPLE_TO_COOPERATIVE_SERVICE_DONE`；理想到期→ISR 未测 |
| M03 | 全 `gateway_mqtt_publish()` 包容周期与解释性子 span | `PARTIAL / CPU_PURE_NOT_MEASURED`；Paho/coreMQTT 单个库 API 不作直接性能对照 |
| M04 | 只见静态 8 KiB 预留及 `PROBE_STACK_BLOCKED` | `NOT_MEASURED/BLOCKED_UNSAFE_SENTINEL`，不填栈哨兵 |
| M05 | Heap 峰值、ENOMEM 本轮基线/总数 | 包含初始化/newlib/CAN，未取得现场字节仍 NOT_MEASURED |
| M06 | 九点 MCU 单调时刻、首业务数值身份 | 设备端点 `DEVICE_PUBLISH_SUCCESS`；主机时刻不能直接相减，真实 Broker 观察另授权 |
| M07 | 最近 cache before/after、lost/replay/drop、LIVE/REPLAY | 只称 `OBSERVED_CACHE_EMPTY_AT_LAST_SNAPSHOT`；缺缓存终点时间戳，不能宣称全量排空，历史 `lost=203` 不抹去 |

原 1 kHz SysTick 记录、16 项队列、16 类事件可能产生扰动；实际 F407 空探针开销仍 **NOT_MEASURED**。候选校准方法是另行审查隔离的“同钩点、同负载、只关闭记录”的空 profile，固定源/链接资源及新 BIN SHA，再在获批现场用同一外部观察域比较 CAN/drop、发布和恢复窗口。该方法会新增诊断源码与烧录，**本轮不实现、不签发**。若负责人未接受替代的不确定性裁定，M02/M03 的性能对照保持 `NOT_COMPARABLE`。
