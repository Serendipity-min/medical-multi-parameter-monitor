# P5 C2.5-R1 快照与扰动判废规约 v1.0

## 1. 适用范围和当前状态

依据 2026-10-08 的《P5 C2.5 诊断覆盖层代码审计与 C3 准入裁定》F-01～F-06 制定。本文件是**待复核的脱机操作规约**，不是 C3A 授权或实测报告。P4/P5 诊断 Patch 与探针保持原 SHA；生产固件、协议、链接脚本及 Flash 布局不变。

固定 P4 源码 `8dee339491cfd4edc468bb9451511d421f26db5e`、P5 源码 `e598fc63719acdf49a99c6da46c656dc8c607782`。诊断 BIN 分别为 `fabd82b305e2fe1bc4bbc0d06bdde91d05daabd7f91c70ca017f48e4617ab551` 和 `47a444ebd3642dffef80364309d0b100cc048b456d75dde0b2806a7f9a052efc`；这只是旧 C2.5 构建身份，尚未获准写入设备。

## 2. 每轮窗口关闭、冻结与保存顺序

以下仅供 C3A 审查，**本轮不连接 COM15/J-Link、不烧录或操作 Broker**。

1. 获批窗口开始前核对 UID、已批准的固件/配置/环境、同一 16 MHz 时钟和双 CAN 合成负载。逐版重新上电后记 `window_generation`、`recovery_generation` 的起始值；首次 D 的窗口号应为 1，三轮为 1、2、3。`recovery_generation` 还包含开机初次入网及可能的失败重试，只要求每轮严格递增。若现场窗口起始值不同，先修订索引规则并复核，不临时填数。
2. 外部观察器记录 D 命令发出时刻，明确使用 `HOST_QPC_US`；探针内部 M06 使用 `MCU_MONOTONIC_US`，两者不直接相减。每次 D 开始前确认上一轮索引、两次冻结读取及 SHA 已写入只增文件；没有保存成功就**禁止下一次 D**。
3. 候选固定观察时长为 D 后 **90 秒**。期间只被动记录原日志/同帧观察，不 halt、不 reset、不用断点、不重启 Broker。到 90 秒先核对至少已观察到恢复、首条合成 VALID 业务与本轮外部记录；缺任一项记失效，不延长时长凑结果。
4. 观察窗口终点定义为随后**首次 SWD halt 时刻**，记录外部时戳。只有此刻以后才允许读取 `probe_state`。一次首次 halt 若落在 `clock_seq` 奇数、活动 `depth` 非零或 IRQ 中，本轮时延指标立即判废；最多允许**一次** resume 后重 halt 取得故障分析副本，该副本不能转为有效测量。无额外 reset、联网重试或循环 halt。
5. 首次 halt 合格时保持内核冻结，从当前诊断 ELF 的 `probe_state` 符号地址**只读**读取完整 1264 B 两次；两次原始字节 SHA-256 必须一致。禁止在运行中逐字段读取 `uint64_t` 聚合。随后核对 `magic=0xC25D1A60`、profile、variant/标记、固件 SHA、偶数 `clock_seq`、`depth=0`、本轮 generation 与完整网络/缓存点。任一不符保存失败证据并停止该版后续轮次。
6. 原始只读快照存于获批的本地忽略/私有证据位置，文件名含版本、轮次、generation、SHA，使用独占创建，严禁覆盖。两次读取和索引保存成功后才可恢复运行并发下一 D；换版之前先完成三轮或记录明确 STOP。原始内存、配置和凭据不进入公开审查包。

这里的 90 秒、首次 halt 和重试限制均是**提议值**，需负责人在 C3A 申请中确认；当前无现场执行资格。索引工具暂以 D→首次 halt 90～92 秒、六轮跨度差≤2 秒为审查容差。由于探针没有独立“窗口结束”标记，最大值覆盖从 D 边界到首次 halt 的整个区间。首次 halt 实际时刻必须作为每轮终点留证；若各轮实际时长不可比，标 `NOT_COMPARABLE`。

## 3. 每轮索引与拒绝规则

脱机 [r1_snapshot_index.py](../../../../gateway/mqtt/tests/measurement/r1_snapshot_index.py) 只检查索引声明。它要求每版恰好三轮、编号连续且先保存再发下一 D；同一版冻结源码/诊断 BIN、环境、负载、profile 与 16 MHz 时钟一致；两次快照 SHA 相同且六轮不能复用同一 SHA。观察暂停、快照不一致、缺轮、generation 缺口、指标名漂移、Probe 失效标志、丢样和网络/缓存点缺失都拒绝。

字段 `foreground_flags` 只允许 `PROBE_STACK_BLOCKED=64`；`irq_flags=0`，`dropped_observations=0`，`tick_dropped_delta=0`，`unmatched_ticks=0`，`network_valid_mask=0x1ff`，`cache_snapshot_mask=3`。`clock_seq` 必须为偶数，`depth=0`。这些条件仅能筛掉已知坏样本；索引由人填写、快照 SHA 未与实际字节关联时，工具输出仍是 `INDEX_CONSISTENCY_ONLY / H16_acceptance=NOT_GRANTED`。

复核真实样本还需对只读原始快照独立重算 SHA、核对 ELF 符号偏移与 UID/固件回读、查验外部观察原件、确认 DWT 在完整窗口持续递增且 SysTick 没有漏服。索引检查不代替这些证据。若设备复位、调试暂停发生在窗口内、DWT 时钟/频率失真或外部记录缺失，按原始失败保存，不能重标有效。

## 4. M01～M07 的可报告名称与来源

| 指标 | 现有数字来源 | R1 审查口径及缺口 |
|---|---|---|
| M01 | `aggregate[OPEN/Q0/Q1/YIELD]` 与 `events[]` | 全 `gateway_mqtt_publish()` 包容时长，包括 P5 PUBACK；只存每类真实最大样本，不存在逐帧分布。丢类/时钟错则 `NOT_COMPARABLE`。 |
| M02 | SysTick `probe_tick` 采样与 `probe_service_done` | 唯一名称 `SYSTICK_ISR_SAMPLE_TO_COOPERATIVE_SERVICE_DONE`。理想到期→ISR 采样及物理 CAN IRQ 时延 **NOT_MEASURED**；不能继续称“计划到期→完成”。 |
| M03 | 完整 publish 父 span、库/AT/CAN 子 span | `PARTIAL / CPU_PURE_NOT_MEASURED`。P4 Paho API 与 P5 coreMQTT API 等待 PUBACK 口径不同，只比较完整 publish 包容周期；子区间只用于解释，包含 IRQ 与测量开销。 |
| M04 | 无安全栈哨兵 | `NOT_MEASURED / BLOCKED_UNSAFE_SENTINEL`；静态 8192 B 保留量不写成高水位。 |
| M05 | `heap_peak_bytes`、`heap_enomem_count - heap_error_base` | 含初始化/newlib/CAN 分配；检查峰值≤24576 B、计数无回退，不能解释成纯业务堆占用。 |
| M06 | `network_us[0..8]`、mask、首条业务数值身份 | 同一 MCU 时域，设备端点为 `DEVICE_PUBLISH_SUCCESS`。QoS0 发送完成不是 Broker ACK；外部 Broker/Backend 只作独立关联。 |
| M07 | `cache_before/after`、lost/replay/drop、LIVE/REPLAY 时刻 | `cache_drained_observed` 只改称 `OBSERVED_CACHE_EMPTY_AT_LAST_SNAPSHOT`，发生于最后一次 Router ACK 后观察，**没有窗口终点的缓存读取时间戳**。不能宣称最终全量排空或无损；既有 `lost=203` 历史事实保留。 |

每类最大记录槽上限 16；相同 scope/结果只原位更新，不能据此计算 p95、逐帧中位数或完整分布。现有 `analyze_h16.py` 的 `cycle_samples` 统计假定输入为真实逐次样本；把这 16 类最大值直接当逐次样本会产生误导性中位数，**当前没有获批的真实 JSON 导出链**。真实字段映射如下：诊断身份取 ELF/BIN 和 `probe_state`，环境/负载/暂停来自现场记录，周期取 `events[]` 加聚合计数，网络取 9 点及身份，堆取探针计数，栈必须 `null`，缓存取最近一次 before/after 和外部截止时刻。上述来源缺一项即不填对应实测字段；后续导出器和 schema 桥接需另审，不修改旧解析器准出逻辑。

## 5. 诊断扰动与判废

固定 profile 为 `C25_PROFILE_1`，两版同样有 1 kHz SysTick 记录、16 项 tick 队列、16 类最大事件与有界前台消费。空探针的 F407 周期成本**尚未测量**；Host 执行时间、静态 RAM 余量和反汇编不能推成实际无扰动。C3A 申请必须提交同频率/同负载空探针成本的独立校准方案或明确由负责人接受未校准限制；未经裁定，M02/M03 性能对照保持 `NOT_COMPARABLE`。

外部观察需逐轮记录 D 与首次 halt、CAN 已处理/丢帧、是否出现额外重连、首次业务时刻、实际时钟和两版诊断 profile。若 probe 丢类、tick 队列满、时钟标志、跨窗口未保存、最大类别超过 16、观察器漏帧或 CAN 行为偏离固定负载，整轮时延对照判废。不能静默扣掉估算探针开销，也不能用少量有效最大值替代全窗口最大。
