# P5 C2.5-R2 离线实现回执与证据索引 v1.0

## 1. 本轮范围

用户指示执行 2026-10-08《P5 C2.5-R1 证据复核、快照链路审计与 C3A 准入裁定》所建议的 R2。R2-01～R2-04 仅做脱机索引、字节链、合成负向测试和 C3A 操作单。主工作树 P4、P5 生产源码、诊断 `probe_events.c/.h`、两套 Patch、原 ELF/BIN、Flash 布局及旧 `analyze_h16.py` 未修改；无 Git add/commit/push、COM15/J-Link、烧录、Broker、Security Gate 或 P6 行为。

R1 审查 ZIP `597b0f262b3742df33af4608757fca0ca771935ff61d53d4738557269661a43e` 保留不动。本轮更改 R1 索引器、它的合成样本/测试、measurement README，并新增布局生成器、字节解码器、六轮绑定器、事件链样本与三组测试。[精确范围与文件哈希](evidence/c25-r2/C25_R2_DIFF.json)以已审 R1 ZIP 为基准；本回执产生后再封存差异索引。

## 2. R2-01 跨轮顺序

索引器现必须接受独立事件日志 `--event-log`。每轮六事件按 `D_SENT < HALT < READ1_DONE < READ2_DONE < SNAPSHOT_PERSISTED < RESUME` 严格递增；同一观察会话里前轮 RESUME 必须早于后轮 D。日志共 36 条，链式 SHA-256 逐条核对；跨会话、重叠、倒序、缺事件和人为声明时刻与日志不一致均拒绝。索引布尔值不能代替事件链。完整重构伪造日志仍可能保持自洽，因此输出只称 `HASH_CHAINED_OFFLINE_EVENT_LOG_NOT_PHYSICAL_AUTHENTICITY`。

## 3. R2-02 原始字节与编译器布局

ARM GNU 14.2.1 使用 `sizeof/offsetof` 生成 P4/P5 `ProbeState` 与子结构偏移；本地原诊断 ELF 的符号表证实主状态 1264 B、各版本 marker 地址。两次独立生成的 `probe-layout-v2.json` SHA 均为 `151a70d3f2bc874939844289d34ce1df48a65301a61a20a5d7884eab8ba36e7b`，副本见[机器布局](evidence/c25-r2/probe-layout-v2.json)和[复现核验](evidence/c25-r2/layout-reproduction.json)。冻结头文件 SHA 与原 C2.5 构建摘要交叉一致。此为类型布局普通 ARM 编译，**没有重建或更改原 P4/P5 诊断固件**。

字节解码器实际读取两份不同本地文件，核对 SHA、精确长度和冻结布局/头文件身份；解码 magic/profile/variant/marker/clock、稳定停止与丢样、M01/M02 最大事件、M03 包容聚合、M05 堆、M06 九阶段、M07 最近缓存和数值帧身份。任何实际文件字节与人工索引 SHA 不符时，六轮绑定器拒绝。跨轮 Heap 峰值/ENOMEM 及缓存累计计数回退也拒绝。测试样本全由普通 Host 代码人工生成 `.bin`，**没有现场快照**。

## 4. R2-03/R2-04 操作和指标限制

[C3A 申请规约](../设计/P5_C25_R2_原始快照链路与C3A申请规约_v1.0.md)列出唯一候选 halt、IPSR/PC、DWT 连续性、双读/保存/恢复后的网络稳定和外部观察。候选 2 秒暂停预算及 30 秒恢复观察均未获现场裁定。空探针 F407 成本仍 `NOT_MEASURED`，其校准候选需另外审批诊断变体与硬件窗口。M03 保持 `PARTIAL / CPU_PURE_NOT_MEASURED`；M04 `BLOCKED_UNSAFE_SENTINEL`；M07 仅最近快照瞬时空缓存，不证明全量排空。旧解析器的逐次样本 schema **没有收到每类最大值**。

## 5. 普通测试与真实证据边界

[最终测试日志](evidence/c25-r2/r2-measurement-tests-final.log)：同一次 `python -m unittest discover -s gateway/mqtt/tests/measurement -p "test_*.py" -v` 执行 **53/53 PASS**，包含未修改旧解析器 22 项、更新后索引 11 项、新事件顺序 7 项、新原始字节 8 项、六轮联链 5 项。联链测试真实读取 12 个临时合成 `.bin` 文件并在忽略 build 内清理。布局独立二次生成的 SHA 相同。

实施期间曾出现两次测试失败：一处是旧 R1 断言仍期待“时长漂移”，新规则更早拒绝索引/事件不符；另一处是初始合成字节的 `clock_seq` 未随六轮索引变化。按真实失败定位修正测试/样本后得到上述最终 PASS；原始失败日志保留在忽略的 `gateway/mqtt/build/h16-diagnostic/r2-layout/`，没有覆盖旧 C2.5/R1 历史记录。

`ARM_DIAGNOSTIC_REBUILD=NOT_RUN`；`REAL_H16=NOT_MEASURED`；`IPSR/PC/DWT_RUNTIME=NOT_VERIFIED`；`PHYSICAL_LOG_AUTHENTICITY=NOT_VERIFIED`；`EMPTY_PROBE_COST=NOT_MEASURED`；`C3A_ENTRY=HOLD`；`SECURITY_GATE=NOT_AUTHORIZED`；`PR6=NOT_MODIFIED_THIS_ROUND`。本轮完成 R2 脱机范围后停止，等待独立 C3A 裁定。
