# 运行日志保存与排障

本轮已启用服务器持久文件和 journald 双份事件日志，供事后查明连接中断、TLS 错误和积压发生的时间。

## 保存位置与轮转

| 来源 | 服务器文件 | 权限 | 保留上限 |
|---|---|---|---|
| Broker | /opt/medical-monitor/logs/broker/broker.jsonl | mosquitto，640 | 单文件 5MiB，当前 + 7 个备份，约 40MiB |
| Backend | /opt/medical-monitor/logs/backend/backend.jsonl | ubuntu，600 | 单文件 5MiB，当前 + 7 个备份，约 40MiB |

文件不在 release 目录内，重启、升级和回滚不会删除日志。按容量轮转，**不保证固定天数**；事件多时留存时间会缩短。
系统 journald 另留同样的结构化事件，其保存时间取决于服务器现有 journal 设置；本次未改全局策略。
出现问题应先将相关时段 JSONL 保存到受限事故目录，避免后续轮转覆盖。仓库只保存脱敏验收样本，不持续同步运行日志。
本轮样本：[runtime-log-sample.jsonl](../../../cloud/evidence/pr2-review1/runtime-log-sample.jsonl)。

## 记录内容

每行 JSON 有 UTC timestamp、component、severity、event，以及该事件适用的数值字段。

- Broker：启动/退出、配置重载、TLS 错误、证书问题、权限/密码文件问题、监听端口占用、认证/协议错误；可保留 OpenSSL 数字错误码。
- Backend：连接成功/失败、断连原因码、订阅状态，每分钟 accepted/rejected/dropped/queue_depth/attempts。
- 未识别 Broker 文本保留为 broker_error / broker_warning / broker_notice，不丢弃事件本身。
- 不保存原始 MQTT 载荷、患者数据、Topic、Client ID、用户名、口令或真实地址。

Broker 的 error/warning/notice 先进入 Python 代理的有界内存管道，再转换为固定类别和数字字段；**原始文本从不先写盘**。
connection_messages=false 保留，不开启 debug/subscribe/unsubscribe 日志。不可绕过代理把 stdout 直接持久化。
日志代理以 mosquitto 用户运行，TERM/HUP 转发给子进程；证书 timer 的 HUP 工作方式继续有效。

## 排障顺序

1. 先看 health 的 mqtt_connected、rejected、dropped；注意 health 是当前状态，日志用于回溯。
2. `sudo journalctl -u medical-monitor-mqtt -u medical-monitor --since "30 min ago" -o cat`。
   只分享带 component 的项目 JSON 事件，不复制未经核对的其他日志行。
3. Broker 有 tls_error：根据 openssl_code（十进制，可转换十六进制）检查证书有效期、时间与客户端 CA；勿关闭证书验证。
4. Backend mqtt_connect_failed：结合 Broker 时间线检查服务、网络、DNS和凭据；数字 reason code 可定位 MQTT 拒绝原因。
5. rejected 增长看 Topic/数据模型，dropped/queue_depth 增长看消费者负载；日志不保存载荷，需用合成源复现。
6. 收集受限日志快照后再重启。日志文件损坏/磁盘满时 journald 是备用证据；同时检查服务退出状态与磁盘。

## 数据可靠性与访问边界

第一阶段 Backend 使用 clean_session=True：后端停机期间，Broker 不为该会话积存 QoS1 消息。
QoS1 只保证相应 MQTT 会话的协议交付，不等于停机期间的数据不丢失；retained 只提供最后状态，不是历史库。
持久 Session、Gateway 缓存与 REPLAY 的组合留待后续评审，本轮未改变这项语义。

公网单共享 View Token 仅适用于当前合成数据阶段。接入真实人体可关联数据前必须另行完成受控网络/VPN、独立用户会话或可撤销凭据方案。
本轮不接入真实人体数据、不更换认证体系，也不启动第二阶段。

参考：[Mosquitto 日志配置](https://mosquitto.org/man/mosquitto-conf-5.html)、[Python 轮转日志](https://docs.python.org/3/library/logging.handlers.html)。
