## 实现与语义纠偏

保留 Vite 7.3.5、TypeScript、Vanilla DOM、Canvas；未增加前端依赖或框架。参考素材只作为布局和配色依据；CDN、在线字体、Tailwind 与 Material Symbols 未进入运行时。新的 [Design.md](../../../../cloud/web/Design.md) 明确视觉不能先于已实现的数据语义，旧线框标记为历史版本。

| 项目 | 最终处理 |
|---|---|
| ECG | 删除 Lead II、ST/QT/PVC、诊断、R 峰与物理走纸标定；保留 RA/LA/RL 静态配置说明 |
| SpO2 | 删除 PI、灌注和 AC/DC 指标、探头正常判断；PPG 仅相对幅值 |
| RESP | 删除 Ω 标定、RA-LL、载波频率、节律诊断和呼吸暂停报警；RR INVALID 显示 `--` |
| NIBP | 无 MAP、压力连续波、CRC/阀门状态和远程测量/放气控制；仅成对离散结果 |
| TEMP | 无 Ta/To 环境温、FOV、内部校准或 VALID 等于无丢包的推断；保留 1–3cm 静态操作说明 |
| 状态 | 顶部为工程样机、未接入患者身份、Gateway/节点状态、来源、真实最后通信和本地时钟；无虚构 Wi-Fi 百分比 |

六路由共用唯一 MonitorSocket、MonitorStore、SessionHistory、AccessDialog 和 RAF。路由不重连、不重新认证、不清空共享波形。只有当前页面 Canvas 挂载；缩放重设位图，不重建接收状态。

SessionHistory 从空开始，逐流按 session/seq/timestamp 去重；设备新会话和断线分段，切换网关清空，刷新清空，每通道最多 3600 条且最多 60 分钟。最近表显示 12 条已接收记录。CSV 仅在用户点击后从本地会话生成，文本单元格转义，没有历史接口或上传。冻结只保存显示副本，底层继续收帧；无效/过期/离线状态优先清空，CSV 包含冻结期间实际收到的新记录。

动态快照和历史文字通过 textContent / 文本节点更新；令牌只在内存，不进入 URL、日志或浏览器持久存储。REPLAY 仍独立显示，不能续活 LIVE。

## 2026-09-23 最终 UI 闭合

用户在初版预览后要求血压模拟放慢、血氧改红、配色增强、模拟数据多样化，并反馈全屏网格后有设置文字、连接验证失败原因不明确。本轮将这些改动连同回归脚本固定在同一 PR。预览模拟的 NIBP 每 30 秒产生一组，HR/PR/RR/SpO2 每秒、TEMP 每 2 秒更新；ECG、PPG、RESP 波形以采样时基分包。变化仅用于明确标识 MOCK 的模拟源，真实设备采集与临床含义不变。

全屏入口在用户点击时同步关闭设置模态层，避免不可见 dialog 截获页面点击；短屏允许中央区域滚动。血氧读数、PPG 和导航统一红色，趋势填充仅沿实际有效会话记录绘制。令牌拒绝、数据格式不兼容分别提示，失败时不保留输入或无限重试；令牌只存在当前页面内存。冻结时接收帧数仍增加，表示本页内存中的接收计数和有界会话历史继续更新；不自动写入服务器、磁盘或长期数据库。

最终构建在本机回环夹具上重跑 [39 项六页面 Browser Acceptance](../../../../cloud/evidence/stitch-ui-final/regression/browser-acceptance.json)，覆盖 1920×1080、1600×900、1366×768、390×844、MOCK/REPLAY/OFFLINE/INVALID、CSV 与不同值的 NIBP 30 秒间隔。[113 项全屏与交互回归](../../../../cloud/evidence/stitch-ui-final/interaction/interaction-acceptance.json)覆盖六页在正常/全屏下的真实点击、连接前后导航、冻结、断开重连、Escape、权限拒绝与 2560×1440 至 844×390 布局。[13 项连接反馈专项](../../../../cloud/evidence/stitch-ui-final/auth/interaction-acceptance.json)再次验证错误令牌提示、重试、格式不兼容分类和冻结收帧。[最终截图目录](../../../../cloud/evidence/stitch-ui-final/README.md)与交互回归同属本次提交。前端 `npm ci`、11 项状态测试、Vite 7.3.5 构建通过；Backend 28 项、模拟节奏 4 项、CANopen 12+11、canonical 41 消息、固定 sanitizer 42 项、Paho 完整性与 9 项测试通过。Windows 缺少 C 编译器，CANopen 与 sanitizer 使用既有 WSL GCC 执行。

用户授权的线上审核静态版按 [同步证据](../../../../cloud/evidence/stitch-ui-v2/server-review-sync.json)、[全屏交互证据](../../../../cloud/evidence/stitch-ui-interaction/server-activation.json)和[连接反馈证据](../../../../cloud/evidence/stitch-ui-auth/server-activation.json)顺序同步；线上仅做正常页面交互，不将本地故障注入扩展到公网服务。上述回执属于审核预览，不将服务器当前文件或旧截图误称为最终 Git SHA 的安全准出结果。
