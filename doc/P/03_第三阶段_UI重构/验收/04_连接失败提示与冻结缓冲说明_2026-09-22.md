# 连接失败提示与冻结缓冲说明

## 认证判断

现有服务令牌没有自动过期机制。用户截图说明校验失败，不能仅凭截图认定“令牌过期”。已确认本机预览与服务器的配置令牌不同，必须使用对应环境的完整值。服务令牌保持不变；用户可从外部私有配置 `E:/medical-monitor-private/server-access.json` 读取服务器令牌，仓库不收录该凭据。原 AppData 路径交付失败，已改用 E 盘并确认记事本显示文件标题；工具可读不能替代用户侧可访问的验证。

新增独立“访问验证失败”弹窗，提示核对令牌和网关授权，提供“重新输入令牌”按钮。提示与设置弹窗互斥，避免再次发生全屏模态层残留。校验失败清除浏览器内存中的令牌并停止自动重试；输入正确令牌可以恢复连接。

数据格式不兼容显示独立原因，不误报为令牌错误。浏览器主动关闭采用允许的应用码 4002；即使对端以普通关闭码响应，也保留此前确认的格式失败原因。

## 冻结期间的数据

| 项目 | 行为与位置 |
|---|---|
| 右上角“已收帧” | 本页累计收到的 WebSocket 快照数；不是文件数量，也不等于硬件采样点数 |
| 当前显示 | 冻结时复制一份显示数据；恢复后呈现最新值 |
| 实时波形 | 浏览器内存滚动缓冲，保留最近约 16 秒，另有每通道 16000 点硬上限 |
| 标量历史 | 浏览器内存；每通道最多 3600 条，保留最长 60 分钟，按会话与序列去重 |
| 文件保存 | 用户点击 CSV 导出时才生成下载；冻结期间的新标量可能包含在导出中 |
| 刷新、关闭页面 | 当前浏览器会话数据清空；切换网关清空历史，普通断线保留有时限的历史 |

冻结不会暂停网络接收，也不表示启用了服务器历史归档。本轮仅增加解释性提示，未新增数据库、自动落盘或改变既有采集策略。
