## 1. 视口规格与布局原则

根据专项合同 MPM-P-WEB-SOW-001 要求，监护屏主要服务于远程中央监护站大屏，其首要目标是在 **1920 × 1080 全高清显示器上实现 100% 垂直零滚动铺满**。同时向下兼容 **1366 × 768** 笔记本屏幕，并为移动端（**390 × 844** 视口）提供纵向安全折叠只读模式。

## 3. 栅格与尺寸规范 (1920 × 1080 零滚动保证)

为了严格实现 `document.documentElement.scrollHeight <= innerHeight`，页面采用全视口 Flexbox / CSS Grid 锚定：

1. **总容器 (`.app-shell`)**：
   - `height: 100vh; overflow: hidden; display: flex; flex-direction: column; background: var(--monitor-bg);`
2. **顶部状态栏 (`.app-header`)**：
   - `height: 52px; flex-shrink: 0; padding: 0 20px; display: flex; align-items: center; justify-content: space-between; border-bottom: 1px solid var(--panel-border);`
3. **中央主视区 (`.monitor-layout`)**：
   - `flex: 1; min-height: 0; display: grid; grid-template-columns: minmax(0, 7fr) minmax(0, 3fr); grid-template-rows: repeat(4, minmax(0, 1fr)); gap: 8px; padding: 8px 12px;`
4. **底部说明栏 (`.app-footer`)**：
   - `height: 36px; flex-shrink: 0; padding: 0 20px; display: flex; align-items: center; justify-content: space-between; border-top: 1px solid var(--panel-border); font-size: 12px; color: var(--text-muted);`

## 5. 参数卡片与读数规范 (Numeric Cards)

每个体征卡片遵循高清晰度层次结构：
- **标题行**：参数名称（如 `HR`、`SpO2`、`RR`、`NIBP`）+ 物理单位（如 `bpm`、`%`、`/min`、`mmHg`）；
- **数值行**：采用等宽高对比数字字体（`--font-numeric`），字号 48px～56px；
- **状态行**：显示数据来源节点与数据有效性标签（如 `Node-B · VALID`）。

### 异常状态映射规则
1. **VALID**：
   - HR / RR / PR：四舍五入整数显示，例如 `72`、`15`。
   - NIBP：以 `SYS / DIA` 形式显示，例如 `118 / 76`，无测量值或无效时显示 `— / —`。
   - TEMP：保留 1 位小数，例如 `36.6`。
2. **INVALID**：
   - 必须显示双横线 `—`，绝不可显示 `0`。
   - 呼吸率趋势区提示 `无有效 RR 数据`。
3. **STALE**：
   - 读数清除为 `—`，状态标签显示 `STALE`。
4. **OFFLINE**：
   - 卡片整体透明度降至 `0.4`，读数清除为 `—`，标签显示 `OFFLINE`。

## 6. Canvas 波形渲染引擎规范 (Waveform Canvas)

1. **清晰度与 DPR 适配**：
   - 每次重绘时检查 `canvas.width !== Math.round(width * dpr)`，自动同步物理像素与 CSS 逻辑像素，杜绝 4K/Retina 屏模糊。
2. **时间轴扫描与走纸窗口**：
   - 默认窗口 8 秒，支持通过顶部按钮切换为 16 秒（`data-window="8"` / `data-window="16"`）。
   - 水平坐标映射公式：`x = width * (1 - (now - point.t) / windowMs)`。
3. **采样断点起笔（Gap Detection）**：
   - 若相邻采样点时间间隔大于 100ms 或序列号重置，标记 `point.gap = true`。
   - 绘图循环检测到 `point.gap` 时立即执行 `ctx.moveTo(x, y)`，严禁执行 `ctx.lineTo(x, y)` 伪造假连续波形。
4. **背景微网格**：
   - 绘制暗色医疗坐标线，横向间距 32px，纵向间距 28px，线宽 0.6px，线色 `#16202c`。

## 7. 响应式布局适配规范

### 7.1 1366 × 768 笔记本屏幕
- 维持 4 行 2 列主结构不变；
- 间距缩减为 6px，标题与状态条高度压至 42px 与 28px；
- 大数值字号自动缩小为 36px～42px，确保在低分辨率屏幕上依旧保持零滚动。

### 7.2 移动端视口（390 × 844，如 iPhone / Android）
- 自动触发 `@media (max-width: 768px)` 媒体查询；
- 主网格重构为单列流式布局（`grid-template-columns: 1fr`），各体征卡片自上而下顺畅排列；
- 限制横向宽度为 `100vw`，禁止产生任何横向滚动条（`document.documentElement.scrollWidth <= innerWidth`）；
- 允许纵向自然滑动，保证床旁移动巡视时的只读可读性。
