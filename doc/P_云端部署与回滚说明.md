部署实施步骤、环境变量、离线依赖、备份与回滚见 [部署 README](../cloud/deploy/README.md)。

2026-09-19 用户明确调整：在已有主域名下新增页面，不新开子域名；服务器为本项目新建独立目录。
因此使用 `/medical-monitor/` 和 `/opt/medical-monitor/`，替代第一阶段合同中建议的独立子域名。
服务器连接使用用户确认的本机 SSH 别名 `tencent-codex`；真实服务器地址、凭据与站点映射不写入版本库。

路径隔离：本项目的 REST、WSS 与静态资源全部位于 `/medical-monitor/`。
后端使用 `127.0.0.1:18765`，公网复用已有 443。未请求也未执行防火墙规则修改。
Nginx 变更只在确认的主站 HTTPS server 增加一条本项目 include。

验收期间允许重启本项目 Backend 和 reload 现有 Nginx，不重启其他项目服务。
验收前后检查主页和已有页面的状态码及内容哈希，并核对 Nginx 变更只含该 include。
若出现既有页面变化或其他任务并发修改，暂停而不是擅自覆盖。
