# G2-S现场操作与记录清单

2026-10-15（Asia/Shanghai）。依据MPM-ECG-G2S-001 v1.0；固定基线`B2@2ca744d2f06d49711863968aeef15b64891edd18`。本文件是现场准备单，不是完成测试回执。尚无本轮上电、备份、烧录或DAC实测结果。

## 1. 当前等待的现场输入

只使用第二块F407，标记S；原采集板B与ADS保持断电、与S断开。不连接真人或RA/LA/RL。

1. 两板USB、J-Link、J5及其它电源全部断开。先提供S整板正面、P11正上方近照及万用表型号/表盘照片，确认S板身份。
2. P11照片须能对应LED/DAC、RJ/ADC、GND/TPAD丝印及三组针。板上可能没有数字3–4或5–6，不要求寻找这些数字。
3. 在确认当前照片与针序前，先不移除跳帽、不按K1、不插电。已有授权窗口内的现场确认属于执行条件，不是再次申请硬件授权。

## 3. 供电与仪表条件

- 选用已经确认的单一USB入口。J5与其它供电不接；J-Link VTref不是供电输出，探针型号/连接方式确认后仅用于目标电平参考及SWD。
- YL-1210铭牌12V直流/1A、中心正极已记录，实际极性/电压和J5匹配未测。USB方案不依赖先验证该适配器，也不自动批准插入J5。
- 万用表先确认型号、黑表笔COM、红表笔电压/电阻插孔。测电压不得用电流插孔或电流档；通断/电阻仅在两板无电状态下进行。确认实物测试点及仪表后再给出具体表笔落点。
- 上电电源测量由现场执行，Codex记录真实读数，不补填理论电压。参考地、3V3/5V测试点和K1选通若无法确认则停止。
- 当前无示波器。可按新合同完成电源、静态偏置与数字状态检查；真实动态输出须记DYNAMIC_UNVERIFIED，不以DMM均值或DMA计数判60/90bpm波形合格。

## 4. 后续依赖顺序（收到现场资料后执行）

1. S0：识别S板/针序/单电源路径/仪表，断电确认和处理指定跳帽；冻结源固件身份与可恢复备份策略。
2. S1：满足断电核验条件后，只给S单独上电，由现场测5V/3V3并记录。当前旧程序未知，不能提前声称其处于新源固件OFF模式；两路模拟端保持与B/ADS断开。
3. 电源合格后，仅连接已确认的S板SWD；实际读取原Flash并校验备份可用性、读保护和恢复方法。实际备份需要S供电，必须在擦写前完成；不能把S0中备份策略就绪写成备份已完成。
4. S2：备份/恢复条件合格后，核验冻结S专用BIN，再烧录校验；只使用S的符号地址切换模式。不得使用B板地址。若源BIN与归档SHA不同，先核对而不冒充相同产物。
5. S3：OFF→BIAS→1Hz→60→90→OFF。逐项记录数字模式/state/faults、DMM DC与动态仪器结果三列；无动态仪器则该列为NOT_MEASURED/DYNAMIC_UNVERIFIED。新固件重启默认OFF，不用无波形判固件失败。
6. 结束时记录S板最终状态/固件身份及恢复执行情况，生成唯一ECG_SOURCE_G2S_HANDOFF.md。未经数据证明不称STATIC_PASS或DYNAMIC_PASS。

原B固件、BIO_V2、G1源码和历史证据不变。不执行G2-A/G3、Security Gate或PR。现场条件不符立即停止，保留失败记录。
