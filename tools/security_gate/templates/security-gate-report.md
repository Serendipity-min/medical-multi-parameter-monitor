# Security Gate Report

自动报告由 report.py 从规范化数据生成，不复制工具原始文字。

1. Commit / Branch
2. Tool Versions
3. Gate Mode
4. Coverage Matrix
5. Findings
6. Accepted Risk
7. ASan/UBSan
8. SCA
9. Secrets
10. Static C
11. Build/Test
12. DAST
13. SBOM
14. GitHub Alerts
15. Architecture Checklist
16. Residual Risk
17. Final Verdict

每次报告旁的 report-integrity.json 记录 report SHA-256、result SHA-256、commit、SBOM SHA-256。
禁止写“项目完全安全”“无漏洞”“全部代码已覆盖”。
